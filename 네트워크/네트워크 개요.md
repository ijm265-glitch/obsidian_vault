## 🔌 Phase 1. 1계층 - 물리 계층 (Physical Layer)
- **정의:** 상위 계층으로부터 전달받은 비트 스트림(Bitstream)을 물리적 전송 매체(UTP, Optical Cable, RF)의 특성에 맞게 **전기, 광, 무선 주파수 신호로 상호 변환(Modulation / Demodulation)하는 계층**입니다.
- 물리적 매체의 결

- [ ] [[1.1 디지털 신호와 아날로그 신호]]
    - 비트(`0`과 `1`)를 전압(Voltage)과 빛으로 표현하는 원리
- [ ] [[1.2 물리적 전송 매체]]
    - UTP 케이블(랜선) 구조와 TP(Twisted Pair)선 간섭 방지 원리
    - 광케이블(Optical Cable)과 무선 주파수(RF)
- [ ] [[1.3 1계층 네트워크 장비]]
    - 더미 허브(Dummy Hub)의 작동 방식과 신호 증폭기(리피터)
    - 충돌 도메인(Collision Domain)의 개념

## 🔗 Phase 2. 2계층 - 데이터 링크 계층 (Data Link Layer)
- **정의:** 단일 물리적 링크(Directly Connected Point-to-Point Link)로 직접 인접한 **두 통신 노드(Node-to-Node) 간의 신뢰성 있는 데이터 전송 및 매체 제어를 담당하는 계층**입니다.
- 물리적으로 연결된 장비(Link) 간 데이터 전송 규약
- [ ] [[2.1 LAN과 이더넷]]
    - 근거리 통신망(LAN)의 정의와 유선 네트워크 표준인 이더넷(Ethernet)의 역할
- [ ] [[2.2 CSMA CD 프로토콜]]
    - 과거 이더넷의 눈치싸움 대화법: Carrier Sense, Multiple Access, Collision Detection
    - 현대 전이중 네트워크 환경에서 CSMA/CD가 불필요해진 이유
- [ ] [[2.3 MAC 주소]]
    - 하드웨어 고유 주소(48비트)의 구조 (OUI + VENDOR)
- [ ] [[2.4 이더넷 프레임 구조]]
    - Header(Preamble, 목적지 MAC, 출발지 MAC, EtherType) / Trailer(FCS/CRC 오류 검출)
- [ ] [[2.5 2계층 핵심 장비 스위치]]
    - MAC 주소 테이블 생성 과정
    - Flooding, Forwarding, Filtering, Learning, Aging
- [ ] [[2.6 ARP 프로토콜]]
    - IP 주소로 상대방의 MAC 주소를 찾아내는 과정
    - ARP Request(브로드캐스트)와 ARP Reply(유니캐스트)        
    - ARP Cache Table 및 GARP(Gratuitous ARP)
- [ ] [[2.7 가상 네트워크 분리 VLAN]]
    - VLAN의 필요성과 802.1Q 트렁킹(Trunking)

## 🌐 Phase 3. 3계층 - 네트워크 계층 (Network Layer)
- **정의:** 서로 다른 이종(Heterogeneous) 서브넷/네트워크로 형성된 복합 네트워크(Inter-network) 상에서, **출발지 호스트부터 최종 수신지 호스트까지(Host-to-Host)의 패킷 종단 간 전송 및 최적 경로 탐색(Routing)을 수행하는 계층**입니다.
- 수많은 링크를 거쳐 목적지까지의 길 찾기

- [ ] [[3.1 논리적 주소의 필요성과 IP 주소]]
    - MAC 주소만으로 글로벌 통신이 불가능한 이유 (위치 정보의 부재)
- [ ] [[3.2 IPv4 주소 체계]]
    - 32비트 체계와 점4성기법(Dotted Decimal)
    - 클래스풀 주소 체계(Classful Addressing)의 역사와 한계 (Class A, B, C, D, E)
- [ ] [[3.3 서브넷 마스크와 서브네팅]]
    - 네트워크 ID와 호스트 ID의 구분 기준 및 AND 비트 연산
    - 할당 불가능한 주소: 네트워크 대표 주소와 브로드캐스트 주소 ($2^n - 2$)
    - CIDR(Classless Inter-Domain Routing) 표기법 (`/24` 등)
- [ ] [[3.4 사설 IP와 NAT]]
    - IPv4 고갈 문제와 사설 IP 대역 (`10.X`, `172.16.X`, `192.168.X`)
    - 공인 IP vs 사설 IP
    - NAT 및 PAT(Port Address Translation)의 작동 원리 (공유기 원리)
- [ ] [[3.5 IPv6 주소 체계]]
    - 128비트 16진수 구조와 무한에 가까운 주소 공간
    - IPv6의 헤더 구조 단순화와 IPsec 기본 탑재로 인한 성능/보안 향상
- [ ] [[3.6 IPv4 패킷 헤더 구조]]
    - TTL(Time To Live)과 유령 패킷 방지
    - Header Checksum, Fragment Offset(패킷 단편화)
- [ ] [[3.7 라우터와 기본 게이트웨이]]
    - LAN과 WAN을 잇는 관문 역할을 하는 기본 게이트웨이(Default Gateway)
- [ ] [[3.8 라우팅과 라우팅 테이블]]
    - 라우팅 테이블(Routing Table)의 구성 요소
    - 정적 라우팅(Static Routing) vs 동적 라우팅(Dynamic Routing)
    - 라우팅 프로토콜 종류: RIP, OSPF, BGP

## 🚚 Phase 4. 4계층 - 전송 계층 (Transport Layer)
- **정의:** 통신을 수행하는 양 끝단의 **최종 응용 프로세스 간(Process-to-Process / End-to-End)의 신뢰성 있는 전송 서비스 및 데이터 흐름을 보장하는 계층**입니다.
- 최종 목적지 컴퓨터 내의 특정 프로그램(프로세스)까지 데이터 전송

- [ ] [[4.1 프로세스 식별과 포트 번호]]
    - IP(건물 주소) + Port(방 번호)의 개념
    - Well-Known Ports(0~1023), Registered Ports, Dynamic Ports
    - [[C.1 Socket]]
- [ ] [[4.2 TCP 프로토콜의 특성]]
    - 신뢰성 중심, 연결 지향적 프로토콜의 특성
    - TCP 세그먼트 헤더 구조 (Sequence Number, Acknowledgment Number 등)
- [ ] [[4.3 TCP 연결 수립과 해제]]
    - 연결 수립: 3-Way Handshake (`SYN` ➔ `SYN-ACK` ➔ `ACK`)
    - 연결 해제: 4-Way Handshake (`FIN` ➔ `ACK` ➔ `FIN` ➔ `ACK`)
- [ ] [[4.4 TCP의 흐름 제어 및 혼잡 제어]]
    - 슬라이딩 윈도우(Sliding Window)
    - 재전송 타이머(Retransmission Timeout) 및 Slow Start
- [ ] [[4.5 UDP 프로토콜의 특성]]
    - 비연결성, 속도 중심 프로토콜의 특성 및 데이터그램 헤더 구조
    - 실시간 스트리밍, DNS, 게임에서 UDP를 채택하는 이유
