## 1. 한눈에 보는 물리적 배치 구조 (내 방 ➔ 인터넷)

내가 방에서 컴퓨터로 버튼을 누르면 데이터는 아래와 같은 순서로 장비들을 통과합니다.

Plaintext

```
[ 내 PC ]
   │  (유선 랜선 / UTP 케이블)
   ▼
[ L2 스위치 ]  ─── (보통 가정용 공유기 내부에 탑재되어 있음)
   │
   ▼
[ 라우터 / NAT ] ─── (가정용 공유기의 핵심 엔진)
   │  (WAN 포트 / 랜선)
   ▼
[ 광트랜시버 / 모뎀 (ONT) ]
   │
   ========= (광케이블 / 빛 신호 전송) =========
   │
   ▼
[ 통신사(ISP) 기지국 L3 스위치 및 라우터 ]
   │  (수십~수백 km 광케이블 망)
   ▼
[ 목적지 서버 (Google, Naver 등) ]
```

## 2. 내가 데이터를 전송할 때 단계별 흐름

실제 내 PC가 "공유기 ➔ 통신사 ➔ 목적지 서버"로 이더넷 프레임과 IP 패킷을 쏘아 보낼 때 장비들이 하는 역할입니다.

### ① 내 PC (데이터 생성 및 1차 포장)

- 웹브라우저에서 클릭하면 데이터가 만들어지고, **3계층에서 목적지 IP**를, **2계층에서 공유기의 MAC 주소**를 적어 **이더넷 프레임**을 완성합니다.
    
- 랜선(UTP 케이블)을 통해 전기 신호로 데이터를 내보냅니다.
    

### ② L2 스위치 (집 안의 기기들을 하나로 묶어주는 역할)

- **배치 위치:** 내 컴퓨터 랜선이 꽂히는 바로 그 포트입니다. (가정용 공유기 뒷면의 LAN 1, 2, 3, 4번 포트가 바로 이 L2 스위치 모듈입니다.)
    
- **하는 일:** 내 PC에서 들어온 이더넷 프레임의 목적지 MAC 주소를 확인하고, 이를 공유기의 라우터 엔진 포트로 전달(Forwarding)합니다.
    

### ③ 라우터 / 공유기 (내 집과 외부 인터넷의 경계)

- **배치 위치:** 스위치 바로 다음 단계이며, 집 안 네트워크(LAN)의 출구 역할을 합니다.
    
- **하는 일:**
    
    1. 내 PC가 보낸 이더넷 껍데기를 벗겨내고 **3계층 IP 헤더**를 확인합니다.
        
    2. 사설 IP(`192.168.x.x`)를 외부에서 통신 가능한 공인 IP로 변환(NAT)합니다.
        
    3. 외부 인터넷으로 나가는 전용 포트(공유기 뒷면의 **WAN 포트**)로 데이터를 넘깁니다.
        

### ④ 광모뎀 / 광트랜시버 (전기 신호 ➔ 빛 신호 변환)

- **배치 위치:** 공유기 WAN 포트와 통신사 광케이블 사이에 위치합니다. (최근 공유기는 이 기능이 통합되어 있기도 하고, 벽면 단자 형태(ONT)로 따로 붙어있기도 합니다.)
    
- **하는 일:** 공유기에서 나온 **전기 신호(0과 1)를 광케이블이 탈 수 있는 레이저/LED 빛 신호(Pulse)로 변환**합니다.
    

### ⑤ 광케이블 (Physical Medium)

- **배치 위치:** 집 벽면 타공 구멍을 타고 나가 전주(전신주)나 아파트 배선함을 거쳐 통신사(KT, SKT, LGU+) 기지국까지 길게 연결되어 있습니다.
    
- **하는 일:** 빛의 속도로 이더넷 프레임 신호를 **수 km~수십 km 떨어진 통신사 국사까지 손실 없이 전송**합니다.
    

### ⑥ 통신사(ISP) 백본 라우터 및 L3 스위치 (인터넷의 고속도로)

- **배치 위치:** 통신사 데이터센터 및 기지국 내부에 거대하게 배치되어 있습니다.
    
- **하는 일:**
    
    1. 광케이블을 통해 들어온 빛 신호를 다시 전기로 복원합니다.
        
    2. 수많은 통신사 거대 라우터들이 **라우팅 테이블**을 조회하며, 구글/네이버 서버가 위치한 가장 빠른 경로로 데이터를 계속해서 릴레이(Relay) 전달합니다.
