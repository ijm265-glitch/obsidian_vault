# 2. I2C 주소 체계 및 프레임 구조 (Address Format)

I2C 버스에는 여러 슬레이브 장치가 공통 선로(SDA, SCL)에 물려 있으므로, SPI처럼 물리적인 칩 선택선(CS Pin)을 늘리는 대신 **소프트웨어 주소 바이트(Address Byte)**를 전송하여 통신할 타깃 장치를 지목합니다.

---

## 2.1 7비트 주소 체계의 기본 원리

* **I2C 표준 주소 길이:** **7비트** (이론상 $2^7 = 128$개, `0x00 ~ 0x7F` 범위).
* **예약 주소(Reserved Address):** 전체 128개 중 일부는 표준 규약에 의해 특수 용도로 예약되어 있어, 일반 센서/부품은 약 112개의 주소를 나누어 사용합니다.
  * `0x00`: General Call (버스 내 모든 장치에 동시 브로드캐스트)
  * `0x01` ~ `0x07`: CBUS, 다른 버스 포맷 등 특수 용도
  * `0x78` ~ `0x7B`: 10비트 주소 확장 모드용 프리픽스

---

## 2.2 1바이트(8비트) 전송 패킷 조립 구조

I2C 물리 계층(Physical Layer)은 **데이터를 무조건 8비트(1바이트) 단위로 전송**합니다. 따라서 7비트 고유 주소 뒤에 1비트 동작 제어 플래그를 붙여 1바이트를 조립합니다.

### 1) 비트 매핑 (Bit Mapping)
7비트 주소를 상위 비트(MSB 방향)로 1칸 밀어내고, 비어 있는 최하위 비트(LSB, Bit 0)에 **R/W (Read/Write) 플래그**를 배치합니다.

| 비트 인덱스 |            Bit 7             | Bit 6 | Bit 5 | Bit 4 | Bit 3 | Bit 2 | Bit 1 |    **Bit 0 (LSB)**     |
| :----- | :--------------------------: | :---: | :---: | :---: | :---: | :---: | :---: | :--------------------: |
| **역할** |              A6              |  A5   |  A4   |  A3   |  A2   |  A1   |  A0   |      **R/W 플래그**       |
| **설명** | **슬레이브 장치 고유 주소 (7-bit ID)** |   -   |   -   |   -   |   -   |   -   |   -   | **0: Write / 1: Read** |

* **Bit 7 ~ Bit 1:** 슬레이브 장치 고유 식별 주소 (7비트)
* **Bit 0 (R/W Bit):** 
  * `0` (LOW) : **Write 모드** (마스터가 슬레이브에 데이터를 기록하겠다)
  * `1` (HIGH) : **Read 모드** (마스터가 슬레이브로부터 데이터를 읽어오겠다)

### 2) 비트 연산 수식
C/C++ 코드 레벨에서 하드웨어 전송 패킷을 직접 생성할 때 사용하는 연산입니다.

$$Packet_{\text{Write}} = (\text{Address} \ll 1) \mid 0$$
$$Packet_{\text{Read}} = (\text{Address} \ll 1) \mid 1$$

---

## 2.3 실전 예시: MPU-6050과 SSD1306 주소 변환

### 1) MPU-6050 (`0x68`)
* 7비트 주소: `0x68` = $2$진수 `0110 1000`
* 좌측 시프트 (`0x68 << 1`): `1101 000_` (맨 끝자리 비어 있음)
* **Write 패킷:** `1101 0000` + `0` = `1101 0000` $\rightarrow$ **`0xD0`**
* **Read 패킷:** `1101 0000` + `1` = `1101 0001` $\rightarrow$ **`0xD1`**

### 2) SSD1306 OLED (`0x3C`)
* 7비트 주소: `0x3C` = $2$진수 `011 1100`
* 좌측 시프트 (`0x3C << 1`): `0111 1000_`
* **Write 패킷:** `0111 1000` + `0` = `0111 1000` $\rightarrow$ **`0x78`**
* **Read 패킷:** `0111 1000` + `1` = `0111 1001` $\rightarrow$ **`0x79`**

> **참고 (데이터시트/기판 표기 혼동 방지):**  
> 일부 중국산 모듈이나 데이터시트에서 MPU-6050 주소를 `0xD0`, OLED 주소를 `0x78`로 표기하는 경우가 있습니다. 이는 **7비트 고유 주소에 Write 비트(0)까지 결합된 8비트 패킷 값**을 적어둔 것입니다. 아두이노 `Wire.h` 라이브러리를 쓸 때는 순수 7비트 주소(`0x68`, `0x3C`)를 넘겨주어야 합니다.

## 2.4 하드웨어 주소 핀 (하드웨어 레벨 충돌 방지)

동일한 센서 2개를 단일 버스에 물려야 할 경우 I2C 주소 충돌이 발생합니다. 이를 방지하기 위해 센서 칩셋은 최하위 비트(A0)를 물리 핀으로 빼두어 변경할 수 있도록 지원합니다.

* **MPU-6050 (AD0 핀):**
  * `AD0 = GND (LOW)` $\rightarrow$ 주소: **`0x68`** (`1101 000`)
  * `AD0 = 3.3V (HIGH)` $\rightarrow$ 주소: **`0x69`** (`1101 001`)
* **SSD1306 OLED (기판 뒷면 저항 납땜 점퍼):**
  * 기본: **`0x3C`**
  * 점퍼 변경 시: **`0x3D`**
