## 센서 슬립 모드 해제 시퀀스 (`initMPU6050`)

MPU-6050은 전원 투입(POR) 직후 배터리 소모를 방지하기 위해 기본적으로 슬립(Sleep) 모드로 진입합니다. 이 상태에서는 내부 센서 코어와 ADC 회로에 전원이 공급되지 않으므로 반드시 웨이크업 제어가 선행되어야 합니다.

```c++
# define MPU_ADDR 0x68
// MPU-6050 초기화 (슬립 모드 해제)
void initMPU6050() {
  Wire.beginTransmission(MPU_ADDR);
  Wire.write(0x6B); // PWR_MGMT_1 레지스터 주소
  Wire.write(0x00); // 0을 써서 슬립 모드 해제 및 내부 8MHz 클록 선택
  Wire.endTransmission(true);
}
```

### 1) 버스 트랜잭션 흐름

1. `Wire.beginTransmission(MPU_ADDR)`
    
    - 마스터(ESP32-S3)가 버스에 **START 신호**를 생성하고, 주소 뒤에 쓰기 플래그(0)를 덧붙여 **`0xD0`** 패킷을 송신 버퍼에 저장하고  브로드캐스트할 준비를 함
        
    - 이것이 브로드캐스팅되면 `0x68` 주소를 가진 MPU-6050이 이를 감지하고 9번째 클록에서 ACK(0)를 반환합니다.
        
2. `Wire.write(0x6B)`
    
    - 타깃 레지스터인 `PWR_MGMT_1` (전원 관리 1)의 주소를 송신버퍼에 저장하여 송신되면 MPU-6050 내부 주소 포인터를 `0x6B`로 설정하도록 한다..
        
3. `Wire.write(0x00)`
    
    - 레지스터에 기록할 데이터 값 `0x00` (`0000 0000b`)을 송신버퍼에 저장
        
    - **Bit 6 (SLEEP) = 0:** 슬립 모드를 해제하여 계측 회로를 기동합니다.
        
    - **Bit 2:0 (CLKSEL) = 000:** 내부 8MHz 오실레이터를 메인 클록으로 지정합니다.
        
4. `Wire.endTransmission(true)`
    
    - 버퍼에 쌓인 바이트들을 모두 플러시(송신)하여 통신을 수행하고 마지막에 STOP 신호(SCL=HIGH일 때 SDA 상승)를 발생시켜 통신 세션을 공식 종료합니다.



## 4.3 14바이트 버스트 읽기 시퀀스 (`readMPU6050`)

센서 데이터(가속도 6바이트 + 온도 2바이트 + 자이로 6바이트)는 메모리 맵 상에서 **`0x3B`부터 `0x48`까지 연속으로 배치**되어 있습니다.
```C++
// 0x3B 레지스터부터 14바이트를 한 번에 읽어오는 함수
bool readMPU6050() {
  // 1. 읽기 시작할 레지스터 주소 전송 (가속도 X축 High 바이트)
  Wire.beginTransmission(MPU_ADDR);
  Wire.write(0x3B);
  byte status = Wire.endTransmission(false); // 재시작(Restart) 신호 유지

  if (status != 0) {
    return false; // I2C 통신 에러
  }

  // 2. 14바이트 연속 요청 (가속도 6바이트 + 온도 2바이트 + 자이로 6바이트)
  Wire.requestFrom((uint16_t)MPU_ADDR, (uint8_t)14, true);

  if (Wire.available() >= 14) {
    // 상위 8비트 << 8 | 하위 8비트 비트 연산으로 16비트 복원
    rawAcX = (Wire.read() << 8) | Wire.read();
    rawAcY = (Wire.read() << 8) | Wire.read();
    rawAcZ = (Wire.read() << 8) | Wire.read();
    rawTmp = (Wire.read() << 8) | Wire.read();
    rawGyX = (Wire.read() << 8) | Wire.read();
    rawGyY = (Wire.read() << 8) | Wire.read();
    rawGyZ = (Wire.read() << 8) | Wire.read();
    return true;
  }
  return false;
}
```

1. `Wire.beginTransmission(MPU_ADDR)`
	- 기기를 식별하기 위해 송신 버퍼에 기기 주소를 저장

2. `Wire.write(0x3B)`
	- 데이터가 있는 레지스터로 포인터 레지스터를 변경하기 위해 송신 버퍼에 데이터 레지스터를 저장

3. `byte status = Wire.endTransmission(false)`
	- 송신 버퍼의 데이터를 flushing하고 마스터가 STOP을 하지 않도록 설정 - STOP이 발생하는 경우 포인터 레지스터가 초기화 되는 경우가 있음

4. `Wire.requestFrom((uint16_t)MPU_ADDR, (uint8_t)14, true)`
	- REPEATED START를 수행
	- 기기 주소와 그 기기 주소의 포인터 레지스터를 바탕으로 14개의 데이터를 가져오는 Blocking 함수
	- 데이터를 가져오면서 마스터는 13번째 데이터까지에 대해 ACK를 하다가 14번째 바이트에서 NACK를 수행 (`true`)

5. 8비트 데이터 $\rightarrow$ 16비트 부호 있는 정수(`int16_t`) 복원
	MPU-6050 내부 ADC는 16비트 해상도의 2의 보수(2's Complement) 결과를 생성하지만, I2C 버스는 한 번에 8비트씩만 통신하므로 상위 바이트(High Byte)와 하위 바이트(Low Byte)가 순차 전달됨
	- `Wire.available() >= 14`
		- 현재 수신버퍼의 길이가 14 이상인지 확인
		- 그렇지 않다면 오류가 발생한것임

	- `rawAcX = (Wire.read() << 8) | Wire.read()`
		- `Wire.read()`를 통해 수신 버퍼의 바이트를 POP함
		- 상위 바이트를 shift하고 하위 바이트를 접합하여 2바이트 값을 복원
