## 1. L2(MAC) 브로드캐스트가 일어나는 케이스

> **`FF:FF:FF:FF:FF:FF`를 붙여서 같은 스위치/LAN 안의 모든 랜카드에게 뿌리는 상황**

### ① ARP (Address Resolution Protocol) 요청

네트워크에서 가장 대표적인 L2 브로드캐스트 케이스입니다.

- **상황:** 내 PC(`192.168.0.2`)가 같은 네트워크 안의 다른 기기(`192.168.0.5`)로 데이터를 보내고 싶습니다. IP 주소는 알고 있지만, 정작 물리적으로 패킷을 전송할 '목적지 MAC 주소'를 모릅니다.
    
- **동작:**
    
    1. 내 PC가 **"IP `192.168.0.5` 갖고 계신 분? MAC 주소 좀 알려주세요!"** 하고 ARP Request 패킷을 만듭니다.
        
    2. L3 목적지 IP는 `192.168.0.5`이지만, 누구의 MAC 주소인지 모르므로 L2 헤더에 `목적지 MAC: FF:FF:FF:FF:FF:FF`를 박아서 쏩니다.
        
    3. L2 스위치는 이 프레임을 받아서 네트워크 안의 모든 기기로 다 퍼뜨립니다.
        
    4. 해당 IP를 가진 기기만 "나야!" 하고 자신의 MAC 주소를 응답(Unicast)합니다.
        

## 2. L3(IP) 브로드캐스트가 일어나는 케이스

> **`255.255.255.255` 또는 서브넷 브로드캐스트 주소(예: `192.168.0.255`)를 목적지로 지정하는 상황**
> 
> _(※ L3 브로드캐스트 패킷도 랜선 위를 지날 때는 L2 헤더에 `FF:FF:FF:FF:FF:FF`가 씌워져 전송됩니다.)_

### ① DHCP IP 할당 요청 (DHCP Discover)

컴퓨터나 스마트폰이 Wi-Fi나 랜선에 처음 연결될 때 일어나는 케이스입니다.

- **상황:** 기기가 네트워크에 막 꽂혔을 때는 **자신의 IP도 없고, 네트워크에 DHCP 서버(공유기)가 어디에 몇 번 IP로 존재하는지 전혀 모르는 상태**입니다.
    
- **동작:**
    
    1. 기기는 **`출발지 IP: 0.0.0.0`**, `목적지 IP: 255.255.255.255`로 설정하여 **"이 동네에 IP 줄 수 있는 DHCP 서버 계신가요?"** 하고 외칩니다 (DHCP Discover).
        
    2. 이 L3 브로드캐스트 패킷은 L2 MAC 브로드캐스트(`FF:FF:FF:FF:FF:FF`)로 포장되어 네트워크 전체에 퍼지고, 이를 들은 공유기(DHCP 서버)가 IP를 할당해 주겠다고 응답합니다.
        

### ② 네트워크 로컬 서비스 자동 탐색 (mDNS, SSDP 등)

스마트폰이나 PC가 같은 Wi-Fi 안에서 **프린터, 스마트 TV, 크롬캐스트, 스마트 홈 기기** 등을 자동으로 찾아낼 때 사용됩니다.

- **상황:** 스마트폰에서 "화면 미러링"이나 "프린터 추가"를 눌렀을 때, 네트워크 안에 어떤 기기가 있는지 일일이 IP를 입력하지 않고 자동으로 찾고 싶습니다.
    
- **동작:**
    
    1. 앱이나 OS가 서브넷 브로드캐스트 주소(예: `192.168.0.255`)로 **"이 네트워크에 존재하는 공유 가능한 프린터/TV 다 응답해라!"** 하고 방송 패킷을 쏩니다.
        
    2. 같은 서브넷 내에 있던 스마트 TV나 프린터가 이 방송을 듣고 _"나 여기 있어!"_ 하고 자기 위치(IP/포트)를 응답하여 자동으로 목록에 뜨게 됩니다.
        

## 3. 요약: 두 케이스의 차이점

|**구분**|**L2 MAC 브로드캐스트 중심 케이스**|**L3 IP 브로드캐스트 중심 케이스**|
|---|---|---|
|**대표 예시**|**ARP 요청** (주소 탐색)|**DHCP Discover** (IP 할당), **서비스 자동 검색**|
|**발생 원인**|IP는 아는데 **상대방의 MAC 주소를 몰라서** 물어볼 때|**상대방의 IP 자체를 아예 모르거나**, **네트워크 전체 기기에 동시 신호**를 보내야 할 때|
|**처리 주체**|L2 스위치 및 랜카드 칩셋|OS(운영체제) 및 L3 라우터/공유기|

이처럼 **IP 주소 체계 안에서 전체에 외쳐야 할 때(L3)**, 혹은 **L2 하드웨어 단에서 상대방의 랜카드 주소를 찾아내야 할 때(L2)** 각각 브로드캐스트가 발생하게 됩니다!
