## 3.7 라우터와 기본 게이트웨이 (Default Gateway)

### 1. LAN과 WAN의 경계

- **LAN (Local Area Network, 내부망):** 집, 사무실, PC방처럼 공유기 하나로 묶인 **사설 네트워크 영역**입니다. 이 내부 기기들끼리는 스위치(Switch)를 통해 서로의 MAC 주소나 사설 IP로 직접 통신할 수 있습니다.
    
- **WAN (Wide Area Network, 외부망):** 인터넷(Internet)처럼 통신사(ISP) 백본망을 통해 전 세계로 연결되는 **외부 광역 네트워크 영역**입니다.
    
### 2. 기본 게이트웨이 (Default Gateway) 란?

"내가 모르는 외부 네트워크(WAN)로 나가는 패킷을 무조건 던져주는 출입문(관문) 주소"입니다.

- **왜 필요할까요?**
    내 PC가 `192.168.0.5`라면, 같은 내부망(`192.168.0.X`)에 있는 기기는 바로 찾아갈 수 있습니다. 하지만 목적지가 구글(`8.8.8.8`)이나 네이버처럼 "내 내부망 대역을 벗어나는 주소"일 경우, PC는 고심하지 않고 **'기본 게이트웨이' 주소로 패킷을 전송**합니다.
    
- **보통 누구인가요?**
    - 가정/사무실 환경: **공유기(Router)의 내부 사설 IP** (예: `192.168.0.1`)
    - 통신사 직접 연결(공인 IP) 환경: **통신사 게이트웨이 라우터 IP** (아까 본 `112.186.13.1`)
        

### 3. 라우터(Router)의 핵심 역할

기본 게이트웨이로 수신된 패킷을 넘겨받는 **라우터**는 두 개의 서로 다른 네트워크(LAN $\leftrightarrow$ WAN) 사이에서 다음 3가지 핵심 작업을 수행합니다.

1. **라우팅 (Routing, 경로 결정):**
    - 패킷의 목적지 IP 주소를 확인하고, 자신의 라우팅 테이블(Routing Table)을 조회하여 _"어느 선로(인터페이스)로 던져줘야 가장 빠르고 정확할지"_ 최적의 경로를 결정합니다.
        
2. **패킷 중계 및 변환 (NAT/PAT):**
    - 사설 IP 패킷을 공인 IP로 변환(PAT)하여 외부 인터넷망으로 내보내고, 반대로 들어오는 응답 패킷을 내부 사설 IP 기기로 다시 뿌려줍니다.
        
3. **L3 이종 네트워크 간 프로토콜 중계:**
    - 내부망이 Wi-Fi(무선)든 Ethernet(유선 랜선)이든 관계없이 L3 IP 데이터그램을 읽어 외부 통신사 망(광케이블/LTE 등)으로 실어 나릅니다.
