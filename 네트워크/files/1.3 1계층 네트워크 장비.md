## 1. 1계층 장비의 정체성과 한계
OSI 1계층(물리 계층) 장비는 데이터의 의미(MAC 주소, IP 주소 등)나 헤더 구조를 **전혀 이해하지 못하는 전기/물리 신호 중계 장치**입니다.

상위 계층의 캡슐화 포장지를 까볼 능력이 없기 때문에, 입력 포트로 들어온 비트 신호(`0`, `1`)를 단순 증폭/정형하거나 연결된 모든 포트로 복사하여 뿌리는 역할(Flooding)만 수행합니다.

## 2. 신호 증폭기: 리피터 (Repeater)
전선(UTP, 광케이블)을 타고 흐르는 전기/광 신호는 거리가 길어질수록 저항과 신호 감쇄(Attenuation) 현상으로 인해 파형이 뭉개집니다.

### 2.1 동작 원리
- **신호 재정형 (Reshaping) 및 증폭:** 단순 전압 증폭기가 아니라, 약해지거나 일그러진 디지털 신호를 받아 **임계값(Threshold)을 기준으로 깨끗한 `0`과 `1` 비트 신호로 다시 정형하여 원본 상태로 복원**한 뒤 다음 선로로 발사합니다.
- **사용 목적:** UTP 랜선의 한계 거리(약 100m)나 광케이블의 한계 전송 거리를 연장할 때 사용합니다.

## 3. 더미 허브 (Dummy Hub)
더미 허브는 "포트가 여러 개 달린 리피터(Multi-port Repeater)"라고 불립니다.

```
  포트 1           포트 2           포트 3           포트 4
    │                │                │                │
────┴────────────────┴────────────────┴────────────────┴──── [공통 전선 (공유 회로)]
```
### 3.1 동작 방식 (Flooding)
- 특정 포트로 전기 신호가 들어오면, 더미 허브는 해당 신호를 들어온 포트를 제외한 모든 포트로 무조건 복사하여 송출(Flooding)합니다.
- 수신받은 컴퓨터들은 각자의 2계층 랜카드(NIC)에서 L2 헤더의 MAC 주소를 까보고, **자기 주소가 아니면 프레임을 버리고(Discard), 자기 주소가 맞으면 수신**합니다.

### 3.2 더미 허브의 단점

- **보안 취약성:** 내 데이터가 네트워크상 모든 PC로 전달되므로, 스니핑(Sniffing) 공격에 매우 취약합니다.
- **대역폭 분할:** 통신 대역폭을 연결된 장비들이 나누어 사용하므로 장비가 늘어날수록 속도가 극도로 느려집니다.
- **충돌 위험:** 공유 매체 구조이므로 신호 충돌이 필연적으로 발생합니다.
## 4. 충돌 도메인 (Collision Domain)

### 4.1 개념
- **정의:** 네트워크상에서 **두 개 이상의 장비가 동시에 데이터를 발사했을 때 전기 신호가 서로 겹쳐 충돌(Collision)이 발생할 수 있는 영역의 범위**를 의미합니다.
### 4.2 더미 허브와 충돌 도메인
- 더미 허브에 연결된 모든 장비는 하나의 거대한 충돌 도메인(Single Collision Domain)에 묶입니다.
- 한 순간에는 오직 **단 한 대의 PC만 데이터를 전송**할 수 있습니다 (반이중 통신, Half-Duplex).
- 만약 PC A와 PC B가 동시에 신호를 쏘면 더미 허브 내부 전선에서 전압 신호가 겹치며 충돌(Collision)이 발생하고, 모든 통신이 중단된 뒤 재전송([[2.2 CSMA CD 프로토콜|CSMA/CD]]) 절차를 거쳐야 합니다.

| **구분**       | **리피터 (Repeater)**  | **더미 허브 (Dummy Hub)**           |
| ------------ | ------------------- | ------------------------------- |
| **주요 기능**    | 신호 거리 연장 (1:1 중계)   | 여러 장비 물리적 연결 (1:N 플러딩)          |
| **주소 인식 여부** | **불가능 (MAC/IP 모름)** | **불가능 (MAC/IP 모름)**             |
| **충돌 도메인**   | 분리 불가 (단일 도메인)      | **분리 불가 (연결된 전체가 1개 도메인)**      |
| **현대적 위상**   | 독립 장비로 거의 안 쓰임      | **2계층 스위치(Switch)에 의해 완벽히 대체됨** |
