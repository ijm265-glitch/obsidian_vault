## 네트워크의 본질적 정의 
- 노드(Node, 컴퓨터, 스마트폰, 라우터 등 장치)들이 링크(Link, 유무선 전송 매체)를 통해 서로 연결되어 데이터와 자원을 주고받는 상태
	- 노드 (Node): 데이터를 전송, 수신, 중계하는 네트워크상 모든 장치
	- 링크 (Link): 노드와 노드 사이를 물리적-논리적으로 잇는 전송 통로 (랜선, 광케이블, 무선 주파수 등)
- 단순히 잇는 것 뿐만 아니라 연결된 장치들이 어떤 통신 규약(프로토콜)과 뱡향성을 가지고 데이터를 오차없이 교환하는가에 있음

## 데이터 흐름에 따른 통신 방식 3가지
- 데이터가 이동하는 방향성과 동시성을 기준으로 통신방식을 구분하면 단방향(Simplex), 반이중(Half-Duplex), 전이중(Full-Duplex)의 3가지로 나뉜다.
### 1. 단방향 (Simplex)
- 데이터가 오직 한쪽 방향으로 흐르는 방식으로, 송신기는 데이터를 보내기만 할 수 있고 수신기는 받기만 가능
	- 동작원리: 송수신 채널의 구분이 없으며, 단 하나의 전송 통로가 단방향으로 고정되어 작동
	- 장점: 회로가 단순하고 신호 충돌이 일어날 가능성이 없음
	- 단점: 수신 측에서 데이터를 정상적으로 받았는지 확인 응답(ACK)를 보낼 수 없어 신뢰성이 필요한 데이터 통신에는 적합하지 않음
	- 예시
		- 아날로그 TV / FM:  라디오 방송에서 방송국 타워는 신호를 쏘기만 하고, 집 안의 라디오는 수신만 함.

### 2. 반이중 통신 (Half-Duplex)
- 양방향으로 통신이 가능하지만 동시에 양쪽으로 보낼 수는 없고 한 번에 한쪽 방향으로 데이터를 전송
	- 동작원리: 하나의 채널을 송신과 수신이 시간적으로 나누어(시분할) 공유함. 한쪽이 데이터를 보내는 동안 다른 쪽은 수신 상태로 대기
	- 단점: 두 장치가 동시에 데이터를 전송하면 신호가 충돌하는 경우가 발생. 채널의 전송 권한을 제어하는 규칙이 필요
	- 예시
		- 무전기: 한 사람의 말이 끝난 후에 상대방이 말할 수 있음

### 3. 전이중 통신 (Full-Duplex)
- **동작 원리:** 송신 전용 채널(Tx, Transmit)과 수신 전용 채널(Rx, Receive)이 물리적으로 완전히 분리되어 있거나, 주파수/시간을 다중화하여 독립적으로 데이터를 처리
- **장점:**
    1. 대기 시간이 없으므로 전송 효율이 반이중 방식에 비해 최대 2배 이상 상승
    2. 보내는 길과 받는 길이 다르므로 충돌(Collision)이 전혀 발생하지 않음
- **예시:**
    - **전화기:** 상대방의 말을 들으면서 동시에 내 목소리를 보낼 수 있음.
