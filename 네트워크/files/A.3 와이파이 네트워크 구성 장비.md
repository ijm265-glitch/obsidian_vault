## 1. 무선 AP (Access Point) vs 무선 공유기

실무나 뉴스, 가정에서 혼용되어 쓰이지만 두 장비는 네트워크 계층상 역할에서 명확한 차이가 있습니다.

```
[ 무선 AP ]    :  L2 장비 (단순 무선-유선 신호 변환 및 브리지 역할)
[ 무선 공유기 ] :  L2 무선 AP + L3 라우터 + DHCP 서버 + Switch + NAT (통합 장비)
```

### 1) 무선 AP (Access Point) — _L2 브리지 장비_

- **역할:** 유선 네트워크(Ethernet)를 무선 전파(Wi-Fi)로 변환하거나, 반대로 무선 신호를 유선으로 바꾸어 주는 **L2 계층의 '무선 스위치/허브'** 역할을 수행합니다.
    
- **특징:**
    
    - 스스로 IP를 할당하거나 라우팅을 수행하는 기능이 없습니다.
        
    - 기업, 대형 건물, 학교 등에서 중앙 라우터/스위치 하단에 여러 대를 설치하여 **넓은 무선 음영 지역을 커버**할 때 주로 사용합니다. (PoE 전원 공급으로 랜선 하나만 꽂아 사용)
        

### 2) 무선 공유기 (Wireless Router) — _올인원(All-in-One) 통합 장비_

- **역할:** 가정이나 소규모 사무실에서 인터넷 회선 1개로 여러 기기를 연결하기 위해 **여러 장비를 하나로 합쳐놓은 통합 단말**입니다.
    
- **내부 구성 요소:**
    1. **L3 라우터 (Router) & NAT:** 하나의 공인 IP를 여러 개의 사설 IP로 공유 가능하게 변환
    2. **DHCP 서버:** 접속하는 기기마다 IP, 게이트웨이, DNS를 자동으로 할당
    3. **L2 스위치 (Switch Hub):** 유선 랜 포트(LAN 1~4)를 제공하여 유선 기기 연결
    4. **무선 AP (Access Point):** 무선 안테나를 통해 Wi-Fi 신호 송수신
        

> **💡 한 줄 비교:** "무선 AP"는 순수한 무선 안테나/신호 변환기이고, 가정에서 쓰는 "무선 공유기"는 AP에 라우터, DHCP, 스위치를 때려 넣은 만능 상자입니다.

## 2. SSID vs BSSID

무선 네트워크 공간에서 특정 Wi-Fi 망을 식별하고 접속하기 위한 두 가지 핵심 식별자입니다.
```
[ SSID (논리적 이름) ] : "MyHome_5G"  ◄── 사람이 읽고 선택하는 이름
[ BSSID (물리적 주소) ] : "AA:BB:CC:11:22:33" ◄── 무선 AP 안테나의 진짜 MAC 주소
```

### 1) SSID (Service Set Identifier) — _논리적 와이파이 이름_

- **개념:** 사람이 무선 네트워크를 구분하여 선택할 수 있도록 부여한 논리적인 와이파이 이름(문자열)입니다. (예: `SK_WiFi_GIGA`, `Coffee_Free_WiFi`)
    
- **특징:**
    - 최대 32Byte의 문자열로 구성됩니다.
    - 보안을 위해 AP 설정에서 SSID 브로드캐스팅 비활성화(Hide SSID)를 적용하면 주변 기기 검색 목록에 나타나지 않게 숨길 수 있습니다.
    - **중복 가능:** 한 공간에 똑같은 SSID 이름을 가진 AP를 여러 대 설치할 수 있습니다. (로밍 기술의 기본 조건)
### 2) BSSID (Basic Service Set Identifier) — _물리적 AP MAC 주소_

- **개념:** 무선 AP(또는 해당 안테나/가상 AP)의 고유한 물리적 MAC 주소(48bit)입니다. (예: `00:11:22:33:44:55`)
    
- **특징:**
    
    - 전 세계에서 **유일한 고유값**을 가집니다.
    - 컴퓨터나 스마트폰이 실제 L2 프레임을 주고받을 때 헤더에 적는 무선 목적지/출발지 주소는 SSID가 아니라 이 BSSID(MAC 주소)입니다.
    - 하나의 물리적 AP가 2.4GHz / 5GHz 대역을 나누거나, 하나의 장비에서 "Guest Wi-Fi" 등 여러 가상 SSID를 띄울 경우, **각 무선 인터페이스마다 서로 다른 BSSID**를 가집니다.

### 💡 와이파이 로밍(Roaming)에서의 동작 예시

대형 회사나 카페에서 하나의 SSID(`Company_WiFi`)를 가진 AP가 10대 설치되어 있다고 해봅시다.

- **사용자 단말기(스마트폰):** 화면에는 똑같은 **SSID (`Company_WiFi`)** 하나만 표기됩니다.
    
- **실제 내부 통신:** 이동하면서 전파가 더 센 AP 쪽으로 새로 붙을 때, 스마트폰은 내부적으로 접속 대상을 **기존 AP의 BSSID A → 신호가 더 센 근처 AP의 BSSID B**로 전환합니다.
    

이 덕분에 사용자는 이동하면서 끊김 없이 똑같은 와이파이 이름을 계속 이용할 수 있습니다.
