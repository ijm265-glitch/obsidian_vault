와이파이(Wi-Fi) 통신 데이터를 공기 중에서 보호하기 위해 발전해 온 **무선 암호화 보안 프로토콜의 역사와 동작 원리**입니다.

## 1. WEP (Wired Equivalent Privacy)의 구조와 치명적 한계

1997년에 등장한 최초의 무선 보안 표준으로, "유선 랜만큼 안전한 보안을 제공하겠다"는 목적으로 만들었으나 **물리적·수학적 결함으로 인해 현재는 완전히 폐기(Obsolete)된 프로토콜**입니다.
```
[ WEP 암호화 방식 ]
24-bit IV (임의의 식별자) + 40-bit/104-bit 고정 비밀키 ──► RC4 스트림 암호화 알고리즘 ──► 패킷 암호화
```

### 치명적 한계점

1. **짧고 빈약한 IV (Initialization Vector):**
    
    - 패킷마다 암호화 키를 다르게 만들기 위해 $24\text{bit}$ 크기의 IV를 추가했지만, 값이 너무 짧아 트래픽이 많으면 **몇 시간 내에 동일한 IV가 재사용**되었습니다.
        
2. **취약한 RC4 알고리즘과 고정키 구조:**
    
    - RC4 스트림 암호화 알고리즘 자체의 수학적 결함과 고정 비밀키 구조 때문에, 공기 중의 무선 패킷을 약 수만~수십만 개 수집하면 **무차별 공격(AirCrack-ng 등)을 통해 단 몇 분 만에 비밀번호가 100% 해킹**됩니다.
        
3. **무결성 검증 무력화 (CRC-32):**
    
    - 데이터 위변조 체크를 위해 CRC-32를 사용했으나, 이는 단순 오류 검출용일 뿐 암호학적 무결성을 보장하지 못해 패킷 조작 공격에 취약했습니다.
        

## 2. WPA2 (Wi-Fi Protected Access 2)

WEP의 치명적 결함을 해결하기 위해 IEEE 802.11i 표준으로 제정된 **현시대 표준 무선 보안 프로토콜**입니다.

### 1) AES-CCMP 암호화 알고리즘 도입

- **AES (Advanced Encryption Standard):** 미국 정부 표준 대칭키 암호화 알고리즘으로, $128\text{bit}$ 이상의 강력한 키 블록을 사용합니다.
    
- **CCMP (Counter Mode Cipher Block Chaining Message Authentication Code Protocol):** AES 암호화 기법을 무선 통신에 맞게 최적화한 프로토콜로, 데이터의 기밀성(Encryption)과 무결성(Integrity Verification)을 동시에 완벽하게 보장합니다.
    

### 2) 인증 방식: PSK vs Enterprise

|**구분**|**WPA2-Personal (PSK)**|**WPA2-Enterprise**|
|---|---|---|
|**인증 방식**|**Pre-Shared Key** (사전 공유 키)|**802.1X / EAP** (중앙 인증 서버)|
|**작동 원리**|모든 기기가 **동일한 와이파이 비밀번호** 하나를 공유하여 인증|사용자별 **개인 ID/PW 또는 개인 인증서**를 부여하여 인증|
|**인증 주체**|무선 AP (공유기) 자체 처리|백엔드의 **RADIUS 인증 서버**|
|**보안 수준**|비밀번호가 유출되면 해당 비밀번호를 아는 모든 사람이 트래픽 복호화 가능|사용자마다 개별 대칭키가 생성되어 타인의 트래픽 복호화 불가능|
|**추천 환경**|가정, 소규모 카페/사무실|기업, 대학교, 금융기관, 공공기관|

## 3. WPA3 (Wi-Fi Protected Access 3)

2018년 발표되어 최신 Wi-Fi 6/7 기기에 적용되고 있는 차세대 보안 표준으로, WPA2의 약점을 대폭 보강했습니다.
```
[ WPA3의 핵심 진화 ]
1. SAE (Dragonfly Handshake) 도입 ──► 사전 공격(Dictionary Attack) 무력화
2. 순방향 비밀성 (Forward Secrecy)  ──► 과거 암호화 트래픽의 사후 복호화 방지
3. GCMP-256 암호화 (Enterprise)    ──► 192-bit 급 대칭키 보안성 강화
```

### 1) SAE (Simultaneous Authentication of Equals) - Dragonfly 4-Way Handshake

- **WPA2 PSK의 문제점:** WPA2에서는 4-Way Handshake 과정을 중간에 해커가 도청(Sniffing)한 뒤, 오프라인에서 사전(Dictionary)을 대입하여 비밀번호를 쉽게 알아낼 수 있었습니다.
    
- **SAE의 해결책:** 비밀번호를 직접 주고받는 대신 Diffie-Hellman 열쇠 교환 방식을 기반으로 한 디퓨-헬만 수학적 악수(SAE)를 수행합니다. 비밀번호를 몰라도 패킷을 들여다보며 비밀번호를 추측해 내는 **오프라인 사전 공격이 수학적으로 불가능**해졌습니다.
    
### 2) 순방향 비밀성 (Forward Secrecy)

- 해커가 어떤 와이파이 비밀번호를 나중에 알아내더라도, **과거에 수집해 둔 사용자의 무선 데이터 트래픽 패킷을 사후에 복호화할 수 없습니다.** (매 세션마다 일회성 고유 암호화 키가 생성됨)
    
### 3) Protected Management Frames (PMF) 의무화

- 무선 통신을 끊어버리는 디어센티케이션(Deauthentication) 공격이나 매체 제어 프레임 난동 공격을 막기 위해 **L2 제어/관리 프레임 암호화를 필수 적용**했습니다.

### 💡 한눈에 보는 요약

- **WEP:** RC4 + 짧은 IV 문제로 **5분 만에 뚫리는 폐기된 표준**
    
- **WPA2:** **AES-CCMP 암호화** 기반의 현재 주력 표준 (가정용 PSK / 기업용 Enterprise RADIUS)
    
- **WPA3:** **SAE(Dragonfly)** 알고리즘을 도입하여 **사전 대입 공격과 과거 데이터 복호화를 근본적으로 차단**한 최신 표준
