## 1. 광역 통신망 (WAN, Wide Area Network)

### 1) WAN의 정의

- **광범위한 공간적 범위:** LAN(근거리 통신망)이 한 건물이나 집 내부를 연결한다면, WAN은 도시, 국가, 대륙 간 등 **지리적으로 떨어진 수십~수천 km 이상의 광범위한 지역**을 연결하는 네트워크입니다.
    
- **통신 사업자(ISP) 기반:** 개인이 직접 케이블을 깔 수 없으므로, KT, SKT, LGU+, AT&T 같은 ISP(Internet Service Provider)가 구축해 둔 통신 망을 임대하거나 경유하여 통신합니다.
    

### 2) LAN과 WAN의 연결 방식

```
[ Home / Office LAN ] ──► [ Router / Modem ] ──► [ ISP Access Network (WAN) ] ──► [ Global Internet ]
```

- LAN 내부 장비들은 사설 IP(Private IP)로 통신하다가, WAN으로 나가는 Boundary Router(공유기 등)에서 NAT(Network Address Translation)를 통해 공인 IP(Public IP)로 변환되어 통신사 WAN망에 탑재됩니다.
    

## 2. 통신사(ISP)의 계층 구조 (Tier 1, Tier 2, Tier 3)

전 세계 인터넷은 수많은 인터넷 서비스 제공업체(ISP)들이 서로 연결되어 만든 '네트워크들의 네트워크'입니다. 이 ISP들은 망의 규모와 커버리지에 따라 3개의 계층(Tier)으로 분류됩니다.


```
               ┌────────────────────────┐
               │    Tier 1 ISPs (Global)│  ◄── 글로벌 백본 (Settlement-Free Peering)
               └───────────┬────────────┘
                           │ (Transit Fee)
               ┌───────────▼────────────┐
               │    Tier 2 ISPs (Regional)│ ◄── 국가/지역 단위 통신사 (KT, SKT, Telstra 등)
               └───────────┬────────────┘
                           │ (Transit Fee)
               ┌───────────▼────────────┐
               │    Tier 3 ISPs (Local) │  ◄── 소규모 지역 ISP, 케이블 방송사
               └────────────────────────┘
```

### 1) Tier 1 ISP (글로벌 백본망)

- **특징:** 전 세계 대륙 간을 넘나드는 거대한 광역 네트워크를 직접 소유한 초거대 통신사들입니다. (예: AT&T, Lumen/Level3, NTT, Telia 등)
    
- **무상 접속 (Settlement-Free Peering):** 자신들과 대등한 규모의 다른 Tier 1 ISP들과는 비용을 지불하지 않고 1:1로 트래픽을 무료 교환(Peering)합니다.
    
- **글로벌 도달성:** 통신 비용(Transit비)을 어디에도 내지 않고 전 세계 모든 인터넷 영역에 접근 가능한 독보적 위치에 있습니다.
    

### 2) Tier 2 ISP (국가/지역 단위 통신사)

- **특징:** 특정 국가나 대륙 커버리지를 가진 대형 통신사들입니다. (예: 한국의 KT, SKT, LGU+ 등)
    
- **혼합 모델:**
    
    - **Transit (통행료 지불):** 자신들이 도달할 수 없는 해외 망으로 나가기 위해 Tier 1 ISP에 통신 비용(Transit Fee)을 내고 망을 이용합니다.
        
    - **Peering (무상/유상 트래픽 교환):** 동일하거나 유사한 규모의 다른 Tier 2 통신사들과는 데이터 트래픽을 직접 교환합니다.
        

### 3) Tier 3 ISP (지역 액세스 망)

- **특징:** 최종 사용자(개인, 중소기업)에게 직접 인터넷 접속 서비스를 제공하는 소규모 지역 ISP입니다.
    
- **접속 방식:** 상위 계층인 Tier 2나 Tier 1 통신사에 접속 비용을 지불하고 트래픽을 사 오는 구조입니다.
    

## 3. 대륙 간 데이터 통신: 해저 광케이블과 IX

국가 간, 대륙 간을 연결하는 인터넷 통신의 $99\%$ 이상은 위성이 아닌 **바다 밑에 깔린 해저 광케이블**을 통해 이루어집니다.

### 1) 해저 광케이블 (Submarine Cable)

- **구조:** 수천 미터 깊이의 바다 밑바닥에敷設(부설)되며, 외부 수압과 물리적 충격을 견디기 위해 **강철 와이어, 전력선, 절연체**로 다층 보호된 중심부에 유리 섬유(광섬유, Optical Fiber)가 들어있는 형태입니다.
    
- **신호 전송 방식:** 전기가 아닌 **빛(Laser) 신호**의 전반사 원리를 이용하여 데이터를 전송합니다.
    
- **리피터 (Repeater):** 빛 신호가 수천 km를 가며 감쇄되는 것을 막기 위해 약 $50\sim100\text{km}$마다 광신호 증폭 장치(Repeater)가 설치되어 있으며, 케이블 내부의 동선(Copper Wire)을 통해 고전압 전력을 공급받습니다.
    

### 2) IX (Internet Exchange / 인터넷 교환 노드)

- **개념:** 서로 다른 통신사(ISP), 콘텐츠 제공업체(CDN, Google, Netflix 등)들이 트래픽을 효율적으로 직접 교환하기 위해 모이는 중계 거점(스위칭 센터)입니다.
    
- **필요성:**
    
    - 만약 IX가 없다면? 한국 KT 사용자가 SKT 서버에 있는 동영상을 볼 때, 망이 직접 안 뚫려 있어 해외 Tier 1 통신사를 경유해 비싼 통행료를 내고 받아와야 할 수 있습니다.
        
    - **IX의 역할:** 중간 중계소 역할을 하여 통신사 간 트래픽 이동 경로를 최단거리로 줄여주고, 해외 Transit 비용 절감 및 지연 시간(Latency)을 획기적으로 낮춰줍니다.
        
- **국내외 주요 IX:**
    
    - **한국:** KIX (한국인터넷진흥원), KINX (한국인터넷백본망), 통신사 자체 IX (KT-IX 등)
        
    - **해외:** LINX (영국 런던), DE-CIX (독일 프랑크푸르트), Equinix (미국/글로벌)
        

### 거시적 데이터 이동 경로 요약

1. 내 PC에서 출발한 데이터 패킷이 **사설 IP $\rightarrow$ 공인 IP**로 변환(NAT)되어 **가입한 ISP(Tier 2/3)** 망으로 들어갑니다.
    
2. 국내 다른 통신사나 서버로 갈 경우 국내 IX(Internet Exchange)를 거쳐 최단거리로 전달됩니다.
    
3. 해외(예: 미국 구글 서버)로 갈 경우, 해저 광케이블 육상 양륙국(Landing Station)을 통해 바다 밑 광케이블을 타고 건너가 **해외 Tier 1/2 ISP망**을 거쳐 목적지에 도달합니다.
