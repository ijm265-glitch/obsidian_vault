
### 1. 라인 전체의 회로 구조 (풀업 저항 + 스위치)

통신선 하나에 여러 센서(노드)가 달려있고, 맨 위에는 전원($5\text{V}$)과 저항이 하나 달려있습니다.


```
               +5V 전원
                │
              [ 저항 ]  ◄── (평소에 라인 전압을 5V로 연약하게 유지해 주는 역할)
                │
 ── 통신선 ─────┼───────────────┬───────────────┬─── (모든 센서가 수신하는 라인)
                │               │               │
            [센서 A]        [센서 B]        [센서 C]
             스위치          스위치          스위치
                │               │               │
               GND             GND             GND  (0V)
```

### 2. 센서들이 스위치를 다룰 때 일어나는 일

#### ① 아무도 말을 안 하거나, 다 같이 '1'을 쏠 때 (모든 스위치 OFF)

- 센서 A, B, C 모두 스위치를 **열어둡니다(OFF)**.
    
- 전선에 흐르는 전류가 없고, 맨 위의 저항을 통해 전원($5\text{V}$)이 통신선에 그대로 연결됩니다.
    
- **결과:** 통신선 전압은 $5\text{V}$ (`Logic 1`)가 됩니다. (가만히 놔두면 1이 되는 약한 상태)
    

#### ② 센서 B 혼자 '0'을 쏠 때 (스위치 하나만 ON)

- 센서 A, C는 스위치를 열어두고 있는데, **센서 B가 자기 스위치를 '찰칵' 하고 닫아버립니다(ON).**
    
- 스위치가 닫히는 순간, 통신선에 있던 전기가 센서 B의 스위치를 타고 아래쪽 GND($0\text{V}$)로 한순간에 전부 빠져나가 버립니다.
    
- **결과:** 통신선 전압은 $0\text{V}$ 쪽으로 강하게 끌려 내려가 $0\text{V}$ (`Logic 0`)가 됩니다.
    

### 3. '0'과 '1'이 충돌할 때 $0$이 이기는 이유

이제 센서 A는 '1'을 쏘려고 스위치를 열고, 센서 B는 '0'을 쏘려고 스위치를 닫은 상황입니다.


```
               +5V 전원
                │
              [ 저항 ]
                │
 ── 통신선 ─────┼───────────────────────┐
                │                       │
            [센서 A]                [센서 B]
          스위치 열림 (1)         스위치 닫힘 (0)
            (아무 역할 못함)         (전기를 GND로 완전히 훔쳐감!)
                                        │
                                       GND (0V)
```

- 센서 A가 아무리 "나는 스위치 열고 $1$ 상태로 가만히 있을래"라고 해봤자, **옆에 있는 센서 B가 스위치를 닫아서 통신선의 전기를 $0\text{V}$ 바닥으로 다 끌어내려 버린 상태**입니다.
    
- 센서 A 입장에서는 손을 떼고 가만히 있는 것밖에 안 되기 때문에, 센서 B가 스위치를 닫는 순간 통신선 전체의 전압은 무조건 $0\text{V}$(Dominant '0')가 됩니다.
    

### 요약하자면

1. **'1' 전송:** "스위치를 연다(OFF)." $\rightarrow$ 가만히 있으면 저항 때문에 전압이 올라가서 $1$이 됨. (힘이 약함)
    
2. **'0' 전송:** "스위치를 닫는다(ON)." $\rightarrow$ 통신선을 바닥($0\text{V}$)에 직결시켜 버림. (힘이 매우 강함)
    
3. **충돌 시:** 한 놈이라도 스위치를 닫아($0$) 바닥에 연결해 버리면, 스위치를 열고 있던($1$) 다른 놈들은 힘을 못 쓰고 **전선 전체가 $0\text{V}$($0$)로 찍히게 됩니다.**
    

혹시 스위치 동작이나 $0\text{V}$ 연결 방식에서 더 헷갈리는 부분이 있으신가요?
