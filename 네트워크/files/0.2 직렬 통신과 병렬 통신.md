## 1. 직렬 통신과 병렬 통신의 기본 개념

데이터의 최소 단위인 비트(`0`과 `1`)를 전송 채널(선로)을 통해 어떤 구조로 나르는가에 따라 직렬 통신(Serial)과 병렬 통신(Parallel)으로 나뉨
### 1.1 직렬 통신 (Serial Communication)
- 단 한 개(또는 송수신 한 쌍)의 전송선로를 사용하여 데이터를 한 비트(Bit)씩 순차적으로 전송하는 방식
### 1.2 병렬 통신 (Parallel Communication)
- 여러 개의 전송선로(예: 8개, 16개, 32개 등)를 병렬로 배치하여 한 번에 여러 비트(1 Byte 이상)를 동시에 전송하는 방식

> 현재는 주로 **직렬 통신**을 채택하고 있음

## 2. 직렬 통신이 채택된 이유
### 2.1 신호 동기화의 한계: 클록 스큐 (Clock Skew)
- **문제점:** 병렬 통신은 여러 선을 통해 신호를 동시에 발사합니다. 하지만 케이블의 미세한 길이 차이, 재질 불균일, 전용 회로의 지연 시간 차이로 인해 **수신 측에 도착하는 시간(Timing)이 미세하게 틀어집니다.**
- **결과:** 데이터 속도가 빨라지거나 전송 거리가 길어질수록, 1번 선의 비트와 8번 선의 비트가 다른 시점에 도착하여 **데이터가 엉키고 거대한 오류**가 발생합니다. 직렬 통신은 단일 선로를 쓰므로 이 스큐 현상 자체가 발생하지 않습니다.
### 2.2 누설과 방해: 신호 간섭 (Crosstalk)
- **문제점:** 전선에 전류(신호)가 흐르면 주변에 전자기장이 형성됩니다. 병렬 케이블처럼 여러 전선이 신호를 가진 채 빽빽하게 붙어가면, 옆 선의 신호가 인접한 선의 신호를 방해하는 누화 현상(Crosstalk)이 강하게 일어납니다.
- **결과:** 고주파(고속) 신호일수록 간섭이 극심해져 신호가 뭉개집니다.
### 2.3 물리적 비용과 케이블 두께 (Cost & Space)
- **문제점:** 수 킬로미터, 수 천 킬로미터(해저 광케이블 등)를 잇는 외부 네트워크망에 병렬 선로를 건설하려면 **케이블 두께, 무게, 소재 비용이 수십 배로 폭증**합니다.
- **결과:** 직렬 통신은 물리적 선로 수를 최소화하여 구축 비용과 유지보수 효율성을 극대화합니다.
### 2.4 기술의 발전: SerDes와 고속 직렬 클록 복원 (Clock Recovery)
- **해결책:** 현대 반도체 기술의 발전으로 **SerDes(Serializer/Deserializer)** 칩셋이 등장했습니다.
- 내부 병렬 데이터를 직렬로 촘촘하게 펴서 초당 수십~수백 기가비트(Gbps)의 극초고주파 신호로 쏘아 보낼 수 있게 되면서, "선을 여러 개 깔아 보내는 병렬 방식"보다 **"선 하나를 극도로 빠르게 쏘는 직렬 방식"이 전속 속도 면에서도 훨씬 뛰어남**을 증명해냈습니다.
