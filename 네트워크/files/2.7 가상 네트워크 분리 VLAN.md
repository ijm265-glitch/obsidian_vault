## 1. VLAN(Virtual Local Area Network)의 필요성

VLAN은 물리적인 스위치 장비 1대를 **소프트웨어적으로 여러 개의 독립된 가상 스위치(LAN)로 나누는 기술**입니다.
**오직 우리 내부의 Local Area Network(LAN)를 논리적으로 쪼개는 기술**
### 왜 VLAN이 필요할까요?

물리 스위치 1대에 연결된 모든 컴퓨터는 기본적으로 하나의 거대한 브로드캐스트 도메인(Broadcast Domain)에 속합니다. 이때 다음과 같은 문제점들이 발생합니다:

1. **브로드캐스트 플러딩(Flooding) 방지**
    - 방금 공부했던 **ARP, GARP, DHCP Request** 같은 브로드캐스트 패킷은 네트워크 전체로 퍼집니다.
    - 기기 수가 많아지면 스위치가 온통 브로드캐스트를 처리하느라 과부하가 걸려 **전체 네트워크 성능이 저하**됩니다.
    - **VLAN 적용 시:** 가상으로 동네를 쪼개어 브로드캐스트 패킷이 **해당 VLAN 내부로만 한정**되도록 폭풍 범위를 줄여줍니다.
        
2. **보안성(Security) 강화**
    - 같은 스위치에 꽂혀 있더라도 인사팀, 개발팀, 재무팀 간의 통신을 차단해야 하는 경우가 있습니다.
    - **VLAN 적용 시:** L2 계층에서 서로 다른 VLAN 간 통신이 **물리적으로 완전히 분리된 것처럼 격리**됩니다. (서로 통신하려면 반드시 L3 라우터나 L3 스위치를 거쳐야만 함)
        
3. **유연한 그룹 관리 및 비용 절감**
    - 1층에 있는 개발자와 3층에 있는 개발자를 **물리적 선 공사 없이 논리적으로 같은 VLAN으로 묶을 수 있습니다.**
    - 팀마다 스위치를 따로 살 필요 없이 **스위치 1대로 해결**되므로 비용이 절약됩니다.

## 2. IEEE 802.1Q 트렁킹 (Trunking)

> 스위치끼리 통신에 사용

스위치가 2대 이상이고, 각 스위치에 VLAN 10(개발팀)과 VLAN 20(인사팀)이 동시에 존재한다고 가정해 보겠습니다.

```
[ 스위치 A ] ════════════ (선 1개만 연결!) ════════════ [ 스위치 B ]
  ├── VLAN 10 (개발팀)                                   ├── VLAN 10 (개발팀)
  └── VLAN 20 (인사팀)                                   └── VLAN 20 (인사팀)
```

만약 트렁킹 기술이 없다면 스위치 A와 B 사이에는 **VLAN 10 전용 랜선 1개, VLAN 20 전용 랜선 1개**를 각각 따로 뚫어 연결해야 합니다. VLAN이 100개면 랜선도 100개를 연결해야 하는 비효율이 발생하죠.

> **트렁킹(Trunking)**이란 **단 1개의 물리적 랜선(포트)을 통해 여러 개의 VLAN 프레임을 동시에 통과시키는 기술**입니다.

### 🏷️ 802.1Q 태깅 (Tagging) 메커니즘

하나의 선으로 여러 VLAN의 데이터가 섞여서 들어가는데, 반대쪽 스위치는 "이 프레임이 VLAN 10 거냐, VLAN 20 거냐?"를 어떻게 구분할까요?
이때 사용되는 업계 표준 규격이 바로 **IEEE 802.1Q**입니다.
```
[ 일반 이더넷 프레임 ]
┌──────────────┬──────────────┬──────────┬──────────┬──────┐
│ 목적지 MAC    │ 출발지 MAC    │  Type    │  Data    │ FCS  │
└──────────────┴──────────────┴──────────┴──────────┴──────┘

[ 802.1Q 태그가 삽입된 프레임 ]
┌──────────────┬──────────────┬───────────┬──────────┬──────────┬──────┐
│ 목적지 MAC    │ 출발지 MAC    │ 802.1Q    │  Type    │  Data    │ FCS  │
│              │              │ Tag (4B)  │          │          │      │
└──────────────┴──────────────┴───────────┴──────────┴──────────┴──────┘
                                    ▲
                                [ VLAN ID: 10 ]
```

1. **태그 삽입 (Tagging):** 스위치는 일반 프레임이 트렁크 포트(Trunk Port)로 나갈 때, L2 헤더 중간에 4바이트짜리 802.1Q 태그 정보(VLAN ID 포함)를 살짝 끼워 넣습니다.
2. 
3. **전송:** 프레임이 "나 VLAN 10번 표딱지 달았다!" 하고 트렁크 선을 따라 건너갑니다.
    
4. **태그 제거 (Untagging):** 건너편 스위치는 태그를 읽어서 VLAN 10번 포트로 내보내주고, 최종 PC로 전달하기 직전에 **4바이트 태그를 다시 깨끗하게 떼어내어** 일반 프레임으로 복원합니다. (PC는 태그 존재 자체를 모름)
