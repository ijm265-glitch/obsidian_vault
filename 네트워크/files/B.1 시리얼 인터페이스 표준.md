산업 현장 및 임베디드 디바이스 통신의 근간이 되는 시리얼 인터페이스 표준(RS-232, RS-422, RS-485)의 비교와, **차동 신호(Differential Signaling)의 물리적 노이즈 상쇄 원리**입니다.

## 1. RS-232, RS-422, RS-485 비교

시리얼 통신 표준들은 전송 방식(단동 vs 차동), 통신 방식(Duplex), 연결 가능한 단말의 수, 통신 거리에 따라 구분됩니다.

|**구분**|**RS-232**|**RS-422**|**RS-485**|
|---|---|---|---|
|**전송 방식**|**단동 신호 (Single-Ended)**|**차동 신호 (Differential)**|**차동 신호 (Differential)**|
|**통신 방식**|전두위 (Full-Duplex)|전두위 (Full-Duplex)|**반두위 (Half-Duplex)** / 전두위 (4선)|
|**네트워크 구성**|**1 : 1** (Point-to-Point)|**1 : N** (1 Master, Max 10 Slave)|**N : N (Multi-Drop, Max 32개 이상)**|
|**최대 통신 거리**|약 $15\text{m}$ ($50\text{ft}$)|약 $1.2\text{km}$ ($4,000\text{ft}$)|**약 $1.2\text{km}$ ($4,000\text{ft}$)**|
|**최대 전송 속도**|~ $20\text{kbps}$ (표준) / $115.2\text{kbps}$|~ $10\text{Mbps}$|~ $10\text{Mbps}$|
|**필요 선 수**|최소 3선 (Tx, Rx, GND)|4선 (Tx+, Tx-, Rx+, Rx-) + GND|**2선 (A/Data+, B/Data-)** + GND|
|**주요 사용처**|PC 임베디드 콘솔, 검사 장비|장거리 1:N 산업용 통신|**PLC, 공장 자동화, 센서 네트워크**|

```
[ RS-232: 단동 신호 ]
  Tx ─────────────────────────► Rx
 GND ─────────────────────────► GND (접지 기준 측정)

[ RS-485: 차동 신호 (2선 반두위 Multi-Drop) ]
  A (+) ───┬───────────────────────┬─── Data+
           │                       │
  B (-) ───┼───────────────────────┼─── Data-
           │                       │
       [ Master ]              [ Slave 1 ]             [ Slave 2 ]
```

## 2. 차동 신호(Differential Signaling)와 노이즈 상쇄 원리

RS-485 및 RS-422가 수백 미터~1km가 넘는 열악한 공장 환경(모터 노이즈, 고전압 전선 전자기 간섭)에서도 통신을 안전하게 유지할 수 있는 핵심 비결은 **차동 전압 측정 원리**에 있습니다.

### 1) 단동 신호 (Single-Ended - RS-232)의 한계

RS-232는 **신호선(Tx) 1개와 공통 접지선(GND) 1개 사이의 전압 차이**로 $0$과 $1$을 판단합니다.

- 외부에서 전자기 간섭(노이즈)이 쳐들어와 신호선의 전압이 $5\text{V} \rightarrow 2\text{V}$로 순간적으로 찌그러지면, 수신 측은 이를 비트 오류로 인식합니다.
    

### 2) 차동 전압 측정 원리 (RS-485 / RS-422)

RS-485는 신호선 하나 대신 서로 위상이 반대인 두 개 신호선 Pair($A/Data+$, $B/Data-$)를 꼬아서(Twisted Pair) 사용합니다.

- **비트 $1$ 전송 시:** $V_A > V_B$ $\Rightarrow$ $V_A - V_B > +0.2\text{V}$
    
- **비트 $0$ 전송 시:** $V_A < V_B$ $\Rightarrow$ $V_A - V_B < -0.2\text{V}$
    

수신기는 절대적인 전압 값이 아니라 두 선 사이의 '전압 차이($V_A - V_B$)'만을 측정하여 $0$과 $1$을 판별합니다.

### 3) 동상 노이즈 제거 (Common-Mode Noise Rejection)

산업 현장에서 모터나 전력선에 의해 강한 전자기파 노이즈($V_{\text{noise}}$)가 전선에 침투한다고 가정해 봅시다.

```
[ 노이즈 침투 전 ]
  V_A = +2.5V,  V_B = -2.5V
  V_diff = V_A - V_B = +5.0V  (비트 1)

[ +10V의 강한 외부 노이즈 침투 ]
  두 선이 꼬여있어(Twisted Pair) 동일한 양의 노이즈가 두 선에 똑같이 가해짐
  V_A' = +2.5V + 10V = +12.5V
  V_B' = -2.5V + 10V = +7.5V

[ 수신 측 차동 전압 연산 ]
  V_diff' = V_A' - V_B' = (+12.5V) - (+7.5V) = +5.0V  (여전히 비트 1!)
```

두 선선이 매우 가깝게 꼬여있기 때문에 외부 노이즈는 두 선에 똑같은 크기와 극성(**동상 노이즈, Common-Mode Noise**)으로 유도됩니다.

수신 측의 차동 앰프(Op-Amp)가 $V_A - V_B$ 뺄셈 연산을 수행하는 순간 **동상 노이즈 $V_{\text{noise}}$가 수학적으로 완전히 0이 되어 소거**됩니다.
