## 1. 계층화(Layering)의 정의와 목적
복잡한 네트워크 통신 과정을 **역할과 기능에 따라 독립적인 단계(Layer)로 나눈 것**을 **계층화**라고 합니다.
컴퓨터 간 통신은 물리적인 전압 신호 전달부터 시작해 에러 체크, 주소 찾기, 전송 관리, 화면 출력까지 수많은 복잡한 작업이 동시에 일어납니다. 이를 하나의 프로그램이나 통째 구조로 만들면 관리가 불가능해집니다
### 💡 계층화의 핵심 목적
1. **모듈화(Modularity)와 유지보수성 향상:** 특정 계층에 문제가 생기거나 기술이 발전하더라도 **다른 계층에 영향을 주지 않고 해당 계층만 수정/교체**할 수 있습니다.
    - _예시:_ 랜선(1계층)을 광케이블로 바꾸거나 와이파이(무선)로 바꿔도, 웹 브라우저(7계층) 프로그램이나 HTTP 프로토콜은 아무런 코드 수정 없이 그대로 동작합니다.
2. **표준화(Standardization):** 서로 다른 제조사(Apple, 삼성, Intel 등)가 만든 장비와 소프트웨어가 **공통된 규격에 맞춰 통신**할 수 있게 해줍니다.
3. **복잡성 감소 및 구조 파악 용이:** 네트워크의 거대한 동작 흐름을 계층별로 나누어 단계적으로 이해하고 문제(트러블슈팅) 위치를 명확히 찾을 수 있습니다.

## 2. OSI 7계층 vs TCP/IP 4계층

| **OSI 7계층 (Theoretical)**      | **TCP/IP 4계층 (Practical)**                 | **역할 및 주요 기능**                            | **주요 프로토콜 및 핵심 장비**                         |
| ------------------------------ | ------------------------------------------ | ----------------------------------------- | ------------------------------------------- |
| **7. 응용 계층** _(Application)_   | **4. 응용 계층**<br>_(Application Layer)_      | 사용자 인터페이스 제공 및 네트워크 서비스 응용                | HTTP, HTTPS, DNS, SSH, FTP, SMTP            |
| **6. 표현 계층** _(Presentation)_  | ^                                          | 데이터 암호화, 압축, 문자 인코딩 변환                    | SSL/TLS, JPEG, MPEG                         |
| **5. 세션 계층** _(Session)_       | ^                                          | 응용 프로그램 간의 세션(연결) 수립, 유지, 종료              | NetBIOS, RPC                                |
| **4. 전송 계층** _(Transport)_     | **3. 전송 계층**<br>_(Transport Layer)_        | 종단간(End-to-End) 오류 제어, 흐름 제어, 포트 번호 기반 식별 | **TCP**, **UDP** / 포트 번호(Port)              |
| **3. 네트워크 계층** _(Network)_     | **2. 인터넷 계층**<br>_(Internet Layer)_        | 논리적 주소(IP) 기반 경로 설정(라우팅) 및 패킷 전송          | **IP**, ICMP, ARP / **라우터(Router)**         |
| **2. 데이터 링크 계층** _(Data Link)_ | **1. 네트워크 인터페이스**<br>_(Network Interface)_ | 물리적 매체를 통한 에러 검출, MAC 주소 기반 인접 노드 간 전송    | **이더넷(Ethernet)**, MAC 주소 / **스위치(Switch)** |
| **1. 물리 계층** _(Physical)_      | ^                                          | 비트(`0`, `1`) 데이터를 전기/빛 신호로 물리적 전송         | UTP 케이블(랜선), 광케이블, 더미 허브                    |
- **OSI 7계층 (ISO 표준):** 네트워크 구조를 가르치고 이해하기 위한 **개념적/이론적 참조 모델**
- **TCP/IP 4계층 (DoD 표준):** 실제 상용 인터넷에서 채택하여 작동하는 **실무적/실용적 프로토콜 수트**
## 3. 캡슐화(Encapsulation)와 역캡슐화(Decapsulation)
네트워크 상에서 데이터가 계층을 따라 이동할 때, 각 **계층의 제어 정보**(주소, 오류 제어 등)를 붙이거나 떼어내는 핵심 과정

| **계층 (Layer)**                              | **송신 측: 캡슐화 (Encapsulation)**                                                                | **수신 측: 역캡슐화 (Decapsulation)**                                      | **해당 계층 데이터 명칭 (PDU)**                                  |
| ------------------------------------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------- |
| **응용 계층** _(Application)_                   | 사용자 데이터 생성<br><br>`[ Data ]`                                                                 | 헤더가 완전히 제거된 순수 데이터 수신<br><br>`[ Data ]`                             | **Data / Message**                                      |
| **전송 계층** _(Transport)_                     | 4계층 헤더(포트 번호 등) 추가<br><br>`[L4 Header]` + `[ Data ]`                                         | 4계층 헤더 해석 및 제거 후 응용 계층으로 전달<br><br>`[ Data ]`                       | **Segment** (TCP) /<br><br>  <br><br>**Datagram** (UDP) |
| **인터넷 계층** _(Internet)_                     | 3계층 헤더(IP 주소 등) 추가<br><br>`[L3 Header]` + `[L4 H]` + `[ Data ]`                              | 3계층 헤더 해석 및 제거 후 전송 계층으로 전달<br><br>`[L4 H]` + `[ Data ]`            | **Packet**                                              |
| **네트워크 인터페이스**<br><br>_(Network Interface)_ | 2계층 헤더(MAC 주소) & 트레일러(FCS) 추가<br><br>`[L2 Header]` + `[L3 H][L4 H][ Data ]` + `[L2 Trailer]` | 2계층 헤더/트레일러 해석 및 오류 검출 후 제거<br><br>`[L3 H]` + `[L4 H]` + `[ Data ]` | **Frame**                                               |
| **물리적 전송** _(Physical Media)_               | 1계층: 비트 데이터(`0`, `1`)를 **전기/빛 신호로 변환하여 전송** ➔                                                | ➔ 1계층: 수신한 전기/빛 신호를 **비트 데이터(`0`, `1`)로 복원**                        | **Bits**                                                |
송신측에서는 응용 계층에서 물리 계층으로, 수신측에서는 물리 계층에서 다시 응용 계층으로 데이터가 전송된다.
