### 핵심: '기준점(Ground)'이 흔들리는 문제 때문에 탄생했습니다!
그냥 전선 한 가닥에 $0\text{V}$와 $5\text{V}$를 쏘면 되지, 왜 굳이 **선 두 가닥을 한 쌍**으로 묶어서 한쪽엔 $+V$, 다른 쪽엔 $-V$를 쏠까요?
단일 선 방식(Single-ended)의 치명적인 약점은 **'외부 노이즈'** 때문입니다.
#### 1. 기존 방식 (선 1가닥 + 접지): 외부 노이즈에 치명적
- 송신기가 비트 `1`을 뜻하는 $5\text{V}$를 쐈습니다.
- 중간에 번개가 치거나 모터가 돌아가서 케이블에 **$+2\text{V}$짜리 전기 노이즈**가 침투했습니다.
- 수신기에는 $5 + 2 = \mathbf{7\text{V}}$가 도착합니다.
- 수신기는 이게 `1`인지, 노이즈가 낀 이상한 신호인지 헷갈리거나 데이터가 깨집니다.
#### 2. 차동 신호 방식 (Differential Signaling, 선 2가닥): 노이즈 완벽 방어
차동 신호는 절대적인 전압 수치($5\text{V}$)를 보는 게 아니라, "두 전선 사이의 '전압 차이(Difference)'"만 보는 방식입니다.
데이터 비트 하나를 보낼 때 전선 두 가닥($A$선, $B$선)을 사용합니다.
- **비트 `1`을 보낼 때:**
    - $A$선에는 $+2.5\text{V}$를 쏩니다.
    - $B$선에는 $-2.5\text{V}$를 쏩니다.
    - 수신기는 $(A - B)$ 전압 차이를 계산합니다:
        $$+2.5\text{V} - (-2.5\text{V}) = \mathbf{+5\text{V}} \quad \rightarrow \text{'1'로 인식!}$$
        
- **비트 `0`을 보낼 때:**
    - $A$선에는 $-2.5\text{V}$를 쏩니다.
    - $B$선에는 $+2.5\text{V}$를 쏩니다.
    - 수신기는 $(A - B)$ 전압 차이를 계산합니다:
        $$-2.5\text{V} - (+2.5\text{V}) = \mathbf{-5\text{V}} \quad \rightarrow \text{'0'로 인식!}$$
###  차동 신호에 노이즈가 침투하면 어떻게 될까요?

랜선은 두 선이 바짝 붙어서 꼬여있기 때문에(Twisted Pair), 외부에서 노이즈가 침투하면 **두 선에 똑같은 크기의 노이즈($+2\text{V}$)가 똑같이 전달**됩니다.

- **비트 `1` 전송 중 $+2\text{V}$ 노이즈 침투:**
    - $A$선 실제 전압: $+2.5\text{V} + \mathbf{2\text{V}} = +4.5\text{V}$
    - $B$선 실제 전압: $-2.5\text{V} + \mathbf{2\text{V}} = -0.5\text{V}$
        
- **수신기에서의 계산 $(A - B)$:**
    $$(+4.5\text{V}) - (-0.5\text{V}) = \mathbf{+5\text{V}}$$

**신호 전압이 노이즈 때문에 출렁거렸음에도 불구하고, 두 선의 전압을 빼버리니 노이즈($+2\text{V}$)가 뺄셈 과정에서 알아서 증발(상쇄)해 버립니다!**
