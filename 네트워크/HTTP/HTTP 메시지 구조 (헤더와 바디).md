**네트워크 상에서 클라이언트와 서버가 교환하는 HTTP 메시지(요청 및 응답 메시지 모두 포함)는 논리적으로 두 가지 핵심 구역으로 분할되어 전송됨**

# 1. HTTP 헤더 (Header): 제어 정보 및 메타데이터
- **개념**: 원활한 데이터 통신 및 해석을 위한 메타데이터를 포함
- **역할**: 본문 데이터를 어떻게 처리하고 해석할지에 대한 제어 정보와 송수신 시스템간의 상태 정보 교환
- **주요 포함 정보**:
	- **콘텐츠 타입(Content-Type)**: 전송되는 데이터의 미디어 형식 (예: `text/html`, `application/json`, `image/jpeg`)
	- **송수신 시스템 정보**: 클라인트의 브라우저 및 운영체제 정보(`User-Agent`) 응답을 생성한 서버 소프트웨어 정보 (`Server`)
	- **인증 및 세션 정보**: 사용자 식별 및 접근 권한을 위한 토큰 (예: `Authorization`, `Cookie`)
	- **기타**: 메시지 생성 시각 (`Date`), 본문의 크기 (`Content-Length`)

# 2. HTTP 바디 (Body): 페이로드
- **개념:** 우편물의 '편지지 본문'에 해당하는 영역으로, 통신을 통해 실질적으로 전달하고자 하는 핵심 데이터(Payload)가 위치하는 공간입니다.
- **주요 역할:** 요청(Request) 시에는 서버가 데이터베이스 등에 반영해야 할 입력값을 전달하고, 응답(Response) 시에는 클라이언트의 화면을 구성할 결과물을 반환합니다.
- **주요 포함 정보:** 클라이언트가 전송하는 로그인 폼 데이터(ID/Password), 서버가 반환하는 HTML 소스 코드, 비동기 통신을 위한 JSON 포맷 데이터 등.
- **특이 사항:** 서버의 상태를 변경하지 않고 자원의 단순 조회를 목적으로 하는 **GET 요청**의 경우, 별도의 데이터를 서버로 전송할 필요가 없으므로 일반적으로 HTTP 바디(Body) 영역이 생략되어 전송됩니다.
