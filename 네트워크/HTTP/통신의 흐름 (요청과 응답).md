# 웹 통신의 기본 구조: 클라이언트-서버 아키텍처
웹상의 데이터 교환은 클라이언트와 서버간의 상호작용을 기반으로 이 과정은 요청과 응답의 절차를 따른다.
- **클라이언트 (Client)** : 웹 브라우저와 같이 사용자가 네트워크를 통해 서버 시스템에 접속하여 데이터를 요구하는 소프트웨어 또는 단말기를 지칭. 통신의 주체로서 먼저 연결을 시도한다.
- **서버 (Server)**: 네트워크 상에서 클라이언트의 연결을 대기하며, 요청이 수신되었을 때 그에 상응하는 정보(웹 페이지, 데이터)나 서비스를 제공하는 시스템

# 통신의 흐름: 요청(Request)과 응답(Response)
- **요청 (Request):** 클라이언트가 특정 자원(Resource)이나 서비스를 서버에 요구하는 행위입니다. 예를 들어, 사용자가 브라우저 주소창에 `google.com`을 입력하고 접속을 시도하는 것은, 클라이언트가 지정된 서버를 향해 "초기 화면을 구성하는 HTML 문서를 전송해 달라"는 내용의 HTTP 요청 메시지(HTTP Request Message)를 발송하는 과정입니다.

- **응답 (Response):** 서버가 수신된 클라이언트의 요청을 해석 및 처리한 후, 그 결과물을 반환하는 과정입니다. 서버는 요청받은 데이터(HTML 문서, 이미지, JSON 데이터 등)를 정상적으로 찾았거나 처리 완료했을 경우, 이를 **HTTP 응답 메시지(HTTP Response Message)** 형태로 캡슐화하여 클라이언트에게 전송합니다.
