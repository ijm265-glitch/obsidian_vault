# HTTP 메서드

|  **메서드**   | **역할 **        | **설명 및 예시**                                                                                  |
| :--------: | -------------- | -------------------------------------------------------------------------------------------- |
|  **GET**   | 조회 (Read)      | 서버에서 데이터를 가져올 때 사용합니다. 상태를 변경하지 않습니다.<br><br>_(예: 게시글 목록 읽기, 상품 정보 보기)_                      |
|  **POST**  | 생성 (Create)    | 서버에 새로운 데이터를 추가할 때 사용합니다. 요청 본문(Body)에 데이터를 담아 보냅니다.<br><br>_(예: 회원가입, 새로운 게시글 작성)_          |
|  **PUT**   | 전체 수정 (Update) | 존재하는 데이터를 **완전히 덮어씌워 수정**할 때 사용합니다. 데이터가 없으면 새로 생성하기도 합니다.<br><br>_(예: 내 프로필 사진 및 정보 전체 변경)_ |
| **DELETE** | 삭제 (Delete)    | 서버에서 특정 데이터를 삭제할 때 사용합니다.<br><br>_(예: 작성한 댓글 삭제, 회원 탈퇴)_                                     |

# 상태코드
- 서버가 클라이언트의 요청을 처리한 후, 결과를 알려주는 3자리 숫자
	- 2xx : 요청을 성공적으로 받았고 처리함
	- 4xx : 클라이언트 오류 - 클라이언트가 잘못된 요청을 함 (오타, 권한 없음 등)
	- 5xx : 서버 내부에서 문제가 발생함 (코드 버그, DB 다운 등)

| **상태 코드**                     | **의미**   | **발생하는 상황 (원인)**                                                       |
| ----------------------------- | -------- | ---------------------------------------------------------------------- |
| **200 OK**                    | 성공       | 가장 긍정적인 응답입니다. GET, PUT 등의 요청이 정상적으로 완료되었을 때 반환됩니다.                    |
| **201 Created**               | 생성됨      | POST 요청이 성공하여, 서버에 새로운 데이터가 무사히 만들어졌을 때 반환됩니다.                         |
| **307 Temporary Redirect**    | 주소 임시 이동 | 결제 시스템이나 특정 API 기능을 잠시 점검하는 동안, 임시 점검 페이지나 백업 서버 주소로 요청을 돌려놓을 때 사용합니다. |
| **400 Bad Request**           | 잘못된 요청   | 클라이언트가 필수 데이터를 빼먹었거나, 형식에 맞지 않는 데이터를 보냈을 때 발생합니다.                      |
| **401 Unauthorized**          | 인증 필요    | 로그인을 하지 않은 상태에서 회원 전용 페이지나 데이터에 접근하려고 할 때 발생합니다.                       |
| **404 Not Found**             | 찾을 수 없음  | 요청한 URL(주소)이나 데이터가 서버에 존재하지 않을 때 뜹니다. (예: 삭제된 게시글)                     |
| **500 Internal Server Error** | 서버 내부 에러 | 사용자의 요청은 맞았으나, 서버 내부의 파이썬 코드나 데이터베이스에서 오류가 났을 때 발생합니다.                 |
