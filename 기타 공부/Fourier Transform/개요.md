## 📌 Phase 1. 푸리에 해석의 수학적 기초 (Continuous Realm)

1. **선형대수학과 기저(Basis)의 직교성**
    
    - 벡터 공간에서의 내적(Inner Product)과 직교(Orthogonality)
        
    - 함수 공간에서의 내적: $\langle f, g \rangle = \int f(t) \bar{g}(t) dt$
        
    - 복소 지수 함수 $e^{j\omega t}$ 기저들의 직교 집합 이해
        
2. **푸리에 급수 (Fourier Series)**
    
    - 주기 신호(Periodic Signal)를 삼각함수/복소 지수 함수의 합으로 분해
        
    - 오일러 공식($e^{j\theta} = \cos\theta + j\sin\theta$)과 복소 푸리에 급수
        
3. **연속 푸리에 변환 (Continuous Fourier Time Transform, FT)**
    
    - 비주기 신호로의 확장 (주기 $T \to \infty$)
        
    - 시간 영역과 주파수 영역 간의 쌍대성(Duality) 및 에너지 보존(파세발 정리, Parseval's Theorem)
        

## 📌 Phase 2. 이산 신호와 DFT (Discrete Realm)

컴퓨터는 연속 신호를 다룰 수 없습니다. 신호를 잘라(Sampling) 디지털 데이터로 만든 후 DFT로 넘어가야 합니다.

1. **표본화 정리 (Sampling Theorem & Nyquist Rate)**
    
    - 연속 신호의 이산화(Sampling) 및 임펄스 기차(Impulse Train) 곱셈
        
    - 주파수 앨리어싱(Aliasing) 발생 원인과 나이퀴스트 주파수 ($f_s / 2$)
        
2. **이산 시간 푸리에 변환 (DTFT) vs 이산 푸리에 변환 (DFT)**
    
    - **DTFT:** 시간은 이산(Discrete), 주파수는 연속(Continuous)
        
    - **DFT:** 주파수 영역까지 $N$개로 이산화(Discretization)한 변환
        
3. **DFT의 수학적 정의와 행렬 표현**
    
    - $X[k] = \sum_{n=0}^{N-1} x[n] W_N^{kn}$ (단, $W_N = e^{-j\frac{2\pi}{N}}$ : 회전인자, Twiddle Factor)
        
    - DFT를 $N \times N$ 복소 반데르몽드(Vandermonde) 행렬 곱으로 바라보기
        
    - **DFT의 시간 복잡도가 $O(N^2)$인 이유** 직접 계산해 보기
        

## 📌 Phase 3. FFT 알고리즘의 핵심 (Cooley-Tukey Algorithm)

$O(N^2)$인 DFT를 $O(N \log_2 N)$으로 획기적으로 줄인 Cooley-Tukey FFT의 분할 정복(Divide and Conquer) 메커니즘을 파헤칩니다.

1. **회전인자(Twiddle Factor) $W_N^{kn}$의 대칭성과 주기성**
    
    - 대칭성: $W_N^{k + N/2} = -W_N^k$
        
    - 주기성: $W_N^{k + N} = W_N^k$
        
2. **시간 솎음(Decimation-in-Time, DIT) Cooley-Tukey 알고리즘**
    
    - $N$개 입력을 짝수 인덱스($x[2m]$)와 홀수 인덱스($x[2m+1]$)로 분할
        
    - 크기 $N$의 DFT 1개를 크기 $N/2$의 DFT 2개로 재귀적으로 줄이는 과정 수학적 도출
        
3. **나비 연산 (Butterfly Diagram)과 비트 반전 (Bit Reversal)**
    
    - 나비 연산 구조(Butterfly Structure)의 이해와 덧셈/곱셈 연산 횟수 계산
        
    - In-place 연산을 위한 비트 반전 재배치(Bit Reversal Permutation) 알고리즘
        
4. **C++ 또는 Python으로 Radix-2 DIT FFT 직접 구현하기**
    
    - 라이브러리(`numpy.fft`나 `fftw`)를 쓰지 않고, 2차원 배열과 재귀/반복문만으로 FFT 알고리즘 코딩해 보기
        

## 📌 Phase 4. 고급 응용 및 실전 신호처리 이슈

FFT를 현실 오디오/신호 데이터에 적용할 때 발생하는 한계와 이를 극복하는 테크닉입니다. (질문자님이 이전에 논의하신 주제들과 직결되는 파트입니다.)

1. **창 함수 (Windowing)와 스펙트럼 누설 (Spectral Leakage)**
    
    - 유한한 길이의 데이터를 잘라낼 때 발생하는 사각창(Rectangular Window)의 기브스 현상
        
    - Hanning, Hamming, Blackman 창 함수를 통한 불연속면 완화
        
2. **시간-주파수 해상도 트레이드오프 (Uncertainty Principle)**
    
    - Window Size($N$)가 커질 때: 주파수 해상도 증가 ($\Delta f \downarrow$), 시간 해상도 감소
        
    - Window Size($N$)가 작을 때: 시간 해상도 증가, 주파수 해상도 감소
        
3. **STFT (단시간 푸리에 변환)와 Overlap-Add (OLA)**
    
    - 연속 오디오의 시간 흐름에 따른 주파수 변화 추적
        
    - STFT 후 IFFT 복원을 위한 위상 보정(Phase Vocoder) 및 윈도우 겹침 조건(COLA Condition)
