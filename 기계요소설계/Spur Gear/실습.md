import numpy as np
import math

def calc_spur(TOOTH: int, MODULE: int, PRESSURE_ANGLE: int = 20) -> dict:
    """
    spur gear 설계에 필요한 값을 계산합니다.
    PCD : Pitch Circle Diameter
    BCD : Base Circle Diameter
    ACD : Adendum Circle Diameter
    DCD : Dedendum Circle Diameter
    """
    Z_min = 2 / (np.sin(np.radians(PRESSURE_ANGLE)) ** 2)

    if TOOTH < Z_min:
        raise ValueError(f"설정한 잇수가 최소 잇수({math.ceil(Z_min)}개)보다 작습니다.")
        
    PCD = MODULE * TOOTH
    BCD = PCD * np.cos(np.pi/180*PRESSURE_ANGLE)
    CIRCULAR_PITCH = np.pi * PCD / TOOTH
    ACD = PCD + 2 * MODULE
    DCD = PCD - 2.5 * MODULE
    info = {
        "PCD" : PCD,
        "BCD" : BCD,
        "CIRCULAR_PITCH" : CIRCULAR_PITCH,
        "ACD" : ACD,
        "DCD" : DCD
    }
    return info


print(calc_spur(18, 2, 20))

PC, BC, AC, DC를 전부 그리고 BC에서부터 2.5도 각도로 점을 배치하여 AC까지 involute curve가 그려지도록 그림을 그린다.

base circle에서 시작하므로 dedendum circle까지 원의 중심을 향해 선을 긋는다.


원 한 바퀴가 360도이고 이빨이 Z개 있으면 이빨과 이골이 차지하는 전체 각도를 원주 피치각이라고 한다
$$\text{원주 피치각} = \frac{360^\circ}{z}$$
표준 평기어에서는 피치원 상에서 이빨의 두꼐와 이골의 길이가 `1:1`로 같음
즉 이빨 1개가 차지하는 각도는 전체 원주 피치각의 절반이 됨
$$\text{이빨 두께 각도} = \frac{360^\circ}{z} \times \frac{1}{2} = \frac{180^\circ}{z}$$
이빨의 중심축을 그리려고 하는 것이기 때문에 이빨 두께의 절반을 가야 중심축을 만들 수 있음 
$$\text{대칭축 각도} = \text{이빨 두께 각도} \times \frac{1}{2} = \frac{180^\circ}{z} \times \frac{1}{2} = \mathbf{\frac{90^\circ}{z}}$$
