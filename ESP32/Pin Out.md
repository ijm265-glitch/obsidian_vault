5V (5Volts / VIN) : Micro USB포트를 통해 들어오는 5V 전원을 출력
3V3 (3.3Volts) : Micro USB포트를 통해 들어오는 5V 전원을 레귤레이터로 변환하여 3.3V를 출력
SVP, SVN (Sensor Voltage Positive, Negative) : 보드 내부적으로 미세한 아날로그 신호를 읽기 위해 섥계된 핀 - 차동 전압으로 측정
TXD0 (Transmit Data 0) : 데이터를 송신
RXD0 (Receive Data 0) : 데이터를 수신
SD0, SD1, SD2, SD3 (Serial Data 0, 1, 2, 3)  : ESP32칩의 플래시 메모리 전용 통신선
