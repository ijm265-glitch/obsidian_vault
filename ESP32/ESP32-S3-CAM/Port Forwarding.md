
- 하나의 공인 IP를 사용하는 공유기 내부에는 여러 기기(PC, ESP32, 스마트폰 등)가 사설 IP(예: `192.168.0.X`)를 할당받아 연결됨
        
- 외부 망에서는 공유기 내부의 특정 기기로 직접 접근할 수 없음
        
- 포트포워딩은 외부에서 들어오는 특정 **포트(Port) 번호** 요청을 내부 네트워크의 특정 기기(사설 IP 및 포트)로 일대일 매핑하여 연결해 주는 기술
        
- **작동 메커니즘**
    
    1. 외부 사용자(스마트폰/외부 PC)가 DDNS 주소와 포트 번호(예: `xxx.iptime.org:8080`)로 접속 요청을 보냄
        
    2. 요청이 공유기의 공인 IP 대문에 도착하면, 공유기는 요청된 외부 포트 번호(`8080`)를 확인함
        
    3. 공유기는 미리 설정된 포트포워딩 테이블을 조회하여 해당 포트(`8080`)가 어떤 내부 기기(`192.168.0.XX`)의 어떤 포트(`80`)와 연결되어 있는지 확인함
        
    4. 공유기가 들어온 신호 패킷의 목적지를 해당 내부 기기(ESP32 등)로 우회(Forwarding)시켜 전달함
        
- **결과**
    
    - 타깃 기기(ESP32 등)가 켜져 있고 정상 작동 중이라면, 외부에서도 내부망의 특정 기기 서비스(웹 서버, 카메라 스트리밍 등)에 접속 가능
        
    - 타깃 기기가 꺼져 있거나 서비스가 중단된 경우, 공유기가 신호를 전달하더라도 응답을 받지 못해 **시간 초과(ERR_TIMED_OUT)** 오류 발생
        
- **ipTime 설정 경로**
    
    - ipTime 관리자 페이지 접속 $\rightarrow$ NAT/Routing $\rightarrow$ Port Forwarding에서 규칙 추가 (내부 IP 주소, 외부 포트, 내부 포트 지정)
