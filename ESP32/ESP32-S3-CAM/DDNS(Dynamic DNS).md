[[5.1 DNS 작동 원리]]

일반적으로 우리가 사용하는 DNS서버는 naver.com등을 입력하면 고정된 IP 주소를 반환하여 통신이 가능하도록 함

DDNS 서버는 IP 주소가 변경되었으면 이를 즉각적으로 반영함
1. 통신사 변동, 공유기 재부팅 등으로 공인 IP가 변경됨
2. 공유기는 이전 공인 IP 정보를 가지고 공인 IP가 변경된 것을 감지하여 ipTIME DDNS 서버로 공인 IP가 변경되었다는 정보를 전송함
3. DDNS 서버는 이를 즉시 갱신함
4. 따라서 외부에서 글자 주소를 입력하면 변경된 공인 IP를 반환하게 되어 통신이 가능
