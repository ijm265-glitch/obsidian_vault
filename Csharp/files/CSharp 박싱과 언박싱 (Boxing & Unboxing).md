## 1. 박싱(Boxing)이란?

**값 타입(Value Type)** 데이터를 참조 타입(Reference Type, 주로 `object` 또는 인터페이스)으로 변환하는 과정입니다.

- **메모리 동작:**
    
    1. **스택(Stack)** 영역에 있던 값 타입 데이터를 **힙(Heap)** 영역에 새로 메모리를 할당하여 복사합니다.
        
    2. 스택에는 힙 영역에 생성된 객체의 **주소(참조)값**이 저장됩니다.
        
- **특징:** 암시적(Implicit) 형변환이 가능합니다.
    
```Cs
int num = 123;       // 값 타입 (스택 메모리)
object obj = num;    // 박싱(Boxing) 발생! (힙 메모리에 새 공간 할당 후 값 복사)
```

## 2. 언박싱(Unboxing)이란?

힙 영역에 **박싱되어 있는 참조 타입 객체**로부터 **원래의 값 타입 데이터**를 다시 추출하는 과정입니다.

- **메모리 동작:**
    
    1. 힙 영역의 객체가 해당 값 타입이 맞는지 **타입 검사**를 수행합니다.
        
    2. 힙 메모리의 값을 **스택(Stack)** 영역으로 복사해 옵니다.
        
- **특징:** 명시적(Explicit) 캐스팅 연산자 `(타입)`를 반드시 사용해야 합니다.

```Cs
object obj = 123;     // 박싱된 상태
int num = (int)obj;   // 언박싱(Unboxing) 발생! (명시적 캐스팅 필수)
```
