모션제어 모듈(Motion Controller Module)은 일반적인 1축 단독 PTP(Point-to-Point) 위치결정을 넘어, **수십 축의 서보 모터를 고속 실시간 산업용 이더넷(EtherCAT)으로 묶어 완벽히 일치된 타이밍으로 동기화·다축 보간 제어**하기 위해 사용하는 전용 컨트롤러 모듈입니다.

**왜 사용하는가?**

- **기존 위치결정 모듈의 한계 극복:** 펄스 출력형 위치결정 카드는 축마다 수십 가닥의 배선이 필요하고 최대 제어 축 수(2~8축)가 적습니다. 반면 모션제어 모듈은 단 하나의 랜선(EtherCAT Daisy-Chain)으로 최대 **32개 실축 서보**를 직렬 연결해 배선 공수를 획기적으로 줄입니다.
    
- **복잡한 다축 동기 및 궤적 연산 부하 분리:** 원호 보간, 헬리컬(나선) 보간, 전자 캠(E-Cam), 전자 기어(E-Gear) 같은 복잡한 기하학적 궤적 연산은 삼각함수와 미적분이 연속으로 들어갑니다. 메인 PLC CPU 대신 **모션 전용 독립 CPU**가 이를 전담 처리하여 시퀀스 스캔 타임 지연을 방지합니다.
    
- **통합 엔지니어링 및 개방성:** EtherCAT 표준(CoE: CANopen over EtherCAT / CiA402)을 따르므로 LS 서보뿐만 아니라 타사 서보 드라이브, 스테핑 드라이브, 리모트 I/O까지 한 네트워크에 묶어 제어할 수 있습니다.
    

**어떤 방식으로 작동하는가?**

1. **상위 지령 수신 (PLC CPU $\leftrightarrow$ 모션 모듈):**
    
    - 메인 PLC CPU가 래더나 ST 언어로 된 표준 모션 펑션 블록(PLCopen 표준: `MC_MoveAbsolute`, `MC_CamIn` 등)을 실행하거나 공유 메모리(2,048워드)를 통해 목표 명령을 내립니다.
        
2. **실시간 궤적 생성 (모션 모듈 내부 연산):**
    
    - 모션 모듈 내부 프로세서가 각 축의 가감속(S자형, 사다리꼴), 속도, 그리고 다축 간의 관계(보간, 캠 곡선)를 **1ms 이하(수백 $\mu\text{s}$ 단위)의 고정 주기**마다 연산합니다.
        
    - 계산 결과로 매 주기마다 각 축이 도달해야 할 미세 순간 목표 위치(`Target Position`)를 만듭니다.
        
3. **EtherCAT 동기 프레임 전송 (모션 모듈 $\rightarrow$ 서보 드라이브):**
    
    - 분산 클럭(Distributed Clocks, DC) 기술을 사용하여 네트워크에 물린 수십 대의 서보 드라이브 클럭을 나노초 단위로 동기화합니다.
        
    - 1ms 주기마다 모든 드라이브에 위치 지령을 동시에 전달하고, 엔코더 피드백 위치를 동시에 회수합니다.
        

**사양표로 보는 주요 기능 (뭘 할 수 있는가?)**

- **축 그룹 운전 및 다차원 보간 (Interpolation):**
    
    - 여러 축을 하나의 그룹으로 묶어 직선 보간(2D/3D), 원호 보간(원/호 그리기), 헬리컬 보간(원통 나선 가공)을 수행합니다. 디스펜싱(본딩 도포기), CNC 절삭, 갠트리 로봇 궤적 추종에 쓰입니다.
        
- **전자 캠(Electronic Cam) 제어:**
    
    - 과거 기계식 편심 캠축을 소프트웨어 테이블(32개 캠 블록 지원)로 대체합니다. 마스터 축(가상축 또는 실축 컨베이어)의 이동량에 맞춰 슬레이브 축이 비선형적으로 감속/가속/정지하며 작업하는 로터리 나이프, 비행 절단기(Flying Shear), 고속 포장기 구현이 가능합니다.
        
- **가상축(Virtual Axis, 4축 지원):**
    
    - 물리적인 모터 없이 메모리 상에서만 일정한 속도/가속도로 회전하는 가상의 기준축을 만듭니다. 이 가상축에 여러 개의 실축을 종속(Slave)시켜 기계적 오차 없이 완벽한 다축 동기 운전을 구현합니다.
        
- **내장 고속 엔코더 입력 (2채널, 최대 500kpps):**
    
    - 외부 라인 마스터 엔코더 신호를 직접 받아 컨베이어 속도를 실시간 추종(Conveyor Tracking)하는 픽앤플레이스 작업을 지원합니다.
        
- **전용 설정 툴 (`XG-PM`):**
    
    - 서보 드라이브 자동 검색(Auto-connect), 캠 프로파일 커브 작도,
