[[로터리 엔코더]](회전 센서)가 회전량, 속도, 방향, 원점을 전달하기 위해 내보내는 3가지 기본 펄스 출력 신호
**A상**
- 모터 축이 회전할 때 일정 간격으로 구형파 출력
- 펄스의 총 개수로 이동거리를 계산하고 단위 시간단 펄스 수로 회전 속도 계산

**B상**
- A상과 위상이 $\frac{\pi}{2}$ 차이나도록 물리적으로 구성되어있음

**Z상**
- 모터 축이 정확히 1회전할 때 마다 펄스를 생성

**체배 (Multiplication)**
A상과 B상의 90도 위상차를 통해 신호의 상승 에지와 하강에지를 카운트 하여 Resolution을 증가시킬 수 있음
1회전에 슬릿이 1000개 있는 1000PPR 엔코더라고 할 때 
- 1체배: A상의 상승 에지만 계수
	- $360^\circ / 1000 = 0.36^\circ$ 의 분해능을 가짐
- 2체배: A상의 상승, 하강 에지를 계수
	- $360^\circ / 2000 = 0.18^\circ$ 의 분해능을 가짐
- 4체배: A상과 B상의 상승, 하강 에지를 계수
	- $360^\circ / 4000 = 0.09^\circ$ 의 분해능을 가짐
