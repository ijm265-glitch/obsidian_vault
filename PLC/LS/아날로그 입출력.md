## 입력

일반적으로 0 ~ 10V or 0 ~ 20mA의 입력을 받을 수 있음

모듈을 연결하고 IO동기화를 수행한 다음 U디바이스로 접근하여 조작 가능

![[Pasted image 20260923120715.png]]



## 출력

0 ~ 10V or 0 ~ 20mA 출력 가능

![[Pasted image 20260923121525.png]]

특이사항으로 출력 플래그를 True로 한 다음에 출력이 가능 
하위비트 4개중 활성화 할 부분을 결정하여 mov로 복사한다
`ex : h0004 = 0b 0000 0000 0000 0100 으로서 0, 2, 3 채널의 출력은 차단하고 1채널의 출력을 가능하게 한다.`
