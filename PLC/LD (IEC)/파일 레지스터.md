**1. 메모리 성격 (비휘발성)**
- **RAM (`D`, `M` 영역 등)**: 읽기/쓰기가 빠르지만 전원이 꺼지면 데이터가 사라짐 (휘발성)
- **Flash Memory (`R` 영역)**: 전원이 차단되어도 데이터가 유지됨 (비휘발성 / 레시피, 설정값, 생산 이력 보관용)

**2. 뱅크(Bank)의 개념**
- `R00000` ~ `R32767` (32,768 워드) 크기의 메모리 블록(서랍장) 1개를 '1개 뱅크'라 함
- CPU 사양에 따라 뱅크가 복수로 존재할 수 있음
- 이 경우 뱅크를 설정하여 데이터를 저장할 수 있음
- `RSET 0` : 0번 뱅크를 선택함, 이 상태에서 `MOV Value R0`를 하면 0번 뱅크의 R0에 값을 저장함
- 이 상태에서 `RSET 1`을 하면 1번 뱅크를 선택하고 `MOV Value R0`를 하면 1번 뱅크의 R0에 값을 저장하며 0번 뱅크의 R0와 1번 뱅크의 R1은 독립적임
    
**3. 뱅크 구성 예시**
- **0번 뱅크**: `R00000` ~ `R32767` (32,768 워드)
- **1번 뱅크**: `R00000` ~ `R32767` (32,768 워드)
- **결과**: 동일한 `R` 주소를 사용하더라도 지정된 뱅크 번호에 따라 실제 가리키는 플래시 메모리 물리 공간이 달라지며, 이를 통해 전체 메모리 용량을 확장

**4. 뱅크를 구성하지 않고 연속된 메모리 주소로 활용**
- ZR을 사용하여 연속된 메모리로 취급할 수 있음
- 예를 들어 2뱅크 파일 레지스터 사양의 PLC라면 ZR0 ~ ZR65335까지의 주소 공간을 가지게 됨
