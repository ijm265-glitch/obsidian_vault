**1. 제어 신호 핀 (Control Signals - BOOL)**
- **EN (Enable)**: **동작 허용** — 블록을 실행시키기 위한 입력 조건 신호 (ON일 때 블록 동작)
- **ENO (Enable Output)**: **동작 완료 출력** — 블록의 연산이 에러 없이 정상 완료되었음을 나타내는 출력 신호

**2. 데이터 핀 (Data Pins - ANY)**
- **IN (Input)**: **데이터 입력** — 연산에 사용될 원본 데이터나 메모리 주소 (`D0000`, 정수 등)
- **OUT (Output)**: **데이터 출력** — 연산 결과가 저장될 메모리 주소
