## 출력
### LIMIT: 출력을 범위안으로 제한하는 함수
- `LIMIT 입력값 상한값 하한값 출력값` 
- 입력값이 상한값보다 같거나 작고 하한값보다 같거나 크다면 입력값은 출력값 그대로를 유지한다
- 입력값이 상한값보다 크면 출력값은 상한값이 된다
- 입력값이 하한값보다 작다면 출력값은 하한값이 된다.

### SCAL: 입력값을 특정한 범위의 값으로 Scaling 하는 함수
- `SCAL 입력값 입력값범위상한 출력값범위상한 출력값`
- 입력값범위상한과 연속되는 상위의 디바이스에는 입력값범위하한의 값이, 출력값범위상한과 연속되는 상위의 디바이스에는 출력값범위하한의 값이 있어야 한다.
	- ex). `SCAL 30 D0 D2 D4`
	- 해당 입력값을 0~100구간에서 0~10구간으로 출력하고 싶다면
	- `D0 := 100; D1 := 0, D2 := 10, D3 := 0`으로 값을 설정한다.

### DATERD: 현재 시간을 읽어오는 함수
- `DATERD D0`
- BCD 형태로 반환한다.

| b15~b8 | b7~b0 |     |
| ------ | ----- | --- |
| 월      | 년     | D0  |
| 시      | 일     | D1  |
| 초      | 분     | D2  |
| 백년     | 요일    | D3  |
요일은 `{0: 일요일, 1: 월요일, ..., 6: 토요일}` 로 구성되어 있음

## 분기
### JMP: 렁을 실행하지 않고 넘어가는 함수
- `JMP SKIP_RING`
- 상기 함수가 실행되면 SKIP_RING이 있는 레이블로 넘어가 SCAN을 이어간다. 
- 주의사항: 레이블을 함수의 위에 배치하면 레이블에서 스캔을 진행하면서 내려가다가 다시 JMP를 하기 때문에 무한 루프가 발생하여 오류가 발생한다.


### CALL, SBRT, RET
`CALL SBRT1`
- SubRoutine을 호출하는 함수
- SBRT1이라는 이름의 SubRoutine을 실행하도록 하고 있다.
- END밑에 작성된 SubRoutine을 호출하여 실행하도록 할 때 사용
 `SBRT SBRT1`
- 이 함수 아래에 작성된 것이 SBRT1이라는 이름의 SubRoutine임을 나타내기 위해 사용하는 함수
`RET`
- SubRountine을 끝내기 위해 사용하는 함수로 Return임
- SubRoutine을 호출한 CALL함수로 렁을 되돌린다.
- 이 때 여전히 CALL함수가 실행상태라면 다시 SBRT1을 실행한다.
