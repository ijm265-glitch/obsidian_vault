`IF, CASE`
## IF문
```
IF Val1 <= 10 THEN
	Result := 10;

END_IF;

// 조건 Val1 <= 10이 참이면 Result에 10의 값을 할당
```

```
IF Val1 <= 10 THEN
	Result := 10;
ELSE
	Result := 20;
END_IF;

// 조건 Val1 <= 10이 참이면 Result에 10의 값을 할당
// 아니면 Result에 20의 값을 할당
```

```
IF Val1 <= 10 THEN
	Result := 10;

ELSIF Val1 <= 20 THEN
	Result := 20

ELSE
	RESULT := 30;

END_IF;

// 조건 Val1 <= 10이 참이면 Result에 10의 값을 할당
// 위 조건을 만족하지 않으면서 Val1 <= 20 조건을 만족하면 Result에 20을 할당
// 모든 조건을 만족하지 않으면 RESULT에 30을 할당
```

## CASE문
```
CASE Val1 OF 
	1 : Result := 10 ; 
	2..5 : Result := 20 ; 
	7, 10 : Result := 30 ; 

ELSE 
	Result := 40 ; 

END_CASE ;

// Val1의 값이 1이면 Result에 10 할당
// 2와 5 사이의 값이면 Result에 20을 할당
// 7 또는 10 사이의 값이면 Reuslt에 30을 할당
// 그 어떤 것에도 해당하지 않는ㄷ면 Result에 40을 할당
```
