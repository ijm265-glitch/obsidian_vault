## 메모리 할당 
### 1. 위치 정보 (두 번째 문자: 데이터를 저장할 구역)

데이터가 PLC 내의 어느 '영역(공간)'에 저장되는지를 나타냅니다.

- **`I` (Input - 입력):** 외부에서 PLC로 들어오는 물리적인 입력 신호입니다. (예: 푸시 버튼, 센서 신호)
    
- **`Q` (Output - 출력):** PLC에서 외부로 내보내는 물리적인 출력 신호입니다. (예: 램프, 모터 구동 신호)
    
- **`M` (Internal Memory - 내부 메모리):** 물리적인 입출력이 아닌, 프로그램 내부에서 계산이나 상태를 임시로 저장하기 위해 자유롭게 사용하는 보조 메모리입니다.
    
- **`R` (Retain / File Register - 파일 레지스터):** 전원이 꺼져도 데이터가 지워지지 않고 유지되어야 하는 중요한 설정값 등을 저장하는 영역입니다.
    
- **`W` (Link Register - 링크 레지스터):** 주로 다른 PLC나 기기들과 통신(네트워크)을 통해 데이터를 주고받을 때 사용하는 전용 메모리 영역입니다.
### 2. 크기 정보 (세 번째 문자: 데이터가 차지하는 공간의 크기)

할당된 번지(어드레스)부터 시작하여 메모리 공간을 '얼마나 크게' 차지할 것인지를 나타냅니다.

- **`X` (Bit - 비트):** **1 Bit** 크기입니다. 0 또는 1 (ON/OFF) 상태만 가질 수 있으며, 주로 단순한 스위치나 접점 상태를 나타낼 때 사용합니다.
    
- **`B` (Byte - 바이트):** **8 Bits** 크기입니다.
    
- **`W` (Word - 워드):** **16 Bits (2 Bytes)** 크기입니다. PLC에서 가장 기본이 되는 데이터 크기 단위이며, 아날로그 센서 값이나 일반적인 정수를 다룰 때 많이 사용합니다.
    
- **`D` (Double Word - 더블 워드):** **32 Bits (4 Bytes)** 크기입니다. 워드(W) 2개를 합친 크기로, 값이 매우 큰 정수나 소수점이 있는 실수(Real) 데이터를 다룰 때 사용합니다.
    
- **`L` (Long Word - 롱 워드):** **64 Bits (8 Bytes)** 크기입니다. 워드(W) 4개를 합친 크기로, 아주 정밀한 계산이나 거대한 데이터를 다룰 때 사용합니다.
### 조합 예시

- `%IX0.0.0`: 입력 영역(`I`)에 위치한 비트(`X`) 크기의 첫 번째 접점
    
- `%MW10`: 내부 메모리 영역(`M`)에 위치한 워드(`W`) 크기의 10번 어드레스
    
- `%MD20`: 내부 메모리 영역(`M`)에 위치한 더블 워드(`D`) 크기의 20번 어드레스 (이 경우 20번과 21번 워드를 함께 점유합니다)

## 입출력 주소 형식 (`%QX0.0.0`, `%IX0.0.0`)

실제 하드웨어 입출력 카드에 연결되는 `%Q`와 `%I`는 **슬롯 위치**까지 명시해야 하므로 점(`.`)으로 구분을 지어 표현

$$\text{\%Q} \quad \text{X} \quad \mathbf{0} \,.\, \mathbf{0} \,.\, \mathbf{0}$$

1. **`%Q`** : 출력 영역 (Output)
    
2. **`X`** : 데이터 타입 (Bit)
    
3. **첫 번째 `0`** : Base 번호 (베이스 0번 = 메인 베이스)
    
4. **두 번째 `0`** : Slot 번호 (0번 슬롯에 장착된 출력 모듈)
    
5. **세 번째 `0`** : Bit 번호 (해당 모듈의 0번째 단자/접점)![[Pasted image 20260801202010.png]]베이스에 PLC를 꽂을 수 있는 슬롯이 있고 입출력 핀의 숫자와 연산능력의 필요에 따라 확장 가능한 형태임

## 메모리 단위
- 시스템의 기본 메모리 단위는 1Word(16 bit)이며, 하나의 데이터 레지스터로 구성됨
- %MW는 1 Word 단위의 어드레스를 점유하고, %MD는 2개의 어드레스를 연속으로 할당받음. 따라서 데이터 충돌(Overlapping)을 방지하기 위해 메모리 맵(Memory Map)을 겹치지 않게 설계해야 함
