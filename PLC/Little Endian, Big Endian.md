> `DEC`:`12203453` 
> `BIN`: `0000 0000 1011 1010 0011 0101 1011 1101`
> `HEX`: `BA 35 BD`

**Big Endian**
- 큰 값 (상위 데이터)을 먼저 낮은 주소에 저장. (사람이 읽는 방식과 동일)
- C에서 시작주소가 0x1000이라고 하고 int type이라고 하면 (4bytes)
- (C는 메모리를 1바이트 단위로 저장)

| **메모리 주소** | **저장된 값 (HEX)** | **설명**     |
| ---------- | --------------- | ---------- |
| `0x1000`   | **00**          | 상위 1st 바이트 |
| `0x1001`   | **BA**          | 2nd 바이트    |
| `0x1002`   | **35**          | 3rd 바이트    |
| `0x1003`   | **BD**          | 하위 4th 바이트 |
- PLC에서 시작 디바이스가 D0라고 하고 Double Word (4bytes) 라고 하면 
- (PLC는 메모리를 WORD(2bytes)단위로 저장)

| **디바이스 주소**    | **저장된 값 (BIN)**       | **설명**           |
| -------------- | --------------------- | ---------------- |
| **D1** (낮은 주소) | `0000 0000 1011 1010` | 데이터의 **상위** 16비트 |
| **D2** (높은 주소) | `0011 0101 1011 1101` | 데이터의 **하위** 16비트 |

**Little Endian**
- 작은 값 (하위 데이터)을 먼저 낮은 주소에 저장 (CPU의 연산 처리에 유리)
- C에서 시작주소가 0x1000이라고 하고 int type이라고 하면 (4bytes)
- (C는 메모리를 1바이트 단위로 저장)

| **메모리 주소** | **저장된 값 (HEX)** | **설명**     |
| ---------- | --------------- | ---------- |
| `0x1000`   | **BD**          | 하위 4th 바이트 |
| `0x1001`   | **35**          | 3rd 바이트    |
| `0x1002`   | **BA**          | 2nd 바이트    |
| `0x1003`   | **00**          | 상위 1st 바이트 |

- PLC에서 시작 디바이스가 D0라고 하고 Double Word (4bytes) 라고 하면 
- (PLC는 메모리를 WORD(2bytes)단위로 저장)

|**디바이스 주소**|**저장된 값 (BIN)**|**HEX**|**설명**|
|---|---|---|---|
|**D1** (낮은 주소)|`0011 0101 1011 1101`|**35BD**|데이터의 **하위** 16비트|
|**D2** (높은 주소)|`0000 0000 1011 1010`|**00BA**|데이터의 **상위** 16비트|
