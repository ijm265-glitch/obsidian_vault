### Function Block
#### CTU
![[Pasted image 20260820135756.png]]
CU로 지정한 디바이스의 RISING을 감지하면 CV로 지정한 디바이스의 값을 0부터 시작해서 1씩 증가시킨다
CV로 지정한 디바이스의 값이 PV로 지정한 값 (디바이스로 지정했다면 디바이스의 값) 이상이 되면 Q로 지정한 디바이스의 값이 TRUE(1)가 된다.
R로 지정한 디바이스 값의 RISING을 감지하면 CV로 지정한 디바이스의 값을 0으로 만든다

#### TON
![[Pasted image 20260820145732.png]]
IN으로 지정한 디바이스가 TRUE이면 ET로 지정한 디바이스의 값을 시간에 따라 증가시킨다.
ET로 지정한 디바이스의 값이 PT로 지정한 값 (디바이스로 지정하였다면 디바이스의 값)과 같아지면 IN으로 지정한 디바이스가 TRUE여도 ET의 증가는 멈추며 Q로 지정한 디바이스의 값이 TRUE가 된다.
IN으로 지정한 디바이스가 FASLE이면 ET로 지정한 디바이스의 값은 0이 된다.

#### TOF
![[Pasted image 20260820151801.png]]
IN으로 지정한 디바이스가 TRUE이면 ET로 지정한 디바이스의 값이 0이 된다.
또한 Q가 TRUE가 된다.
IN으로 지정한 디바이스가 TRUE에서 FALSE가 되면 ET로 지정한 디바이스의 값이 시간에 따라 증가한다. 
ET로 지정한 디바이스의 값이 PT로 지정한 값 (디바이스로 지정하였다면 디바이스의 값)과 같아지면 IN으로 지정한 디바이스가 FALSE여도 ET의 증가는 멈추며 Q로 지정한 디바이스의 값이 FALSE가 된다.
