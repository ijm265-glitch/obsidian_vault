### 1. 변수 선언 (인스턴스 생성)

프로그램의 로컬 변수 창(Variable Declaration)에서 FB를 실행하기 위한 인스턴스(Instance)를 등록합니다.

- **변수 종류:** `VAR` (로컬 변수)
    
- **변수 이름:** 사용할 인스턴스 명칭 (예: `MyTimer`, `Motor_FB`)
    
- **데이터 타입(타입):** 생성하고자 하는 **함수 블록의 타입 이름** (예: `TON`, `CTU`, 또는 사용자가 정의한 FB 이름)을 지정합니다.
    
### 2. 코드 작성 및 인스턴스 호출

코드 작성란(ST Editor)에서 선언한 변수 이름(인스턴스)을 호출하여 내부 입력(Input) 및 출력(Output) 파라미터를 설정합니다.

- **호출 및 파라미터 매핑 방식:**
    ```c
    // 인스턴스 이름(입력변수 := 값, 출력변수 => 저장할변수);
    MyTimer(IN := Start_Button, PT := T#5s);
    Current_Out := MyTimer.Q;
    ```
