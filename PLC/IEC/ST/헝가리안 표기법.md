변수 및 함수와 인자의 식별자 앞에 데이터 타입을 명시하는 방법

| **데이터 타입**             | **접두어**       |
| ---------------------- | ------------- |
| **BOOL**               | `b`           |
| **BYTE**               | `by`          |
| **WORD**               | `w`           |
| **DWORD**              | `dw`          |
| **LWORD**              | `lw`          |
| **SINT**               | `si`          |
| **INT**                | `i` 또는 `n`    |
| **DINT**               | `di` 또는 `dn`  |
| **LINT**               | `li`          |
| **USINT**              | `usi`         |
| **UINT**               | `ui`          |
| **UDINT**              | `udi`         |
| **ULINT**              | `uli`         |
| **REAL**               | `r`           |
| **LREAL**              | `lr`          |
| **TIME**               | `t`           |
| **DATE**               | `d`           |
| **TIME_OF_DAY (TOD)**  | `tod`         |
| **DATE_AND_TIME (DT)** | `dt`          |
| **STRING**             | `s` 또는 `st`   |
| **ARRAY**              | `a` 또는 `arr`  |
| **FB_INST**            | `fb`          |
| **STRUCT**             | `st` 또는 `str` |

ex: `tTimeout`, `nState`, `bCmd_Start`
