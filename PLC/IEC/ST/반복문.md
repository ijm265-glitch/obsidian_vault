`FOR, WHILE, EXIT`

## FOR문
```
SUM := 0; 
FOR counter := 0 TO 10 DO 
	SUM := SUM + 1; 
END_FOR ;

// counter 변수가 0에서 10까지 1씩 증가한다.
// SUM 변수에 1의 값을 계속 더한다.
// 최종 SUM의 값은 11
```

```
SUM := 0; 
FOR counter = 0 TO 10 BY 2 DO 
	SUM := SUM + 1; 
END_FOR;

// counter 변수가 0에서 10까지 2씩 증가함
// sum 변수에 1의 값을 계속해서 더한다.
// sum의 최종 값은 6
```

## WHILE문
```
Counter := 0 
WHILE Counter < 20 DO 
	Counter := Counter + 1; 
END_WHILE ;

// Counter < 20 조건이 참일경우 WHILE안의 상태문을 수행
// 반복하여  Counter에 1씩 더하여 Counter변수가 20이 되면 FALSE가 되어 순환문을 빠져나감
```

## EXIT
```
SUM := 0; 
FOR Counter := 0 TO 10 DO 
	SUM := SUM + 1; 
	EXIT;
	 
END_FOR ;
(*
Counter 변수가 0에서 10까지 1씩 증가하는 FOR문이지만 상태문에 EXIT를 사용하여 바로 빠져나옴
Counter변수는 0이 되고 SUM변수는 1이 됨
*)
```

```
Counter := 0; 
WHILE Counter < 20 DO 
	Counter := Counter + 1 ; 
	IF Counter = 10 THEN 
		EXIT; 
		
	END_IF; 

END_WHILE ;

(*
Counter 변수가 20보다 작다는 조건이 맞으면 상태문을 수행함.
Counter 변수가 20이 되면 조건이 FALSE가 되어 WHILE을 빠져나옴
그러나 상태문에 IF문과 EXIT를 사용하여 Counter 변수가 10일 겨우 반복문을 빠져나옴
*)
```
