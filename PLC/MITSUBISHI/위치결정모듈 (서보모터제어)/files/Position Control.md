### 1. [[In-position range]] (`INP` / `PA10`): 위치결정 완료 범위 (인포지션 밴드)

- **현재 설정값**: `1600 pulse`
    
- **기능**: 서보가 목표 위치로 이동할 때, 목표 좌표 대비 **남은 위치 편차(오차)가 이 범위(±1600 pulse) 안으로 들어오면 "목표 위치에 다 왔다"고 판단하여 드라이브 내부의 `INP` 신호를 켭니다**.
    
- **실무적 의미**:
    
    - PLC 시퀀스에서 "이 축이 이동 완료되었으니 다음 실린더를 전진시켜라" 같은 다음 스텝 인터록을 걸 때 이 신호를 사용합니다.
        
    - 정밀 조립 장비처럼 매우 타이트한 위치 정밀도가 필요하면 이 값을 줄이고, 고속 운전에서 신호를 빠르게 넘겨 택트 타임을 줄이고 싶다면 범위를 넓힙니다.
        
    - 테스트 환경에서는 기본값인 `1600` 그대로 두시면 됩니다.
        

### 2. Error excessive alarm (`ERZ`, `*COP3` / `PC01` 등): 위치 편차 과대 알람

- **현재 설정값**: `0 rev` / 단위 `1 [rev] Unit`
    
- **기능**: 위치 지령(가야 할 위치)과 엔코더 피드백(실제 위치)의 차이(정류 오차)가 비정상적으로 벌어졌을 때 `[AL. 52 Error excessive]`(편차 과대 알람)를 띄우는 한계치를 설정합니다.
    
    - 모터가 회전 중 기계적인 간섭이나 끼임(잼)으로 물리적으로 멈춰버렸을 때, 서보는 계속 전기를 밀어넣어 모터가 타거나 기계가 부서지는 것을 방지하기 위해 이 알람을 띄우고 서보를 끕니다.
        
- **기본값 `0 rev`의 의미**:
    
    - `0`으로 두면 기능을 끄는 것이 아니라, 제조사가 서보 모터 정격에 맞게 내부적으로 정해둔 표준 기본 한계치(약 3회전 상당 등)를 자동으로 적용합니다.
        
    - 따라서 특별한 안전 기준이 있는 경우가 아니라면 기본값인 **`0`** 그대로 두시면 됩니다.
