![[Pasted image 20261006112950.png]]### 1. Forced stop deceleration function (`*AOP1` / `PA04`) & Time constant (`RSBR` / `PC24`)

- **좌측 드롭다운 (`Forced stop deceleration function selection`)**:
    
    - 비상정지 신호(`EM2`)가 들어왔을 때 모터에 전기를 바로 끊고 관성으로 미끄러지게 둘 것인지, 아니면 **강제로 브레이크(역토크)를 걸어 부드럽고 빠르게 감속 정지**시킬 것인지를 정합니다.
        
    - 앞선 `Common - Basic` 창에서 `Forced stop`을 `Disabled`로 설정해 두었다면 CN3를 안 쓰므로 비활성화 상태가 유지됩니다.
        
- **우측 입력칸 (`Forced stop deceleration time constant`: `100 ms`)**:
    
    - 감속 정지 기능을 쓸 때 최고 속도에서 정지할 때까지 걸리는 감속 시간(기본 100ms)입니다.
        

### 2. Vertical axis freefall prevention (`RSUP1` / `PC29`): 수직축 자연 낙하 방지

- **기능**: Z축(상하로 오르내리는 수직 리프트 기구)에서 모터 전원이 꺼지거나 서보 오프될 때 기구물이 중력으로 뚝 떨어지는 것을 막는 보정 기능입니다.
    
- **원리**: 기계식 전자 브레이크가 물리적으로 완전히 잠기기까지 수십 ms의 지연 시간이 발생하는데, 이 찰나의 틈 동안 모터가 역방향으로 살짝 토크를 유지해 아래로 처지는 현상(Drop)을 상쇄해 줍니다.
    
- **설정**: 지금처럼 평상에 놓인 단독 모터 테스트나 수평축 환경에서는 필요 없으므로 **기본값(`0`)** 그대로 둡니다.
    

### 3. Machine diagnosis function (`FRIC` / `PF31`): 기계 마찰 진단 기능

- **기능**: 볼스크루나 LM 가이드의 노후화, 그리스(윤활유) 부족 등으로 기구부 마찰력이 커졌는지를 드라이브가 스스로 감지하는 스마트 진단 기능입니다.
    
- **설정**: 특정 속도로 주행할 때의 마찰 토크를 비교 판단하기 위한 기준 속도(`Friction judgement speed`)를 지정하는 항목이며, 기본값은 `0`(기능 미사용)입니다. 기본 상태 그대로 두시면 됩니다.
