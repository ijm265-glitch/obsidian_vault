### PLC 기반 서보 모터 제어 (포인트 테이블 방식)

PLC를 이용한 서보 모터 제어는 목표 위치, 속도, 가감속 시간 등을 미리 표 형태로 등록해 두고, 번호(Point No.)를 호출해 기동하는 **포인트 테이블(Positioning Data) 방식**이 널리 쓰입니다.

---

#### 1. 시스템 4대 구성 요소

1. **PLC (CPU)**
* 전체 시스템 시퀀스 제어 및 상위 판단 담당
* 목표 포인트 번호 지정 및 운전 지령(기동/정지 플래그) 하달


2. **위치결정 모듈 (Positioning / Motion Module)**
* 포인트 테이블(위치 데이터) 저장 및 궤적 프로파일(가감속·목표 위치·속도) 연산
* CPU의 지령에 맞춰 서보 드라이브로 구동 신호 전송


3. **서보 앰프 (서보 드라이브, Servo Drive)**
* 위치결정 모듈의 지령을 받아 모터의 위치·속도·전류 루프 제어
* 모터 엔코더 피드백을 실시간 감시하며 정밀 전력 공급


4. **서보 모터 (Servo Motor)**
* 드라이브의 전력을 받아 기계 기구부를 구동
* 내장 엔코더를 통해 현재 회전각/위치 데이터를 서보 드라이브로 피드백



---

#### 2. 동작 제어 시퀀스 흐름

```text
[1. PLC CPU]
      │  포인트 번호(1~600 등) 지정 & 기동 플래그(Start Bit) ON
      ▼
[2. 위치결정 모듈]
      │  해당 포인트 파라미터(위치·속도·가감속) 연산 후 지령 출력
      ▼
[3. 서보 드라이브]
      │  지령(통신 데이터 / 펄스열) 수신 후 모터 구동 전력 인가
      ▼
[4. 서보 모터] ──(엔코더 피드백)──> [3. 서보 드라이브]

```

1. **지령 전달:** PLC CPU가 이동하려는 **포인트 테이블 번호**를 위치결정 모듈의 버퍼 메모리에 쓰고, **기동 시작 플래그**를 켭니다.
2. **프로파일 연산 및 출력:** 위치결정 모듈이 지정된 번호의 위치값과 속도값을 읽어 가감속 프로파일을 생성한 뒤, 서보 드라이브로 제어 신호를 보냅니다.
	* *전송 방식:*
		* **네트워크 통신 방식:** SSCNET, CC-Link IE TSN, EtherCAT 등의 고속 모션 필드버스로 디지털 데이터 지령 전달
		* **펄스열/아날로그 방식:** Pulse/Direction 펄스열 또는 속도 아날로그 전압 출력
3. **모터 구동 및 피드백:** 서보 드라이브가 해당 지령에 맞춰 모터를 회전시키고, 엔코더 신호를 받아 편차를 0으로 유지하며 정밀 제어를 완료합니다.
