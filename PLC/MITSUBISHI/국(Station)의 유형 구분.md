## 1. 마스터국 (Master Station)

네트워크 전체의 통신 스케줄(폴링 및 토큰 제어), 파라미터 배포, 각 슬레이브의 상태 진단을 총괄하는 사령탑입니다.

- **국번**: 항상 0번 (`Station No. 0`)으로 고정됩니다.
    
- **대표 모듈**: `QJ61BT11N` (Q 시리즈), `RJ61BT11` (iQ-R 시리즈), `FX5-CCL-MS` (iQ-F 시리즈)
    
- **핵심 역할**:
    
    - 하나의 CC-Link 망에는 반드시 1대의 마스터국만 활성화되어 동작합니다 (단, 마스터 이상 시 백업하는 대기 마스터국 구성은 가능).
        
    - 최대 **64개의 슬레이브국**을 거느리고 매 스캔마다 전체 링크 디바이스(`RX`, `RY`, `RWr`, `RWw`) 데이터를 수집·배포합니다.
        

## 2. 리모트 I/O국 (Remote I/O Station)

단순히 **ON/OFF 비트(Bit) 신호만** 주고받는 가장 가볍고 기본적인 슬레이브 기기입니다. 워드(수치) 데이터는 일절 다루지 않습니다.

- **사용하는 링크 디바이스**: **`RX`** (입력 비트), **`RY`** (출력 비트)만 사용 (`RWr`, `RWw`는 사용 안 함)
    
- **점유 용량**: 1국당 `RX` 32점, `RY` 32점 할당 (고정)
    
- **대표 기기**:
    
    - 분산 I/O 단자대 모듈 (예: `AJ65SBTB1-32D` 입력 모듈, `AJ65SBTB1-32T` 출력 모듈)
        
    - 공압 매니폴드 솔레노이드 밸브 블록 (SMC, Festo 등)
        
    - 현장의 푸시버튼 박스, 타워 램프, 포토/근접 센서 집합 블록
        
- **특징**: 워드 영역(`RWr/RWw`)을 잡아먹지 않고 오직 비트만 빠르게 처리하므로, 한 네트워크에 최대 **64대**까지 꽉 채워서 연결할 수 있습니다.
    

## 3. 리모트 디바이스국 (Remote Device Station)

ON/OFF 비트 신호뿐만 아니라, **아날로그 수치나 설정값 같은 16비트 워드(Word) 데이터를 함께** 주고받는 기기입니다. 현업에서 가장 많이 다루게 되는 슬레이브 유형입니다.

- **사용하는 링크 디바이스**: **`RX`, `RY` (비트) + `RWr`, `RWw` (워드)** 모두 사용
    
- **점유 용량**: 1국당 기본 `RX/RY` 각 32점 + **`RWr/RWw` 각 4워드** 할당 (기기 사양에 따라 1~4국 점유)
    
- **대표 기기**:
    
    - **인버터** (미쓰비시 FR-A800 / E800 시리즈 등): 기동/정지 비트는 `RY`로, 목표 주파수(Hz)는 `RWw`로 전송
        
    - **아날로그 입출력 모듈** (A/D, D/A 변환기): 채널별 전압/전류 디지털 변환값을 `RWr/RWw`로 송수신
        
    - 디지털 온도 조절기, 로드셀 인디케이터, 유량계
        
- **특징**: 워드 데이터를 주기적(사이클릭)으로 주고받지만, 비주기적인 대용량 메시지 통신(트랜지언트 전송) 기능은 없습니다. 한 망에 최대 **42대**까지 연결 가능합니다.
    

## 4. 인텔리전트 디바이스국 (Intelligent Device Station) 및 로컬국 (Local Station)

자체 CPU나 고성능 연산 장치를 탑재하고 있어, 주기적인 사이클릭 전송(`RX/RY/RWr/RWw`)은 물론이고 필요할 때마다 대용량 파라미터나 명령 프레임(MC 프로토콜 등)을 비주기적으로 주고받는 트랜지언트 전송(Transient Transmission)까지 가능한 최상위 슬레이브입니다.

- **사용하는 링크 디바이스**: `RX`, `RY`, `RWr`, `RWw` + **트랜지언트 통신 채널**
    
- **인텔리전트 디바이스국 대표 기기**:
    
    - 모션/위치결정 모듈, 고속 카운터 모듈
        
    - 바코드/QR 리더기, RFID 컨트롤러, 비전 센서
        
    - 산업용 로봇 컨트롤러, GOT(HMI 터치패널), RS-232C 시리얼 인터페이스 모듈
        
- **로컬국 (Local Station)이란?**:
    
    - 인텔리전트 디바이스국 중에서도 **자체 PLC CPU를 장착한 또 다른 PLC**가 슬레이브로 물린 경우를 특별히 **로컬국**이라 부릅니다.
        
    - 마스터 PLC의 `QJ61BT11N`과 똑같은 모듈을 다른 PLC에 꽂고 국번만 1~64번으로 주면 즉시 로컬국(PLC to PLC 슬레이브)으로 동작합니다.
        
- **특징**: 처리하는 데이터 규모가 크므로 한 망에 최대 **26대**까지 연결할 수 있습니다.
    

## 국 유형별 핵심 비교 요약

| **구분**                    | **리모트 I/O국** | **리모트 디바이스국**         | **인텔리전트 디바이스국 / 로컬국**          |
| ------------------------- | ------------ | --------------------- | ------------------------------ |
| **비트 데이터 (`RX`, `RY`)**   | **O**        | **O**                 | **O**                          |
| **워드 데이터 (`RWr`, `RWw`)** | X            | **O**                 | **O**                          |
| **비주기 통신 (Transient)**    | X            | X                     | **O** (전용 명령어 `RIRD`/`RIWT` 등) |
| **망 내 최대 연결 대수**          | 64대          | 42대                   | 26대                            |
| **대표 현장 장비**              | 센서/솔밸브 단자대   | 인버터, 아날로그(AD/DA), 온조기 | 하위 PLC(로컬국), 로봇, 바코드, 서보       |

```
[라인 메인 마스터 PLC (0번)]
        │ (상위 CC-Link 1번 망)
        ├── [로봇 셀 PLC] (로컬국 1번)
        └── [가공 스테이션 PLC] (로컬국 2번) ── [QJ61BT11N #1: 상위망 로컬국]
                                              [QJ61BT11N #2: 하위망 마스터국]
                                                      │ (자체 CC-Link 2번 망)
                                                      ├── [가공 리모트 I/O (센서/솔밸브)]
                                                      └── [스핀들 인버터 (A800)]
```
