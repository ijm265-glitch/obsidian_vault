슬레이브 기기가 다루어야 할 데이터 양이 1국 기본 제공량(비트 32점, 워드 4점)을 넘어설 때, 이를 해결하는 방법은 **점유 국수 늘리기**와 **확장 사이클릭 설정** 두 가지가 있습니다.

## 1. 기본 1국 점유의 한계와 복수 국 점유 계산법

기본적으로 CC-Link는 슬레이브 기기 1대당 1국(Station)의 통신 메모리를 부여합니다.

- **1국 기본 제공량**:
    
    - 비트(`RX`, `RY`): **각 32점** (16진수 `00H` ~ `1FH`)
        
    - 워드(`RWr`, `RWw`): **각 4점** (16진수 `0` ~ `3`)
        

### (1) 한계 상황

- 8채널 아날로그 입력 모듈(A/D)을 쓴다면 채널당 1워드씩 최소 8워드가 필요한데, 1국 기본 할당량은 4워드뿐이므로 모듈 전체를 다 읽어올 수 없습니다.
    
- 인버터나 복합 센서처럼 모니터링해야 할 데이터(주파수, 전류, 전압, 누적 시간, 알람 코드 등)가 4워드를 초과할 때 공간 부족이 발생합니다.
    

### (2) 복수 국 점유 (Occupied Stations: 2국, 3국, 4국 점유)

기기가 다루는 데이터가 많을 때, 물리적인 기기는 1대지만 **논리적인 국번 자리를 2~4개 연속으로 차지**하여 메모리 대역폭을 곱절로 늘리는 방식입니다.

- **점유 국수별 할당 용량 (기본 사이클릭 기준)**:
    

|**점유 국수**|**비트 할당 (RX / RY)**|**워드 할당 (RWr / RWw)**|**비고**|
|---|---|---|---|
|**1국 점유**|각 **32점** (`20H`)|각 **4워드**|일반 I/O, 단순 인버터 제어|
|**2국 점유**|각 **64점** (`40H`)|각 **8워드**|아날로그 입출력, 표준 인버터 제어|
|**3국 점유**|각 **96점** (`60H`)|각 **12워드**|고기능 아날로그, 온조기 멀티 채널|
|**4국 점유**|각 **128점** (`80H`)|각 **16워드**|다축 위치결정, 로봇 컨트롤러 인터페이스|

### (3) 번지 및 국번 건너뛰기 계산 예시

2번 국번에 **2국 점유** 기기를 배치한 경우:

- **국번 계산**:
    
    - 해당 기기는 **2번**과 **3번**을 모두 차지합니다.
        
    - 따라서 다음 연결할 기기의 국번은 반드시 **4번**이어야 합니다.
        
- **디바이스 영역 계산 (Hex)**:
    
    - 비트 시작: $(2-1) \times 20\text{H} = \text{RX/RY } 20\text{H}$
        
    - 비트 크기: 2국 점유이므로 $32 \times 2 = 64$점 ($40\text{H}$) $\rightarrow$ **`RX20 ~ RX5F` / `RY20 ~ RY5F`**
        
    - 워드 시작: $(2-1) \times 4\text{H} = \text{RWr/RWw } 4\text{H}$
        
    - 워드 크기: 2국 점유이므로 $4 \times 2 = 8$워드 $\rightarrow$ **`RWr4 ~ RWrB` / `RWw4 ~ RWwB`**
        

## 2. 확장 사이클릭(Extended Cyclic)을 통한 대역폭 확장

복수 국 점유는 워드를 늘릴 수 있지만 치명적인 단점이 있습니다. "국번 자리를 2~4개씩 잡아먹기 때문에 네트워크 전체에 연결 가능한 기기 대수(최대 64국)가 급격히 줄어든다"는 점입니다.

이를 해결하기 위해 CC-Link Ver 2.0부터 도입된 기술이 확장 사이클릭(Extended Cyclic)입니다.

**국번 자리는 1개만 차지하면서, 1국당 전송되는 워드/비트 전송 크기를 2배, 4배, 8배로 증폭**시키는 방식입니다.

### (1) 확장 배수 설정 단계

|**확장 설정**|**비트 할당 배수**|**워드 할당 배수**|**1국 점유 기준 실제 제공량**|
|---|---|---|---|
|**Single (1배)**|1배|1배|`RX/RY` 32점 / **`RWr/RWw` 4워드**|
|**Double (2배)**|1배|**2배**|`RX/RY` 32점 / **`RWr/RWw` 8워드**|
|**Quadruple (4배)**|2배|**4배**|`RX/RY` 64점 / **`RWr/RWw` 16워드**|
|**Octuple (8배)**|4배|**8배**|`RX/RY` 128점 / **`RWr/RWw` 32워드**|

- 워드 데이터는 정직하게 2배, 4배, 8배(최대 32워드)로 늘어납니다.
    
- 비트 데이터는 2배 설정 시에는 그대로 32점이며, 4배 설정 시 64점, 8배 설정 시 128점으로 늘어납니다.
    

### (2) 복수 국 점유 vs 확장 사이클릭 비교 (워드 16개가 필요할 때)

워드 데이터 16개(`RWw 16점 / RWr 16점`)를 주고받아야 하는 센서 모듈이 있다고 가정해 보겠습니다.

- **방법 1: 복수 국 점유(4국 점유, Single 배수) 사용**
    
    - 차지하는 국번: **4개** 소모 (예: 1번, 2번, 3번, 4번 국번 소모)
        
    - 남은 연결 가능 슬레이브 수가 크게 줄어듦
        
- **방법 2: 확장 사이클릭(1국 점유, Quadruple 4배) 사용**
    
    - 차지하는 국번: **단 1개** 소모 (예: 1번 국번만 사용, 다음 기기는 2번 국번 사용)
        
    - 워드 용량: 16워드 확보 완료
        

## 3. 실무 파라미터(GX Works) 설정 시 체크 포인트

GX Works의 `Network Parameter` $\rightarrow$ `CC-Link` $\rightarrow$ `Station Information` 창에서 슬레이브를 등록할 때 다음 두 열(Column)을 기기 사양에 맞게 선택합니다.

1. **`Occupied Station Points`**: 1 Station 점유, 2 Station 점유 등 선택
    
2. **`Extended Cyclic Setting`**: Single, Double, Quadruple, Octuple 선택
    

> **실무 주의점**:
> 
> - 확장 사이클릭은 슬레이브 기기 하드웨어가 **CC-Link Ver 2.0 이상을 지원**해야만 사용 가능합니다 (구형 Ver 1.10 전용 기기는 Single만 지원).
>     
> - 확장 배수를 높일수록 1주기당 주고받는 데이터 패킷이 커지므로, CC-Link 네트워크의 전체 **링크 스캔 타임(Link Scan Time)**이 다소 증가합니다. 따라서 대용량 워드가 반드시 필요한 기기에만 선별적으로 적용하는 것이 좋습니다.
