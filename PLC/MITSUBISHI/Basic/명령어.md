코일이나 접점에서 직접 입력하여 사용


### 접점
#### 타이머
`T0 k20`

#### 카운터
`C0 k3`


### 코일
#### set 설정
`set m0`
#### reset 설정
`rst m0`

#### Block reset
`BKRST L6035 K2`
#### 플립 플롭
`FF M0`
- Rising Pulse를 감지해서 연결된 비트 디바이스의 상태를 반전
#### 점프 (Condition Jump)
`CJ P0` 
- 활성화되면 P라는 포인터부터 스캔을 시작한다.
- 포인터는 모선의 왼쪽에 적어서 지정할 수 있음

#### Master Control
`MC N0 M100`, `MCR N0`
`MC N0 M100`와 `MCR N0`사이를 `N0`라는 Nest로 만들 수 있음
`MC N0 M100`를 가동하는 비트가 활성화되면 (예를 들어 M0)
`--[ M0 ]--------------------------------------------[ MC   N0   M100 ]`
Nest `N0`를 실행한다.


#### INC, INCP, DEC, DECP
`INCP d0`
- 활성화되면 d0를 1 증가시킨다.
