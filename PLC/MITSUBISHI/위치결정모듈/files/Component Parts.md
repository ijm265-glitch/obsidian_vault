### 1. Regenerative option (`**REG` / `PA02`): 회생 저항 옵션

- **설정값**: `Regen. option is not used`
    
- **기능**: 서보 감속 시 발생하는 역기전력(에너지)을 태우기 위해 외부 회생 저항기(FR-ABR 등)를 추가로 달았는지 여부를 설정합니다.
    
- **기준**:
    
    - 소용량 드라이브 단독 구성이거나 내장 회생 저항(또는 콘덴서 흡수)만 사용하는 경우 기본값인 `Regen. option is not used`를 그대로 둡니다.
        
    - 잦은 급감속으로 회생 알람(`AL 30 Regenerative error`)이 발생하여 외장 저항기를 달았을 때만 해당 저항 모델을 지정합니다.
        

### 2. Brake output (`MBR` / `PC16`): 전자 브레이크 인터록

- **설정값**: 체크박스 해제 (기본값)
    
- **기능**: 모터 자체에 전자기식 낙하 방지 브레이크가 내장된 모델(모터 품번 끝자리 `B`, 예: HG-KR43B)을 쓸 때 브레이크 해제 신호(`MBR`) 타이밍을 자동으로 제어할지 여부입니다.
    
- **기준**:
    
    - 브레이크가 없는 일반 표준 모터(예: HG-KR43)이거나 단독 모터 테스트 단계에서는 체크를 끕니다.
        
    - 브레이크 장착 모터일 경우 체크하여 릴레이 지연 시간(`0 ms`)을 장비 규격에 맞게 보정합니다.
        

### 3. Battery (`*ABS`, `**COP4` / `PA03`): 절대위치(ABS) 검출 시스템

- **설정값**: `Disabled (Used in incremental system)`
    
- **기능**: 서보 앰프 전면에 배터리(MR-BAT6V1SET 등)를 장착하여 전원을 꺼도 현재 기계 좌표를 계속 기억하는 절대위치 시스템(Absolute System)을 쓸 것인지, 전원을 켤 때마다 원점을 새로 잡는 증분형(Incremental System)으로 쓸 것인지를 정합니다.
    
- **주의**: 배터리를 실제로 꽂지 않고 이를 `Enabled`로 바꾸면 배터리 단선/전압 저하 알람(`AL 9F` 또는 `AL 25`)이 발생하므로, 배터리가 없는 테스트 환경에서는 **`Disabled`** 상태를 유지해야 합니다.
    

### 4. Encoder cable (`**COP1` / `PC04`): 엔코더 케이블 결선 방식

- **설정값**: `2-wire`
    
- **기능**: 앞서 매뉴얼 POINT 박스에 나왔던 장거리 4선식 케이블인지, 일반 2선식 통신 케이블인지 지정합니다.
    
- **기준**: 기본 제공되는 일반 길이(수 m 이내) 케이블은 모두 **`2-wire`** 방식이므로 기본값을 그대로 유지합니다.
