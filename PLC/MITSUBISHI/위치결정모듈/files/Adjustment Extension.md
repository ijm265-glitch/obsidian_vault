### 1. Slight vibration suppression control (`*MVS` / `PB24`): 미소 진동 억제 제어

- **현재 상태**: `Disabled` (회색 비활성화)
    
- **기능**: 서보 모터가 목표 위치에 도달해 정지해 있을 때, 엔코더 분해능 1~2펄스 단위로 미세하게 "지잉-" 거리며 축이 떨리는 정지 시 미소 진동을 잡아주는 특수 제어 기능입니다.
    
- **비활성화된 이유**: 이전 창에서 `Auto tuning mode 1`을 켜두었기 때문에, 드라이브가 기본 제어 알고리즘으로 내부 제어하고 있어 수동 개입 항목이 잠겨 있는 것입니다.
    

### 2. PID control (`*MVS` / `PB24`): 제어 방식 선택

- **설정값**: `PI control is enabled.` (기본값)
    
- **기능**: 속도 제어 루프를 **PI(비례-적분) 제어**로 돌릴 것인지, 완전한 **PID(비례-적분-미분) 제어**로 돌릴 것인지를 정합니다.
    
- **기준**: 산업용 모션 제어의 99%는 안정성이 검증된 **PI 제어**를 표준으로 사용하므로 기본값 그대로 유지합니다.
    

### 3. Feed forward gain (`FFC` / `PB04`): 피드포워드 게인

- **설정값**: `0 %` (기본값)
    
- **기능**: 목표 위치 지령의 속도 변화를 미리 예측하여, 오차가 생기기 전에 모터에 선제적으로 토크를 가해주는 **앞먹임(Feedforward) 비율**입니다.
    
- **실무적 의미**:
    
    - 값을 올리면 가감속 시 위치 편차가 획기적으로 줄어들어 초고속 고정밀 트래킹이 가능해집니다.
        
    - 하지만 너무 높이면 급출발·급정지 시 기계에 덜컥거리는 충격이나 오버슈트가 발생하기 때문에 보통 튜닝 시 `0%`에서 시작해 조금씩 올립니다.
        
    - 기본 테스트 환경에서는 `0 %`가 표준입니다.
        

### 4. [[Torque Feedback loop gain]] (`TFBGN` / `PB45`): 토크 피드백 루프 게인

- **설정값**: `18000 rad/s` (최댓값이자 기본값)
    
- **기능**: 모터의 토크(전류) 제어 루프의 응답 주파수 한계치입니다.
    
- **기준**: 서보 드라이브의 기본 전류 응답 성능을 100% 발휘할 수 있도록 출하 시 최대치(`18000`)로 고정되어 나오므로 건드릴 필요가 없습니다.
