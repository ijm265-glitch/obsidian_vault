### 1. 상단 툴바 버튼 기능

- **`Axis 1` (축 선택 드롭다운)**: 파라미터를 읽거나 쓸 대상 서보 축(1축, 2축 등)을 지정합니다.
    
- **`Read` (읽기)**: 현재 서보 앰프 하드웨어에 저장되어 있는 파라미터를 PC 소프트웨어로 읽어옵니다.
    
- **`Set To Default` (초기화)**: 모든 파라미터 설정을 공장 출하 초기값으로 되돌립니다.
    
- **`Verify` (비교 검증)**: 현재 PC 화면에 열려 있는 파라미터와 실제 서보 앰프 내부의 파라미터가 일치하는지 비교하여 다른 점을 찾아냅니다.
    
- **`Open` / `Save As`**: 파라미터 설정 내용을 PC 파일(`.mr2`)로 열거나 백업 저장합니다.
    
- **우측 상단 쓰기 버튼**:
    
    - **`Selected Items Write`**: 현재 화면에서 수정한 특정 항목만 앰프에 씁니다.
        
    - **`Axis Writing`**: 해당 축의 전체 파라미터를 앰프에 일괄 전송(다운로드)합니다.
        

### 2. 본문: Operation mode selection (`**STY`)

- **`Standard control mode`**: 일반 회전형 서보 모터(내장 엔코더 방식)를 구동하는 기본 제어 모드입니다. 현재 회전형 모터를 사용 중이시라면 이 상태 그대로 두시면 됩니다.
    
- **하단 안내 문구의 의미**:
    
    - 만약 이 운전 모드(표준, 리니어, 풀클로즈드 등)를 변경하여 서보 앰프에 다운로드(`Write`)했다면, 서보 전원을 완전히 껐다 켠(Power OFF $\rightarrow$ ON) 후 프로젝트 설정도 변경된 모드로 맞춰야 정상 동작한다는 주의 사항입니다.
