![[Pasted image 20261006114647.png]]### 1. One-touch tuning function (`*AOP3` / `PA21`)

- **현재 설정값**: **`Enabled`** (유효)
    
- **기능**: MR Configurator2 프로그램 내의 **원터치 튜닝(One-touch Tuning) 실행 기능**을 허용할 것인지 결정합니다.
    
- **실무적 의미**:
    
    - 나중에 기구물을 조립한 뒤 버튼 하나를 눌러 모터를 앞뒤로 흔들며 기계 관성과 공진점을 자동으로 찾아 게인·필터를 세팅하고 싶을 때 이 기능이 켜져 있어야 합니다.
        
    - 기본 상태인 `Enabled`로 두어야 추후 튜닝 도구를 정상적으로 사용할 수 있습니다.
        

### 2. Permissible overshoot amount level (`OTHOV` / `PA21`)

- **현재 설정값**: **`0 %`** (0~100)
    
- **하단 안내 문구**: `The value "0%", it is set to "50%"`
    
- **기능**: 원터치 튜닝을 수행할 때, 급정지 구간에서 허용할 **오버슈트(목표 위치를 지나치는 양)의 최대 허용치**를 지정합니다.
    
- **의미**:
    
    - 입력칸에 `0 %`를 적어두면 기능을 끄는 것이 아니라 **시스템 기본 권장 허용값인 `50%`로 자동 간주**하여 튜닝을 진행한다는 뜻입니다.
        
    - 금형이나 정밀 간섭 구간처럼 모터가 절대 목표 지점을 넘어가면 안 되는 장비라면 이 값을 0~10% 수준으로 엄격하게 조이고, 일반 장비는 기본값(`0 %`) 그대로 둡니다.
