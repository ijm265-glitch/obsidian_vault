### 2. 소켓 게이트웨이(IP 패킷 전송 / 게이트웨이)란?

CC-Link IE Field 같은 **"폐쇄적인 제어용 전용망" 내부를 경유하여, 일반 PC나 비전 카메라 등의 "범용 TCP/IP 패킷"을 통과시켜 주는 중계 기능**을 말합니다.

- **배경 문제**:
    
    - CC-Link IE Field는 고속 제어 전용 프로토콜로 통신하므로, 일반적인 PC의 웹 브라우저나 소켓 통신 프로그램은 이 망에 직접 물려도 통신이 불가능합니다.
        
    - 만약 제어반 안쪽에 있는 인버터나 서보 앰프의 파라미터를 현장 PC로 튜닝하려면, 제어용 CC-Link 케이블 외에 별도의 일반 LAN 케이블을 장비마다 이중으로 깔아야 하는 낭비가 발생합니다.
        
- **해결책 (소켓 게이트웨이 기능)**:
    
    - 마스터 PLC나 통신 모듈이 중간에서 **중계기(Gateway)** 역할을 해줍니다.
        
    - PC가 보낸 표준 TCP/IP 소켓 패킷을 마스터 PLC가 받아서, CC-Link IE Field 전용 통신 프레임 속에 캡슐화(포장)해 해당 노드까지 배달해 줍니다.
        
    - 목적지 노드에 도착하면 다시 일반 IP 패킷으로 풀어서 타깃 장치(예: 인버터 셋업 소프트웨어, 바코드 리더기)에 전달합니다.
        
- **한계**:
    
    - 추가적인 래더/파라미터 설정이 필요하고, 제어 데이터 전송 주기 사이에 틈새로 끼워 넣는 방식이라 대용량 전송(고해상도 비전 영상 스트리밍 등)을 하기에는 속도와 대역폭에 제약이 큽니다.
        
    - 바로 이 한계를 없애기 위해 나온 기술이 앞서 언급한 **CC-Link IE TSN**(하나의 선으로 제어와 일반 대용량 TCP/IP를 완전 동시 분할 전송)입니다.
