### 1. 국번 설정 스위치 (`STATION NO.` - 상단 2개)
국번을 직접 다이얼로 설정하도록 되어있음
0번의 경우 해당 베이스에 연결되어있는 CPU를 Master (Client)로 사용하고 1~64로 설정하는 경우 Slave (Server)로 사용하게 됨
그 외의 숫자는 오류가 발생

### 2. 전송 속도 및 모드 설정 스위치 (`MODE`)

16진수(0~F) 다이얼로, 통신 속도(Baud Rate)와 동작 상태(온라인/테스트 모드)를 결정합니다.

- **정상 운전 시 (온라인 모드):**
    - `0`: **156kbps** (가장 기본적이며 최장 1.2km까지 전송 가능)
    - `1`: **625kbps**
    - `2`: **2.5Mbps**
    - `3`: **5Mbps**
    - `4`: **10Mbps** (고속 통신, 최장 100m)
        
- **점검/진단 시:**
    - `5 ~ 9`: 회선 테스트 모드
    - `A ~ E`: 하드웨어 자체 테스트 모드
    - `F`: 설정 금지

#### 조건 1: 총 점유 국수 한계 ($\le 64$)

$$\{(1 \times a) + (2 \times b) + (3 \times c) + (4 \times d)\} \le 64$$C-Link는 슬레이브 1대가 무조건 번호 하나만 먹는 게 아니라, 처리할 데이터 양에 따라 **1국, 2국, 3국, 4국**을 차지(점유)할 수 있음

- **$a$ (1국 점유 기기):** 간단한 16/32점 원격 I/O 모듈 (번호 1개 차지)
- **$b$ (2국 점유 기기):** 데이터가 조금 더 많은 인버터 등 (번호 2개 연속 차지)
- **$c$ (3국 점유 기기):** 중형 복합 기기 (번호 3개 차지)
- **$d$ (4국 점유 기기):** 로컬 PLC, 서보 앰프 등 대용량 장비 (번호 4개 차지)
네트워크 1개 시스템에서 모든 기기들이 차지하는 **국번의 총합은 최대 64**를 넘을 수 없습니다.


#### 조건 2: 마스터 모듈의 통신 데이터 버퍼 한계 ($\le 2304$)
마스터 모듈(QJ61BT11N)이 한 번에 송수신하여 버퍼 메모리에 담아둘 수 있는 최대 링크 포인트 용량(총 2304점)을 넘지 않아야 합니다

- **$A$ (리모트 I/O국):** 비트 신호(ON/OFF) 위주 기기 $\rightarrow$ 대당 16점 소모
- **$B$ (리모트 디바이스국):** 수치 데이터(워드)가 오가는 아날로그 모듈, 인버터 등 $\rightarrow$ 대당 54점 소모
- **$C$ (로컬국, 인텔리전트국):** PLC 간 통신 등 대용량 데이터 전송 기기 $\rightarrow$ 대당 88점 소모
슬레이브들의 종류별 대수를 곱해 다 더했을 때 마스터의 전체 통신 처리 용량인 **2304점** 이내여야 통신 프레임 누락 없이 정상 동작합니다.

### 1. 로컬 PLC $\rightarrow$ 마스터 PLC로 보낼 때 (로컬 송신 / 마스터 수신)

1. **송신 (로컬 PLC):**
    - 로컬 PLC가 프로그램에서 **출력(`Y100F`)** 코일을 켭니다.
    - 이 신호는 로컬 CC-Link 모듈의 송신 버퍼인 `RY00F`에 담깁니다.
        
2. **통신선 이동:**
    - 두 모듈 사이를 잇는 CC-Link 케이블(`DA`, `DB`)을 타고 신호가 마스터로 날아갑니다.
        
3. **수신 (마스터 PLC):**
    - 마스터 CC-Link 모듈의 수신 버퍼인 `RX00F`에 신호가 도착합니다.
    - 마스터 모듈이 이 값을 마스터 CPU 메모리의 `X100F`로 자동 복사(리프레시)해 줍니다.
    - **결과:** 마스터 PLC는 자기 센서가 켜진 것처럼 **`X100F` 입력 접점**으로 인식합니다.

### 2. 마스터 PLC $\rightarrow$ 로컬 PLC로 보낼 때 (마스터 송신 / 로컬 수신)

1. **송신 (마스터 PLC):**
    - 마스터 PLC가 프로그램에서 출력(`Y1000`~`Y107F`)을 켭니다.
    - 마스터 CC-Link 모듈의 송신 버퍼인 `RY000`~`RY07F`에 담깁니다.
        
2. **통신선 이동:**
    - CC-Link 케이블을 타고 로컬 측으로 날아갑니다.
        
3. **수신 (로컬 PLC):**
    - 로컬 CC-Link 모듈의 수신 버퍼인 `RX000`~`RX07F`에 도착합니다.
    - 로컬 CPU 메모리의 `X1000`~`X107F`로 자동 복사됩니다.
    - **결과:** 로컬 PLC는 **`X1000`~`X107F` 입력 접점**으로 신호를 받아 동작합니다.

#### ① 마스터국 PLC (GX Works2 설정)

- **Remote Input (RX) 시작 주소:** **`X1000`**
    - 통신 모듈 버퍼 `RX000`이 CPU의 `X1000`에 매핑
    - 버퍼 `RX00F` $\rightarrow$ CPU의 `X100F`에 매핑
        
- **Remote Output (RY) 시작 주소:** **`Y1000`**
    - CPU의 `Y1000` $\rightarrow$ 통신 모듈 버퍼 `RY000`에 매핑
