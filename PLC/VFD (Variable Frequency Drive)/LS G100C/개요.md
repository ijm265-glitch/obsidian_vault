### EMC 필터 내장
VFD는 AC -> DC -> AC의 과정을 거치는데
DC -> AC는 PWM으로 이루어지며 이 과정에서 고주파수 노이즈가 발생할 수 밖에 없음
이 고주파수 노이즈를 상쇄하는 필터가 내장되어있음

|---|---|---|

### 디지털 핀
FX : 정회전
BX : 역회전
BX : 비상정지
RST : 알람 리셋 (에러 발생 후 해제 신호)
Spd-L : 다단속 저속 운전 지령


### 아날로그 핀
VR : 외장 가변저항에 전기를 공급하기 위해 내보내는 DC 전원 (10~12V)
V1 : 전압의 크기를 측정하는 아날로그 입력 핀 - 전압의 크기에 따라 0 -> 0Hz, 10V -> 60Hz로 비례동작
CM : 0V
I2 : 4~20mA 범위의 전류를 받아서 4mA -> 0Hz, 20mA -> 60Hz로 선형적 동작한다.

#### 주파수 지령 방법 3가지
**외장 볼륨 다이얼 - Potentiometer** 
- VR로 10V를 공급하고
- CM으로 0V 기준을 설정한 다음
- V1으로 분압된 0 ~ 10V 전압을 입력받도록 한다.

**PLC 아날로그 출력이 가능한 경우**
- V1으로 바로 0~10V 사이의 전압값을 출력하여 주파수 변환

**전류로 지령**
- PLC의 아날로그 출력 (4mA ~ 20mA)를 이용하거나 유량계, 압력센서 등의 전류 신호를 I2로 바로 연결해서 사용

### 아날로그 출력
AO : 0 ~ 10V 직류 전압으로 신호를 출력
- 기본 설정은 출력 주파수로 0Hz -> 0V 60Hz -> 10V를 출력

### 디지털 출력
A1, B1, C1 : 에러가 발생시 출력을 발생시킴
- 정상 운전 : A1 - C1 (Open), B1 - C1 (Short)
- 에러 발생 : A1 - C1 (Short), B1 - C1 (Open)

EG(Emitter Ground), Q1(Collector)
- Q1 : 스위치의 신호 출력 핀으로 평상시에 Open되어 있다가 인버터 설정 조건이 만족되면 Short
- EG : 트랜지스터의 기준 접지 (0V)
