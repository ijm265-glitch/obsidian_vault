C 베이스의 문법으로 구성되어 있음
전역 : HMI를 구성하는 어느곳이던 작동 
화면 : 특정 화면에서만 작동
일정 : 스케줄러에 따라 지정된 시간에 작동
오브젝트 : 화면에 있는 오브젝트를 동작시키거나 화면 스캔에 따라 동작

### 디바이스 주소 표시 형식
$$@[디바이스 형식:제어기 번호:\#국번:디바이스 주소]$$
디바이스 형식
- X: Bit
- W: Unsigned Short
- S: Short
- D: Unsigned Integer
- L: Integer
- F: Float
제어기 번호
- HMI의 통신 포트
국번
- HMI와 연결되는 장비의 고유 번호
- 생략시 프로젝트 속성에서 지정한 국번 사용
디바이스 주소
- HMI와 연결되는 장비의 디바이스 주소
## 예제
```C
if (@[S:HW00004] >= 4)
{
	@[S:HW00004] = 1;
}

if (@[S:HW00004] == 2)
{
	@[S:HW00002] -= @[S:HW00003];
	
	if (@[S:HW00002] <= 0)
	{
		@[S:HW00002] = 0;
		@[S:HW00004] = 3;
	}
}
```
- 모드 선택의 값이 4보다 커지면 모드를 1로 변경 (IDLE)
- 모드가 2라면 (RUNNING) 목표수량 (`@[S:HW00002]`)에서 초당생산속도 (`@[S:HW00003]`)를 뺀다. 
- 실행주기는 1초간격으로 설정하였기 때문에 문제없이 실행
- 빼기연산의 결과가 음수라면 0으로 변경하고 모드를 3으로 변경 (DONE)

### 스크립트 명령어 - `CopyData, SetData`
`CopyData(@[W:D0, @[W:D100], 5);`
- `D0 ~ D4`까지의 값을 `D100 ~ D104`로 복사한다.
`SetData(@[W:D0, @[W:D100], 50)`
- D100은 오프셋 디바이스, D0를 해당 디바이스, 24을 설정값이다.
- D100에 24이라는 값이 있다면 D0에서 24만큼 떨어진 D24디바이스에 50의 값을 설정한다
