
- **태그**: PLC 메모리 주소(예: `M0000`, `D0100`)에 '원료_투입_스위치' 같은 이름을 매겨 직관적으로 관리하는 기능, 변수라고 생각해도 좋을듯
    
- **문자열 표**: 자주 쓰는 문구나 다국어 메시지를 미리 표로 등록해 두고 필요할 때 불러와 출력하는 기능입니다.
    
- **로깅**: 지정한 디바이스 값(온도, 압력 등)을 시간 흐름에 따라 파일(CSV 등)에 주기적으로 기록·저장하는 기능입니다.
    
- **레서피**: 생산 제품이 바뀔 때 필요한 여러 설정값(파라미터) 세트를 한 번에 PLC에 전달하거나 읽어오는 기능입니다.
    
- **흐름알람**: 경고나 알림 조건을 만족할 때 HMI 화면 한쪽(상·하단)에 전광판처럼 글자가 흘러가며 표시되는 알람입니다.
    
- **이력알람**: 발생한 알람의 시간, 내역, 해제 여부 등의 기록을 DB처럼 누적 저장하고 관리하는 기능입니다.
    
- **스케줄러**: 특정 시간(예: 매일 오전 8시, 매주 월요일)이 되면 지정된 동작을 자동으로 실행하도록 제어하는 기능입니다.
    
- **스크립트**: 기본 오브젝트 기능 외에 C언어 형태의 문법으로 복잡한 연산이나 제어 로직을 직접 구현하는 기능입니다.
    
- **소리**: 알람이 발생하거나 버튼을 누를 때 WAV 등 음원 파일을 재생하여 음성 안내나 경고음을 내보내는 기능입니다.
