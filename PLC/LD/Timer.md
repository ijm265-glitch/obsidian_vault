**TON (Timer On-Delay)**
- LOW -> HIGH에서 작동
- HIGH상태가 계속해서 유지되었을 때 일정시간 후 신호를 발생시킨다.
- **HIGH $\rightarrow$ LOW에서 초기화** 
	- HIGH 상태가 유지되지 않고 LOW로 변경되는 즉시 타이머 경과 시간이 0으로 초기화되며 발생했던 신호도 OFF된다.

**TOFF (Timer Off-Delay)**
- HIGH -> LOW에서 작동
- LOW상태가 계속해서 유지되었을 때 일정시간 후 신호를 차단시킨다.
- **LOW $\rightarrow$ HIGH에서 초기화**
	- LOW 상태가 유지되지 않고 HIGH로 변경되는 즉시 타이머 경과 시간이 0으로 초기화되며 신호 발생 대기 상태(또는 출력이 HIGH인 상태)로 복귀한다.

**TMR (Retentive Timer)**
- LOW -> HIGH에서 작동
- HIGH상태가 유지된 시간을 누적하여 일정시간 후 신호를 발생시킨다.
- **별도 리셋(RST) 신호 입력 시 초기화** 
	- 입력 신호가 LOW로 바뀌어도 누적된 시간 값은 유지되며, 별도의 Reset(RST) 명령 또는 리셋 비트 신호가 들어왔을 때만 누적 시간이 0으로 초기화된다.

**TMON (Monostable Timer)**
- LOW -> HIGH에서 작동 
- 작동된 시점에서 일정시간 동안 신호를 발생시킨다.
- **일정시간 경과 후 자동 초기화** 
	- 작동된 시점부터 설정된 일정시간이 지나면 입력 신호의 상태(HIGH/LOW)와 관계없이 출력이 꺼지며 자동으로 초기화된다. (동작 중 입력 변화는 무시됨)

**TRTG (Retriggerable Timer)**
- LOW -> HIGH에서 작동
- 작동된 시점에서 일정동안 신호를 발생시킨다.
- 다시 작동되면 다시 작동된 시점에서 일정시간 동안 신호를 발생시킨다.
- **재작동 시 시간 카운트 초기화 / 일정시간 경과 후 자동 초기화** 
	- 타이머 동작 중 다시 작동(LOW $\rightarrow$ HIGH)되면 경과 시간이 0으로 재설정되어 처음부터 다시 카운트하며, 재작동 없이 설정된 일정시간이 완전히 경과하면 출력이 꺼지며 자동 초기화된다.
