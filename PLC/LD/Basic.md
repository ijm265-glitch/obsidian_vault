## Scan 방식
Python 인터프리터 방식처럼 라인을 한줄씩 읽어 내려가면서 연산을 수행
완전히 읽었으면 다시 첫번째 줄로 돌아가 다시 읽어 내려감
단, 코드의 순서 의존성을 극도로 지양하는 파이썬등의 인터프리터 방식 언어와 다르게 순서 의존성을 적극적으로 활용한다.

![[Pasted image 20260730121554.png]]
1. P0 <- (LOW -> HIGH -> LOW)
- L98에서 신호가 들어오면 그에 따라 M0에도 신호가 들어온다.
- L99에서 신호가 들어와도 P20, P21에 신호가 들어오지 않았기 때문에 작동하지 않는다
- L101에서 신호가 들어와도 P20에 신호가 들어오지 않아 작동하지 않는다
- L103에 신호가 들어오면 P20이 작동하고 자기유지된다.

2. P0 <- (LOW -> HIGH -> LOW)
- L98에 신호가 들어오면 그에 따라 M0에도 신호가 들어온다.
- L99에 신호가 들어와도 P21에 신호가 들어오지 않았기 때문에 작동하지 않는다
- L101에 신호가 들어오면 P20에 신호가 들어왔기 때문에 P21이 작동하고 자기유지된다. 
- L103에 신호가 들어오면 P20은 자기유지되고 있기 때문에 신호가 변화하지 않는다

3. P0 <- (LOW -> HIGH -> LOW)
- L98에 신호가 들어오면 그에 따라 M0에도 신호가 들어온다.
- L199에 신호가 들어오면 P20, P21에 신호가 들어왔기 때문에 P21이 작동하고 자기유지된다.
- L101에 신호가 들어오면 P21은 자기유지되고 있기 때문에 신호가 변화하지 않는다 
- L103에 신호가 들어오면 P20은 자기유지되고 있기 때문에 신호가 변화하지 않는다

만약 출력 라인을 반대로 정렬한다면 스캔 방식의 특성상 연속적으로 작동하여 한번에 3개의 모터가 작동하게 된다.
