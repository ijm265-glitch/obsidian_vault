> **COM (공통단자)** : 핀을 하나로 모아주는 역할을 수행한다. 출력핀을 모아주는 출력 COM과 입력핀을 하나로 모아주는 입력 COM이 있다. 

### 1) NPN (Sink 방식: 전류를 들이마심)

- **개념**: 스위치(트랜지스터)가 닫히면 전류가 해당 장치 내부(GND 방향)로 **빨려 들어가며 작동**함.
    
- **센서가 NPN 타입일 때 (PLC 입력 측)**
    - 센서가 전류를 먹는 주체이므로, PLC의 `입력 COM`에 $+24\text{V}$를 연결하여 PLC $\rightarrow$ 센서 방향으로 전류가 빨려 들어가게 해야 함.
        
- **PLC 출력이 NPN 타입일 때 (PLC 출력 측)**
    - PLC가 전류를 들이마시는 주체이므로, PLC의 `출력 COM`에 $0\text{V}$ (GND)를 연결하고, 장비(부하) 반대편에 $+24\text{V}$를 걸어주어야 함.
        

### 2) PNP (Source 방식: 전류를 뿜어냄)

- **개념**: 스위치(트랜지스터)가 닫히면 내부 $+24\text{V}$ 전원에서 외부로 **전류가 뿜어져 나오며 작동**함.
    
- **센서가 PNP 타입일 때 (PLC 입력 측)**
    - 센서가 전류를 뿜어내는 주체이므로, PLC의 `입력 COM`에 $0\text{V}$ (GND)를 연결하여 센서 $\rightarrow$ PLC 방향으로 전류가 흘러 들어오게 해야 함.
        
- **PLC 출력이 PNP 타입일 때 (PLC 출력 측)**
    - PLC가 전류를 뿜어내는 주체이므로, PLC의 `출력 COM`에 $+24\text{V}$를 연결하고, 장비(부하) 반대편을 $0\text{V}$ (GND)에 연결해야 함.


**PNP (Source)**
### NPN 방식 장비
- Normally Open상태에서 그라운드 (0V, GND)를 여닫는 스위치 역할을 함
- **ex) NPN 센서 (입력):**
	- 입력 COM에 연결된 24V가 있을 때 감지하면 신호선과 센서의 그라운드를 연결하여 입력핀의 전압을 낮춤
	- `PSU (24V) ➔ 입력 COM ➔ (PLC, 전압 강하 감지) ➔ 입력 핀 ➔ 신호선 ➔ (센서, NO 스위치) ➔ 센서 전원 GND ➔ PSU (0V)`
- **ex) NPN 출력:**
	- 출력 COM에 연결된 0V가 있을 때 신호를 주면 외부의 24V와 출력 COM (0V, GND)을 연결하여 장비를 동작시킴 
	- `PSU (24V) ➔ 장비 전원 (24V) ➔ 장비 (전력 소비) ➔ 장비 신호선 ➔ 출력 핀 ➔ (PLC, NO 스위치) ➔ 출력 COM ➔ PSU (0V)`

### PNP 방식 장비
- Normally Open 상태에서 전원 (+24V, VCC)을 여닫는 스위치 역할을 함
- **ex) PNP 센서 (입력):**
	- 입력 COM에 연결된 0V(GND)가 있을 때, 센서가 물체를 감지하면 신호선과 센서의 전원(+24V)을 연결하여 입력 핀의 전압을 높임 ($0\text{V} \rightarrow 24\text{V}$)
	- `PSU (24V) ➔ 센서 전원 ➔ (센서, NO 스위치) ➔ 신호선 ➔ 입력 핀 ➔ (PLC, 전압 상승 감지) ➔ 입력 COM ➔ PSU (0V) `
- **ex) PNP 출력:**
	- 출력 COM에 연결된 **+24V**가 있을 때, PLC가 신호를 주면 출력 COM (+24V)과 외부 부하(0V/GND에 연결되어 대기 중인 장비)를 연결하여 전하를 쏴줌으로써 장비를 동작시킴
	- `PSU (24V) ➔ 출력 COM ➔ (PLC, NO 스위치) ➔ 출력 핀 ➔ 장비 신호선 ➔ 장비 (전력 소비)➔ 장비 GND ➔ PSU (0V)`
## 입력핀 
### NPN방식
- **`COM` 배선:** 입력 COM에 **`+24V`** 연결

- **대기 상태:** 입력 핀은 **`24V (HIGH)`** 상태 유지 (전하 밀도 높음)

- **센서 연결:** NPN 센서의 신호선(검은색)을 해당 입력 핀에 연결

- **동작 메커니즘:**
    1. 센서 감지 시, 센서 내부 스위치가 신호선과 센서 GND(0V)를 연결
    2. 
    3. 입력 핀(+24V)과 센서 GND(0V) 사이에 **전위차 발생**
        
    4. 입력 핀의 전하가 센서를 타고 GND로 빠져나가며 **전하 밀도 감소**
        
    5. 입력 핀 전압이 $24\text{V} \rightarrow 0\text{V}$로 강하 (`Falling Edge`)
        
    6. PLC가 이 하강 엣지(`Falling`)를 감지하여 신호 입력 인식

### PNP방식
- **`COM` 배선:** 입력 COM에 **`0V (GND)`** 연결
    
- **대기 상태:** 입력 핀은 **`0V (LOW)`** 상태 유지 (전하 밀도 낮음)
    
- **센서 연결:** PNP 센서의 신호선(검은색)을 해당 입력 핀에 연결
    
- **동작 메커니즘:**
    
    1. 센서 감지 시, 센서 내부 스위치가 신호선과 센서 전원(+24V)을 연결
        
    2. 센서 전원(+24V)과 입력 핀(0V) 사이에 **전위차 발생**
        
    3. 센서에서 공급된 전하가 입력 핀으로 유입되며 **전하 밀도 증가**
        
    4. 입력 핀 전압이 $0\text{V} \rightarrow 24\text{V}$로 상승 (`Rising Edge`)
        
    5. PLC가 이 상승 엣지(`Rising`)를 감지하여 신호 입력 인식

## 출력핀

출력 COM과 출력핀을 PLC가 출력신호를 주면 연결함
### NPN방식
- **`COM` 배선:** 출력 COM에 **`0V`** 연결

- **대기 상태:** 출력 핀은 외부의 장비로부터 **`24V (HIGH)`** 상태 유지 (전하 밀도 높음 )

- **장비 연결:** 장비의 신호선(검은색)을 해당 출력 핀에 연결

- **동작 메커니즘:**
    1. PLC의 출력신호를 주면 출력핀 (24V)이 출력 COM (0V)와 연결됨
    
    2. 장비의 전원(+24V)과 출력 COM(0V) 사이에 **전위차 발생**
        
    3. 전원의 양전하가 COM을 타고 GND로 빠져나가며 **폐회로 형성**
        
    4. 폐회로 형성에 따른 전류 발생으로 부하가 동작
### PNP방식
- **`COM` 배선:** 출력 COM에 **`24V`** 연결

- **대기 상태:** 출력 핀은 **`0V (LOW)`** 상태 유지 (전하 밀도 낮음)

- **장비 연결:** 장비의 신호선(검은색)을 해당 출력 핀에 연결

- **동작 메커니즘:**
    1. PLC의 출력신호를 주면 출력핀 (0V)이 출력 COM (24V)와 연결됨
    
    2. 출력 핀(0V)과 출력 COM(24V) 사이에 **전위차 발생**
        
    3. 출력 COM이 입력핀을 지나 장비의 GND로 빠져나가며 **폐회로 형성**
        
    4. 폐회로 형성에 따른 전류 발생으로 부하가 동작
