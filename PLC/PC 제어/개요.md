제어영역
1. 실시간 제어 커널
	- 주요 언어: IEC 61131-3 (ST, LE) 또는 C/C++
	- 모터 서보 1ms 동기 제어, 센서/솔레노이드 즉시 반응, 인터록 및 안전 로직.
	- TwinCAT 등의 전용 실시간 런타임 커널에 IEC 표준 언어로 올려서 사용
2. 상위 UI / 관리 영역
	- 주요 언어: C#
	- 장비 조작 터치 화면(GUI), 작업 레시피(Recipe) 관리, MES/CIM 공장 서버 통신, 데이터베이스 로깅, 비전 검사 결과 표시

구성 예시
- **로직 작성:** 하부의 모터 구동 시퀀스, IO 제어는 교재 내용대로 TwinCAT PLC(주로 ST 언어)로 작성하여 실시간 영역에 상주시킵니다.
    
- **상위 앱 개발:** 오퍼레이터가 보는 프로그램은 Visual Studio에서 C# (WPF)으로 만듭니다.
    
- **통신 연동:** C# 프로그램이 TwinCAT에서 제공하는 **ADS 통신 라이브러리**(`TwinCAT.Ads`)를 사용해 실시간 PLC 영역의 변수 메모리를 읽고 쓰며 화면에 뿌려주고 버튼 명령을 내립니다.
