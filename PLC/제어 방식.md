#core 
### 두 제어 방식의 핵심 비교

| **구분**       | **1. 단계별 시퀀스 제어 (Stop-and-Go)** | **2. 파이프라인 트래킹 제어 (On-the-Fly)**      |
| ------------ | ------------------------------- | ------------------------------------- |
| **핵심 철학**    | **"하나씩 확실하게 끝내고 다음으로"**         | **"멈추지 않고 흘려보내며 병렬 처리"**              |
| **작업 방식**    | 스토퍼/클램프로 물건을 잡고 정지 상태에서 가공      | 컨베이어가 등속 주행하는 상태에서 감지 및 처리            |
| **동기화 기법**   | **ACK / Req 핸드셰이크**, 하드웨어 인터록   | **FIFO 큐, 링 버퍼, 시프트 레지스터, 엔코더 펄스**    |
| **제어 로직 형태** | 단일 FSM, SFC 차트, 고전 래더 스텝 릴레이    | **구역별 독립 FSM 병렬 구동 + 공유 데이터 큐**       |
| **장점**       | 충돌 위험 0%, 디버깅 단순, 결함 역추적 용이     | **압도적인 생산 속도(Throughput), 공정 병목 최소화** |
| **단점**       | 라인 속도가 가장 긴 단일 작업 시간에 묶임        | 타이머/거리 계산 오차 발생 시 데이터 꼬임 위험           |
| **대표 적용처**   | 정밀 조립, 로봇 용접, 볼트 체결, 가공기 투입     | 물류 분류(소터), 비전 검사, 라벨 부착, 잉크젯 마킹       |
