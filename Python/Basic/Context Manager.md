## 1. 컨텍스트 매니저란?

- **개념:** 자원의 취득(Allocation)과 해제(Release)를 안전하게 자동으로 관리해 주는 파이썬의 구조(Protocol)입니다.
    
- **목적:** 파일, 네트워크 연결, DB 커넥션, 락(Lock) 등을 사용할 때, 예외(Exception)가 발생하더라도 **자원이 반납되지 않고 누수(Leak)되는 위험을 방지**합니다.
    
- **대표 사용 구문:** `with` 문 (`with open(...) as f:`)
    

## 2. 동작 원리: Dunder 메소드 (`__enter__`, `__exit__`)

클래스 내부에서 Dunder 메소드(Double Underscore Method, 던더 메소드)인 `__enter__`와 `__exit__`를 구현하면 해당 클래스의 인스턴스를 `with` 구문에서 사용할 수 있습니다.

### ① `__enter__(self)`

- **시점:** `with` 블록에 진입하는 **직전**에 실행됩니다.
    
- **역할:** 자원을 확보하거나 스트림을 개설하고, OS로부터 받은 **파일 핸들/자원 객체를 반환**합니다.
    
- **`as` 키워드과의 관계:** `__enter__()`가 `return`하는 값이 `with ... as <변수>`의 변수에 할당됩니다.
    

### ② `__exit__(self, exc_type, exc_value, traceback)`

- **시점:** `with` 블록이 **끝나거나, 내부에서 예외(에러)가 발생하여 빠져나올 때** 실행됩니다.
    
- **역할:** 파일 닫기(`close()`), 연결 종료 등 **자원 정리(Clean-up) 작업**을 수행합니다.
    
- **매개변수 (인자 3개):**
    
    - `exc_type`: 발생한 예외의 클래스 (에러가 없으면 `None`)
        
    - `exc_value`: 발생한 예외 인스턴스/메시지 (에러가 없으면 `None`)
        
    - `traceback`: 예외 추적 객체 (에러가 없으면 `None`)
        
- **예외 처리 기믹:** `__exit__`에서 `True`를 반환(`return True`)하면 발생한 예외를 무시(suppress)하고 계속 진행하며, `False`를 반환하거나 아무것도 안 쓰면 에러를 외부로 던집니다.
