# 파이썬 코드 계층 구조
- 라이브러리 (Library)
	- 수 많은 기능이 모여 있는 거대한 단위 (ex. , Pandas)
	- 라이브러리 안에는 여러 개의 모듈과 패키지가 존재
- 패키지 (Package)  =폴더 (관련된 파일들의 묶음)
	- 라이브러리 내부에서, 비슷한 성격의 모듈(파일)을 모아둔 폴더
- 모듈 (Module) = 파이썬 파일(`.py`)
- 객체 (Object)
	- 모듈(파일)안에 정의되어 있는 객체 (ex. sqrt() 함수객체, APIRouter 객체) 
	
---
# 기본 사용 방법
```python 
from Module import Object
```

```python
import fastapi 
# 내가 fastapi패키지에 접근하면 패키지 안의 __init__.py가 실행됨
# __init__.py는 from .applications import FastAPI를 실행하여 FastAPI객체를 메모리에 올려서 패키지.객체로 접근이 가능해짐
app = fastapi.FastAPI() 
# 패키지에서 FastAPI Class Object를 가져옴
```
	ex). `from sklearn.tree import DecisionTreeClassifier`
- Library : sklearn
- Package : sklearn.tree
- Module : \_classes.py `__init__.py가 from ._classes import DecisionTreeClassifier`를 실행해서 `from Package import Object`가 가능함
- Object : DecisionTreeClassifier
