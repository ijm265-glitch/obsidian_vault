# 함수 (function)
```python 
print("1. 아직 함수 객체는 세상에 존재하지 않습니다.")

condition = True

if condition:
	# 인터프리터가 코드 흐름에 따라 def my_func()을 읽을 때 
	# my_func 함수 객체가 힙에 생성됨
    def my_func(): 
        pass
        
```
생성 : 인터프리터가 def가 있는 라인을 실행할 때 힙에 생성
실행 : 함수객체를 호출하여 실행

# 제너레이터 (generator)
```python 
def my_generator(): 
	print("🚀 코드가 드디어 실행됩니다!") 
	yield "부품 1" 
	print("🚀 두 번째 실행!") 
	yield "부품 2"
	
gen = my_generator()
next(gen)
gen.__next__()
```
생성 : 정의한 제너레이터를 호출하여 힙에 생성
실행 : `next()` 또는` __next__()`메서드를 호출하여 실행

# 클래스 (class)
```python
print("1. 아직 클래스 객체는 없습니다.") 
class MyClass: # 파이썬이 이 공간을 '실행'하면서 지나가기 때문에 아래 print문이 즉시 작동합니다! 
	print("🚀 2. MyClass 객체를 힙에 굽고 있는 중입니다!") 
	def my_method(self): 
		pass 

print("3. 이제 메모리에 MyClass라는 클래스 객체가 존재합니다.") 
print(MyClass) 
# 출력: <class '__main__.MyClass'> (클래스 자체도 메모리 주소를 가진 객체입니다)
```
생성 : class가 있는 라인을 실행하는 순간 클래스 내부의 정의된 공간을 쭉 실행하고 빠져나오면서 힙에 생성
실행 : 호출하여 인스턴스를 생성
