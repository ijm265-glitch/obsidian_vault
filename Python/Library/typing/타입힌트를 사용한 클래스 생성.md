# 방법1 : \_\_init\_\_()
```python
class Mold2:

def __init__(self, age: int, name: str, is_student: bool):
	self.age = age
	self.name = name
	self.is_student = is_student

def is_invincible(self):
	if self.age <= 13:
		print("Yes, He is invincible.")
	else:
		print("No He is not.")
```

# 방법2 : dataclass

```python
from dataclasses import dataclass
@dataclass
class Mold1:
	age: int
	name: str
	is_student: bool
	
	def is_invincible(self):
		if self.age <= 13:
			print("Yes, He is invincible.")
		else:
			print("No He is not."
```
