- 클라이언트와 API 서버의 중간에 끼어있는 소프트웨어
- 클라이언트의 request가 API 함수의 인자로 들어오기 전 미들웨어를 거침
- 서버의 response가 전송되기 전 미들웨어를 거침
`왜 쓰나요?`
- 모든 API 함수마다 공통되는 "시간 측정", "로그 남기기"등의 작업을 서버에 들어오고 나가는 모든 요청과 응답을 일괄적으로 통제, 조작
```python
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse

app = FastAPI()

@app.middleware("http")
async def check_ticket_middleware(request: Request, call_next):
	print(f"{request.url.path} 누군가 접근을 시도합니다.")
	token = request.headers.get("Authorization")
	
	if not token:
		return JSONResponse(status_code=401, content={"message": "입장불가: 토큰이 없습니다"})
		
	response = await call_next(request)	
	print("요청 처리가 끝나고 데이터를 프론트엔드로 보냅니다.")
	return response

@app.get("/secret-data")
async def read_data():
	return {"data": "이것은 1급 비밀 데이터입니다."}
```
