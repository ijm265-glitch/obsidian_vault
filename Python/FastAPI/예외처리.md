`HTTPException`과 사용자 정의 예외를 사용하여 예외처리가 가능
# 1. HTTPException
```python
from fastapi import HTTPException, FastAPI

app = FastAPI()

@app.get('/items/{item_id}')
def get_item(item_id: int):
	if item_id == 999:
		raise HTTPException(
			status_code=404,
			detail="요청하신 아이템은 존재하지 않습니다."
		)

	return {"item_id": item_id, "name": "전설의 검"}
```
# 2. 사용자 정의 예외와 전담 핸들러
에러 메시지 형태를 어떠한 스타일로 통일하고 싶거나, 특정 에러가 발생했을 떄 슬랙으로 알림을 보내는 등의 특별한 조치를 하고 싶을 떄 예외 핸들러를 만듬
`사용자 정의 예외를 FastAPI에서 사용하는 법`
1. 파이썬의 커스텀 예외 클래스를 생성
2. 커스텀 예외를 FastAPI에서 사용하기위해 exception_handler를 생성
3. 커스텀 예외가 raise되면 `@app.exception_handler(A)`데코레이터와 연결된 함수를 호출하여 예외처리를 수행한다.
