산업용 3선식 센서(근접 센서, 포토 센서 등)와 PLC 디지털 입력 모듈의 결선은 전류가 센서로 흘러 들어가는가(Sink), 아니면 센서에서 흘러나오는가(Source)라는 폐회로(Closed Loop) 경로를 맞추는 작업입니다.

전선 색상 규격부터 센서 내부 구조, PLC 모듈과의 매칭 원리 및 실제 결선도를 단계별로 정리합니다.

---

### 1. 산업용 3선식 직류(DC 24V) 센서 표준 선 색상

제조사(오므론, 오토닉스, 지멘스 등)를 불문하고 글로벌 표준(IEC 규격)으로 배선 색상이 통일되어 있습니다.

* **갈색 (Brown, BN):** `+24V` (DC 전원 양극)
* **청색 (Blue, BU):** `0V / GND` (DC 전원 음극)
* **흑색 (Black, BK):** `OUT` (검출 신호 출력선)

---

### 2. 센서 출력 타입의 물리적 구조 (NPN vs PNP)

앞서 다룬 트랜지스터 스위칭 원리가 센서 흑색(OUT) 선 내부에 그대로 적용되어 있습니다.

```text
[ NPN 센서 내부 ]                      [ PNP 센서 내부 ]

   갈색 (+24V) ─── 센서 감지 회로        갈색 (+24V) ─── Emitter
                       │                                   │
                       ▼ Base                           [ PNP ]
                    [ NPN ]                                │
                       │                                   ▼ Collector
   흑색 (OUT)  ─── Collector             흑색 (OUT)  ─── 센서 출력선
                       │                                   
   청색 (0V)   ─── Emitter               청색 (0V)   ─── 센서 감지 회로 & GND

```

* **NPN 출력 센서 (전류 Sink형):**
* 센서 감지 시 내부 NPN 트랜지스터가 켜지면서 **흑색(OUT) 선을 청색(0V) 라인으로 단락**시킵니다.
* 즉, 흑색 선은 외부(PLC)로부터 **전류를 빨아들여 0V로 흘려보내는 싱크(Sink) 역할**을 합니다.


* **PNP 출력 센서 (전류 Source형):**
* 센서 감지 시 내부 PNP 트랜지스터가 켜지면서 **갈색(+24V) 라인의 전원을 흑색(OUT) 선으로 공급**합니다.
* 즉, 흑색 선은 외부(PLC)를 향해 **+24V 전류를 뿜어내는 소스(Source) 역할**을 합니다.



---

### 3. 결선의 대원칙: Sink와 Source의 상호 매칭

PLC 입력 모듈 내부에는 신호 절연을 위한 포토커플러(포토다이오드 + 포토TR)가 들어있습니다. 다이오드에 불을 켜려면 **한쪽은 반드시 전류를 밀어주고(Source), 다른 한쪽은 전류를 빨아들여야(Sink)** 합니다.

| 센서 종류 | 센서의 동작 | 요구되는 PLC 입력단 | PLC 공통단자 (COM) 결선 | 주요 사용 지역 |
| --- | --- | --- | --- | --- |
| **NPN 센서** | 전류를 빨아들임 (**Sink**) | 전류를 밖으로 밀어냄 (**Source**) | **COM = +24V** | 한국, 일본 (아시아권 기본) |
| **PNP 센서** | 전류를 밀어냄 (**Source**) | 전류를 안으로 빨아들임 (**Sink**) | **COM = 0V (GND)** | 유럽, 미국 (글로벌 표준) |

---

### 4. 실제 결선도 및 전류 순환 경로

#### 패턴 A: NPN 센서 + 소스(Source) 입력 PLC (COM = +24V)

국내 설비나 일본계 PLC(미쓰비시, LS ELECTRIC 등)에서 가장 흔하게 사용하는 조합입니다.

```text
  +24V ─────────┬───────────────────────────────> [ PLC COM 단자 ]
                │                                         │
                ├─────── 갈색 (Brown, +24V)                │ (내부 저항)
                │                                         ▼
         ┌──────┴──────┐                        ┌──────────────────┐
         │             │                        │  [포토다이오드]   │ (PLC 입력 모듈)
         │  NPN 센서   │                        │         │        │
         │             │                        └─────────┼────────┘
         │  흑색 (OUT) ├──────────────────────────────────┘ [ PLC 입력 핀 (X0) ]
         │             │ (전류 유입: Sink)
         └──────┬──────┘
                │
   0V  ─────────┴─────── 청색 (Blue, 0V) ───────────────────> 전원 공급기 GND

```

* **전류 루프:** `+24V 전원` $\rightarrow$ `PLC COM 단자` $\rightarrow$ `PLC 내부 포토다이오드` $\rightarrow$ `PLC 입력 핀(X0)` $\rightarrow$ `센서 흑색(OUT)` $\rightarrow$ `센서 내부 NPN` $\rightarrow$ `센서 청색(0V)` $\rightarrow$ `0V 전원`
* 센서가 물체를 감지하면 접지 경로를 열어주어 PLC 내부 포토커플러에 순방향 전류가 흐르고, PLC 입력 접점(X0) LED가 켜집니다.

---

#### 패턴 B: PNP 센서 + 싱크(Sink) 입력 PLC (COM = 0V)

유럽계 PLC(지멘스 등) 및 안전 규격이 중요한 공정 라인에서 기본으로 사용하는 조합입니다.

```text
  +24V ─────────┬─────── 갈색 (Brown, +24V)
                │
         ┌──────┴──────┐
         │             │
         │  PNP 센서   │ (전류 방출: Source)
         │  흑색 (OUT) ├──────────────────────────────────┐ [ PLC 입력 핀 (X0) ]
         │             │                                  │
         └──────┬──────┘                        ┌─────────┴────────┐
                │                               │         │        │
                ├─────── 청색 (Blue, 0V)         │  [포토다이오드]   │ (PLC 입력 모듈)
                │                               │         ▼        │
   0V  ─────────┴───────────────────────────────┴─> [ PLC COM 단자 ] (GND)

```

* **전류 루프:** `+24V 전원` $\rightarrow$ `센서 갈색(+24V)` $\rightarrow$ `센서 내부 PNP` $\rightarrow$ `센서 흑색(OUT)` $\rightarrow$ `PLC 입력 핀(X0)` $\rightarrow$ `PLC 내부 포토다이오드` $\rightarrow$ `PLC COM 단자` $\rightarrow$ `0V 전원`
* 센서가 물체를 감지하면 흑색 선으로 +24V를 뿜어주어 PLC 내부 포토커플러를 거쳐 0V(COM)로 빠져나가면서 입력 접점이 활성화됩니다.

---

### 5. 한눈에 끝내는 현장 점검 규칙

1. **"센서가 NPN이면 COM은 플러스(+24V), 센서가 PNP면 COM은 마이너스(0V)"**
2. **테스터기(멀티미터) 전압 측정 요령:**
* **NPN 센서 검증:** 검정 리드봉을 `0V`에 대고, 빨간 리드봉을 `흑색(OUT)`에 댄 상태에서 감지 시 전압이 $0\text{V}$로 떨어지면 정상(오픈 컬렉터 Low 도통).
* **PNP 센서 검증:** 검정 리드봉을 `0V`에 대고, 빨간 리드봉을 `흑색(OUT)`에 댄 상태에서 감지 시 전압이 약 $24\text{V}$가 찍히면 정상(+24V 인가).
