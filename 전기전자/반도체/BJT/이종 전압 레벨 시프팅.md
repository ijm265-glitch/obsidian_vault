
### 1. 회로도 (레벨 시프팅)

```text
 [ 5V MCU 영역 ]            :              [ 24V 외부 전원 영역 ]
                            :
                            :                +24V (외부 전원)
                            :                  │
                            :             [ R_pull-up ] (풀업 저항: 10kΩ)
                            :                  │
 [출력 핀] ─────────────────:──────────────────●──────> [ 24V 입력 기기 / PLC ]
    │                       :                  (신호 노드)
    │                       :
 Collector (C)              :
    │                       :
  [ NPN ]                   :
    │                       :
 Emitter (E)                :
    │                       :
   GND (0V) ────────────────:─────────────────────────> GND (공통 접지: 0V)
                            :
                  (점선: 물리적 경계)

```

#### 노드(●)의 배선 연결

가운데 점(`●`)이 찍힌 신호 노드에 **세 가닥의 선**이 함께 만납니다:

1. **왼쪽:** 5V MCU 내부 NPN 트랜지스터의 컬렉터(출력 핀)에서 온 선
2. **위쪽:** 외부 24V 전원에서 풀업 저항을 거쳐 내려온 선
3. **오른쪽:** 다음 24V 입력 기기(PLC, 드라이버 등)로 신호를 전달하는 선

---

### 2. 왜 5V MCU가 24V에 연결되어도 타지 않는가?

일반적인 마이크로컨트롤러 출력 핀은 내부에 5V 전원선이 연결되어 있어서, 밖에서 24V를 넣으면 내부로 전기가 역류해 칩이 터집니다.

하지만 오픈 컬렉터(Open Collector)는 칩 내부에 전원선이 아예 없습니다.

* 오직 '접지(0V)로 가는 길을 열어줄 NPN 스위치'만 들어있습니다.
* 따라서 외부에서 24V를 풀업 저항으로 걸어주더라도, 전압이 MCU 내부 전원 회로로 역류할 길 자체가 없어 MCU가 안전합니다.

---

### 3. 신호 전달 동작 원리 (0V와 24V 생성)

MCU가 내부 NPN 트랜지스터를 켜고 끄는 것에 따라 신호 노드(`●`)의 전압이 어떻게 바뀌는지 확인해 보겠습니다.

#### 상황 1. MCU가 신호를 끌 때 (NPN OFF) $\rightarrow$ 24V 출력

* **스위치 상태:** MCU 내부의 NPN 트랜지스터가 완전히 열린(끊어진) 스위치가 됩니다.
* **전류의 흐름:** 아래쪽 GND(0V)로 빠져나갈 길이 완전히 차단되므로, 풀업 저항을 통해 흐르는 전류는 $0\text{A}$입니다.
* **전압 형성:**
* 저항 양단에 전압 강하가 전혀 발생하지 않습니다($\Delta V = 0\text{V}$).
* 따라서 외부 전원의 **+24V가 신호 노드(`●`)에 그대로 맺히게 됩니다**.


* **결과:** 다음 기기(PLC)는 입력선으로 **24V (High)** 신호를 받게 됩니다.

#### 상황 2. MCU가 신호를 켤 때 (NPN ON) $\rightarrow$ 0V 출력

* **스위치 상태:** MCU 내부의 NPN 트랜지스터가 도통되어 신호선을 접지(GND)와 이어줍니다.
* **전류의 흐름:**
* +24V 외부 전원에서 풀업 저항을 통과한 전류가 NPN을 타고 안전하게 GND(0V)로 빠져나갑니다.
* 이때 풀업 저항(10kΩ)이 중간에서 전류를 약 $2.4\text{mA}$로 작게 제한해 주므로 쇼트가 발생하지 않습니다.


* **전압 형성:**
* 신호 노드(`●`)가 NPN을 통해 바닥(GND)에 붙어버렸기 때문에, 신호선의 전압은 즉시 약 0V (Low)로 뚝 떨어집니다.


* **결과:** 다음 기기(PLC)는 입력선으로 **0V (Low)** 신호를 받게 됩니다.

---

### 4. 핵심 정리

* 5V 제어기는 단지 NPN 스위치를 닫아 접지로 당기거나(ON), 손을 떼는 것(OFF)만 합니다.
* 바깥에 달린 **풀업 저항이 24V 전압을 공급**해 줍니다.
* 이 덕분에 5V MCU의 부담 없이 외부 회로에는 깔끔한 0V / 24V 디지털 신호(레벨 시프팅)가 전달됩니다.
