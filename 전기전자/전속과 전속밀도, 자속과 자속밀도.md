# 전기력선
- 전기장의 세기를 나타내기 위해 전기장위에서 그려지는 선 
- 어떤 양전하를 전기장 위에 두었을 때 힘을 받아 움직이는 방향을 전기력선이라고 할 수 있다
- 전기력선은 유전율이 반영된 값으로 다음과 같다
진공 상태에서 전하 $Q$가 있을 때, 여기서 나오는 총 전기력선의 개수($N$)는 다음과 같이 약속합니다.

$$N = \frac{Q}{\varepsilon_0}\ \text{[개]}$$
- 즉 어떤 전하를 소스로 하여 3차원 공간에서 발산하는 전기력선은 유전율이 클수록 작아진다
- 전기력선이 빽빽하면 그곳의 전기장이 강하고 듬성하면 전기장의 값이 약하다고 할 수 있다
- 이를 전기력선의 밀도로 나타낼 수 있으며 이는 역시 전기장의 세기 그 자체이다.
- $$E=\frac{1}{4\pi r^2}\cdot\frac{Q}{\epsilon}[N/C = V/m]$$
# 전속
- 앞서 설명한 전기력선은 유전율이 반영되어 복잡한 계산을 요한다.
- 따라서 계산상의 단순함을 만들기 위해 전속이라는 개념이 만들어졌고 전속은 전기력선과 같이 어떤 양전하를 전기장 위에 두었을 때 힘을 받아 움직이는 방향을 전속이라고 한다. 
- 진공상태에서 전하 $Q$가 있을때 여기서 나오는 총 전속의 수는 다음과 같다.
- $$N = Q$$
- 전속 역시 어떤 위치에서의 밀도가 높으면 전하를 강하게 밀어내고 밀도가 낮으면 전하를 약하게 밀어낸다
- 따라서 전속밀도 D는 다음과 같이 정의된다.
$$D=\frac{Q}{4\pi r^2}$$
- 따라서 전속밀도와 전기장(전기력선의 밀도)는 다음과 같이 나타난다
- $$D=\epsilon E$$
### 자기력선

- **정의:** 자기장의 세기를 나타내기 위해 자기장 위에서 그려지는 가상의 선.
    
- **성질:** 어떤 양의 자극(N극)을 자기장 위에 두었을 때 힘을 받아 움직이는 방향을 자기력선이라고 할 수 있다. (실제로는 자극이 단독으로 존재할 수 없어 자기력선은 시작과 끝이 없는 닫힌 곡선(폐루프)을 이룬다.)
    
- **특징:** 자기력선은 매질의 투자율($\mu$)이 반영된 값으로 다음과 같다.
    
    > 자하 $m\ \text{[Wb]}$이 있을 때, 여기서 나오는 총 자기력선의 개수($N_H$)는 다음과 같이 약속합니다.
    > 
    > $$N_H = \frac{m}{\mu}\ \text{[개]}$$
    > 
    > 즉, 어떤 자극을 소스로 하여 3차원 공간에서 발산하는 자기력선은 매질의 **투자율($\mu$)이 클수록 개수가 작아진다.**
    
- **밀도와의 관계:** 자기력선이 빽빽하면 그곳의 자기장(자계)이 강하고 듬성하면 자기장의 값이 약하다고 할 수 있다. 이를 자기력선의 밀도로 나타낼 수 있으며, 이는 역시 **자기장의 세기($H$) 그 자체**이다.
    
    $$H = \frac{1}{4\pi r^2} \cdot \frac{m}{\mu}\ \text{[A/m]}$$
    

### 자속 (Magnetic Flux)

- **도입 배경:** 앞서 설명한 자기력선은 매질의 투자율($\mu$)이 반영되어 매질이 바뀔 때마다 개수가 변하므로 복잡한 계산을 요한다.
    
- **정의:** 따라서 계산상의 단순함을 만들기 위해 자속($\Phi$)이라는 개념이 만들어졌고, 자속은 자기력선과 같이 자극이 자기장 위에서 힘을 받아 움직이는 방향을 자속이라고 한다.
    
- **특징:** 매질의 투자율과 관계없이 자하 $m\ \text{[Wb]}$이 있을 때 여기서 나오는 총 자속의 수는 다음과 같다.
    
    $$\Phi = m\ \text{[Wb]}$$
    
- **밀도와의 관계:** 자속 역시 어떤 위치에서의 밀도가 높으면 실제 물리적인 힘을 강하게 미치고, 밀도가 낮으면 힘을 약하게 미친다. (실제 전하가 받는 로런츠 힘과 전자기 유도 현상을 결정하는 **진짜 알짜 물리량**이다.)
    
- **자속밀도 ($B$):** 따라서 자속밀도 $B$는 다음과 같이 정의된다.
    
    $$B = \frac{m}{4\pi r^2}\ \text{[Wb/m}^2 = \text{T]}$$
    

### 자속밀도와 자기장의 관계

따라서 자속밀도($B$)와 자기장(자기력선의 밀도, $H$)은 매질의 투자율($\mu$)을 매개로 하여 다음과 같은 관계식으로 나타난다.

$$B = \mu H$$

> **💡 전기를 방해하는 유전율($\varepsilon$)과 달리, 투자율($\mu$)은 자기장을 통과시키고 강화하는 성질이므로 곱하기($\mu H$)의 형태로 자속밀도(최종 알짜 힘)가 강력해집니다.**

| **구분** | **매질의 반응을 반영하기 전 '원인'(가상의 다발 밀도)**                                                                                                    | **매질의 반응을 반영한 '진짜 최종 물리량'(실제 힘을 발휘하는 필드)**                                                        |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| **전기** | **전속밀도 ($D[C/m^2]$)**<br><br>  <br><br>_(유전율 $\varepsilon$을 반영하기 전 원래의 전기적 밀도)_                                                       | **전기장 세기 ($E = \frac{D}{\varepsilon}[V/m, N/C]$)**<br><br>  <br><br>_(유전율을 반영하여 **약화**된 실제 전기 힘)_ |
| **자기** | **자기장 세기 ($H[AT/m, N/Wb]$)**<br><br>전하량의 단위는 $C$ 자하량의 단위는 $Wb$                               <br><br>_(투자율 $\mu$를 반영하기 전 원래의 자기적 밀도)_ | **자속밀도 ($B = \mu H$)$[T, Wb/m^2]$**<br><br>  <br><br>_(투자율을 반영하여 **강화**된 실제 자기 힘)_                |
|        |                                                                                                                                       |                                                                                                   |

$$\mathbf{F} = q(\mathbf{E} + \mathbf{v} \times \mathbf{B})$$
- $\mathbf{F}$: 전하가 받는 최종 로런츠 힘 벡터 $[\text{N}]$
- $q$: 입자의 전하량 $[\text{C}]$
- $\mathbf{E}$: 그 지점의 전기장 세기 벡터 $[\text{V/m}]$
- $\mathbf{v}$: 전하의 이동 속도 벡터 $[\text{m/s}]$
- $\mathbf{B}$: 그 지점의 **자속밀도** 벡터 $[\text{T}]$
# 전위차
$$V_{AB} = V_A - V_B = -\int_{B}^{A} \mathbf{E} \cdot d\mathbf{l}$$

- $\mathbf{E}$: 전기장 벡터 (전하가 받는 전기력의 방향)
- $d\mathbf{l}$: 이동 경로의 미소 변위 벡터
- **음의 부호($-$)가 붙는 이유:**
	우리가 전하를 이동시키기 위해 가해야 하는 힘은 전기장 방향과 반대 방향(척력을 거스르는 방향)이어야 외력이 양의 일을 할 수 있습니다. 즉, 전기장에 거슬러서 일($-\mathbf{E}$)을 해준 것을 적분했다는 물리적 의미를 담고 있습니다. 
- 절대적인 전압(전위차)이란 어떠한 점에서의 전위와 아주 먼 거리에서(따라서 전기력선의 밀도가 매우 낮은 곳)의 전위차를 의미한다 즉 
- $$V = -\int_{\infty}^{r} E \cdot dr' = \frac{Q}{4\pi\varepsilon r}\ \text{[V]}$$
