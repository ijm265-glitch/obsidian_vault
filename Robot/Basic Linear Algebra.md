
좌표란?
기저벡터를 각각 얼마나 취합할지에 대한 것
점 P = (3, 1, 2) 좌표를 가지고 있을 때
\[\[1, 0, 0\].T, \[0, 1, 0\].T, \[0, 0, 1\].T\]
의 기저벡터가 있다면 
각각 \[1, 0, 0\].T 를 3배
\[0, 1, 0\].T 를 1배
\[0, 0, 1\].T 를 2배
하여 합하면 그 점을 기술할 수 있다.

**능동(active) 회전**과 **수동(passive) 회전**

### 예시: $R_z(90°)$

$$R=\begin{bmatrix}0&-1&0\\1&0&0\\0&0&1\end{bmatrix}$$

**관점 1. 능동: 벡터를 돌린다**  
좌표축은 가만히 있고 **벡터가 90° 돌아가요.**  

$$R\begin{bmatrix}1\\0\\0\end{bmatrix}=\begin{bmatrix}0\\1\\0\end{bmatrix}$$

x 방향 화살표가 y 방향으로 돌아갔어요.

**관점 2. 기저(좌표계)를 돌린다**  
이번엔 **좌표축을 90° 돌려서 새 좌표계 B를 만들어요.** 이때 두 가지를 물어볼 수 있어요.

- **(2-a) 새 축은 어디를 가리키나?**  
    $R$의 **열**이 정답이에요. 1열 (0, 1, 0)은 새 x축, 2열 (−1, 0, 0)은 새 y축이에요. 기저벡터를 능동 회전시킨 결과니까, 관점 1과 같은 행렬이 그대로 나와요.
- **(2-b) 가만히 있는 점의 좌표는 새 좌표계에서 몇이 되나?**  
    여기서 **전치 $R^T$**가 필요해요. 점 (1, 0, 0)은 그대로인데 축이 돌았으니, 새 좌표계에서는  
    $$R^T\begin{bmatrix}1\\0\\0\end{bmatrix}=\begin{bmatrix}0\\-1\\0\end{bmatrix}$$ 축이 +90° 돌면 점은 상대적으로 −90° 돈 것처럼 보이죠.

### 핵심 정리

|질문|쓰는 행렬|
|---|---|
|벡터를 θ만큼 돌리면? (능동)|$R$|
|좌표계를 θ만큼 돌리면, 새 축 방향은?|$R$의 열|
|좌표계 B에서 잰 좌표를 A 좌표로 바꾸려면?|$\mathbf{p}_A = R\,\mathbf{p}_B$|
|A에서 잰 좌표를 B 좌표로 바꾸려면?|$\mathbf{p}_B = R^T\mathbf{p}_A$|

새로운 좌표계에서 보았을 때 그 점의 물리적 위치는 바뀌지 않는다
